N10: Decimals and Fractions

Foundation Higher All Boards

Convert between terminating/recurring decimals and fractions. Identify which fractions give terminating decimals. Use exact fraction forms in calculations.

Lesson Overview

Estimated Lessons: 2
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, Eduqas, CCEA

Learning Objectives

  • Convert terminating decimals to fractions (simplify)
  • Convert fractions to terminating decimals (division)
  • Convert recurring decimals to fractions (algebraic method)
  • Identify if a fraction gives terminating or recurring decimal
  • Use exact fractions in calculations instead of rounded decimals

Prerequisites

  • Place value (tenths, hundredths, thousandths)
  • Fraction simplification (HCF)
  • Short/long division
  • Basic algebra: forming and solving equations (for recurring)

Materials & Equipment

  • Scientific calculator (fraction ↔ decimal button)
  • Place value grids
  • Recurring decimal notation cards (dot notation)
  • Fraction/decimal equivalence tables

Lesson 1: Terminating Decimals and Fractions

Duration: 50 minutes

Starter Activity (5 minutes)

Quick Conversions

0.5 = ?, 0.25 = ?, 0.125 = ?, 3/4 = ?, 7/8 = ?

Main Content (35 minutes)

Teaching Notes:
Decimal → Fraction: Write as fraction with denominator 10, 100, 1000... then simplify.
0.7 = 7/10
0.35 = 35/100 = 7/20
0.008 = 8/1000 = 1/125
2.4 = 24/10 = 12/5

Fraction → Decimal: Divide numerator by denominator (short division).
3/8 = 3 ÷ 8 = 0.375
7/16 = 7 ÷ 16 = 0.4375

Terminating vs Recurring: Fraction in simplest form. Denominator prime factors only 2 and/or 5 → terminating. Other prime factors → recurring.
3/20 = 3/(2²×5) → terminating
2/15 = 2/(3×5) → recurring
Worked Example 1: Decimal to Fraction

Convert to fractions in simplest form:
(a) 0.6 = 6/10 = 3/5
(b) 0.125 = 125/1000 = 1/8
(c) 0.04 = 4/100 = 1/25
(d) 1.375 = 1375/1000 = 11/8 = 1⅜
(e) 0.002 = 2/1000 = 1/500

Worked Example 2: Fraction to Decimal

Convert to decimals:
(a) 7/20 = 7 ÷ 20 = 0.35
(b) 5/8 = 5 ÷ 8 = 0.625
(c) 11/40 = 11 ÷ 40 = 0.275
(d) 3/16 = 3 ÷ 16 = 0.1875

Worked Example 3: Terminating or Recurring?

Simplify denominator, check prime factors:
(a) 3/12 = 1/4 = 1/2² → terminating (0.25)
(b) 5/18 = 5/(2×3²) → has 3 → recurring (0.27̇)
(c) 7/32 = 7/2⁵ → only 2s → terminating (0.21875)
(d) 4/15 = 4/(3×5) → has 3 → recurring (0.26̇)
(e) 9/50 = 9/(2×5²) → only 2,5 → terminating (0.18)

Terminating Decimal ⇔ Fraction (simplest form) has denominator of form 2ᵃ5ᵇ

Recurring Decimal ⇔ Fraction (simplest form) has prime factor other than 2 or 5

Notation:
0.3̇ = 0.333...
0.16̇ = 0.1666...
0.1̇6̇ = 0.161616...
0.12̇3̇ = 0.1232323...

Common Misconception

0.5 = 5/100 (confusing tenths/hundredths)

0.5 = 5 tenths = 5/10. The first decimal place is tenths.

Differentiation

Support:
Place value chart. "Read the decimal aloud: 0.35 = 35 hundredths = 35/100". Division scaffold for fraction→decimal.
Stretch:
Prove: fraction terminates iff denominator is 2ᵃ5ᵇ. Convert 0.12̇3̇ to fraction. Find fraction between 0.3̇ and 0.34.

Plenary (5 minutes)

Terminating or Recurring?

3/25 (T), 5/28 (R), 7/40 (T), 11/30 (R), 13/64 (T)

Assessment Criteria

  • Got it: Converts both ways fluently; simplifies fractions; identifies terminating/recurring correctly
  • Getting there: Converts terminating decimals; division errors for fraction→decimal; prime factor check incomplete
  • Not yet: Place value confusion; cannot simplify; no division method

Lesson 2: Recurring Decimals to Fractions (Higher)

Duration: 50 minutes

Starter Activity (5 minutes)

Pattern Recognition

1/9 = 0.1̇, 2/9 = 0.2̇, 3/9 = 0.3̇... What is 7/9? What about 1/99, 23/99?

Main Content (35 minutes)

Teaching Notes:
Algebraic Method for Pure Recurring: Let x = recurring decimal. Multiply by 10, 100, 1000... to shift repeat. Subtract.
Example: x = 0.3̇ → 10x = 3.3̇ → 10x - x = 3 → 9x = 3 → x = 3/9 = 1/3

Mixed Recurring: Non-repeating then repeating part.
x = 0.16̇ → 10x = 1.6̇, 100x = 16.6̇ → 100x - 10x = 15 → 90x = 15 → x = 15/90 = 1/6

Shortcut: Pure recurring: repeat/9s. Mixed: (all digits - non-repeating) / (9s then 0s).
Worked Example 1: Pure Recurring

Convert 0.7̇ to a fraction.
Let x = 0.777...
10x = 7.777...
Subtract: 10x - x = 7.777... - 0.777...
9x = 7
x = 7/9

Worked Example 2: Two Digits Recurring

Convert 0.1̇6̇ to a fraction.
Let x = 0.161616...
100x = 16.161616...
Subtract: 100x - x = 16
99x = 16
x = 16/99

Worked Example 3: Mixed Recurring

Convert 0.21̇6̇ to a fraction.
Let x = 0.2161616...
10x = 2.161616... (shift past non-repeating)
1000x = 216.161616... (shift one full repeat)
Subtract: 1000x - 10x = 216 - 2 = 214
990x = 214
x = 214/990 = 107/495

Recurring Decimal → Fraction (Algebraic):
1. Let x = decimal
2. Multiply by 10ⁿ to shift repeat to left of decimal
3. Multiply by 10ᵏ to shift one repeat (or align)
4. Subtract to eliminate recurring part
5. Solve for x, simplify

Shortcuts:
0.ȧ = a/9
0.aḃ = ab/99
0.ȧḃ = ab/99
0.cä̇ (c non-repeating) = (ca - c)/90...0

Common Misconception

0.16̇ = 16/99

0.16̇ = 0.1666... not 0.161616... The dot is only over 6. 0.16̇ = 1/6, but 0.1̇6̇ = 16/99.

Differentiation

Support:
Step-by-step template. Start with pure recurring (0.ȧ, 0.aḃ). Use shortcut patterns: /9, /99, /999.
Stretch:
Convert 0.0̇9̇ ( = 1?), 0.123̇4̇5̇. Prove 0.9̇ = 1. Express 0.0̇1̇2̇ as fraction.

Plenary (5 minutes)

Quick Convert

0.4̇ = 4/9
0.0̇4̇ = 4/99
0.1̇2̇ = 12/99 = 4/33
0.3̇6̇ = 36/99 = 4/11
0.16̇ = 1/6

Assessment Criteria

  • Got it: Algebraic method for any recurring decimal; simplifies answers; uses shortcuts
  • Getting there: Pure recurring method; struggles with mixed recurring; subtraction alignment errors
  • Not yet: Doesn't understand algebraic method; treats recurring as terminating; no subtraction

Homework Suggestions

  • Mixed conversion worksheet (decimal↔fraction, terminating↔recurring)
  • Recurring decimal to fraction practice (algebraic method)
  • Identify terminating/recurring for 20 fractions
  • Calculator check: use fraction button to verify
  • CorbettMaths "Recurring Decimals to Fractions" (Higher)
