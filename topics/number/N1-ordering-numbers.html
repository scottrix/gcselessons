N1: Ordering Numbers

Foundation Higher All Boards

Order positive and negative integers, decimals, and fractions using inequality symbols. Use a number line to compare and arrange values from smallest to largest.

Lesson Overview

Estimated Lessons: 2
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, Eduqas, CCEA

Learning Objectives

  • Order positive and negative integers on a number line
  • Compare and order decimals (up to 3 decimal places)
  • Order fractions by converting to common denominators or decimals
  • Use inequality symbols (<, >, ≤, ≥) correctly
  • Order mixed sets of integers, decimals, and fractions

Prerequisites

  • Place value understanding (units, tens, hundreds, tenths, hundredths)
  • Understanding of negative numbers on a number line
  • Basic fraction equivalence (e.g., 1/2 = 2/4 = 0.5)
  • Reading and writing inequality symbols

Materials & Equipment

  • Scientific calculator
  • Number line (printed or drawn)
  • Squared paper for aligning decimals
  • Fraction wall or fraction strips (optional)

Lesson 1: Integers and Decimals

Duration: 50 minutes

Starter Activity (5 minutes)

Number Line Placement

Place these numbers on a number line: -5, -2, 0, 3, 7. Which is smallest? Which is largest?

Main Content (35 minutes)

Teaching Notes:
Integers: Negative numbers are smaller than positive numbers. On a number line, values increase left to right. -7 < -3 < 0 < 2 < 5.

Decimals: Align decimal points vertically. Compare digit by digit from left to right. Add placeholder zeros if needed.
Example: Order 0.6, 0.06, 0.606, 0.066
Align: 0.600, 0.060, 0.606, 0.066
Order: 0.060 < 0.066 < 0.600 < 0.606

Mixed integers and decimals: -2.5 < -1 < 0 < 0.5 < 3
Worked Example 1: Ordering Decimals

Order from smallest to largest: 3.4, 3.04, 3.404, 3.004

Step 1: Align decimal points and add zeros: 3.400, 3.040, 3.404, 3.004
Step 2: Compare units: all 3
Step 3: Compare tenths: 0, 0, 4, 4 → 3.004 and 3.040 are smallest
Step 4: Compare hundredths: 3.004 has 0, 3.040 has 4 → 3.004 < 3.040
Step 5: Compare 3.400 and 3.404: hundredths both 0, thousandths: 0 vs 4 → 3.400 < 3.404
Answer: 3.004 < 3.040 < 3.400 < 3.404

Worked Example 2: Mixed Integers and Decimals

Order: -4, -1.2, 0, 0.5, 2, -0.8

Negative numbers first (most negative is smallest): -4 < -1.2 < -0.8
Then zero: 0
Then positive: 0.5 < 2
Answer: -4 < -1.2 < -0.8 < 0 < 0.5 < 2

Inequality Symbols:
< means "less than" (smaller)
> means "greater than" (larger)
≤ means "less than or equal to"
≥ means "greater than or equal to"

Memory aid: The symbol opens toward the larger number (like a crocodile mouth eating the bigger value).

Common Misconception

0.6 is smaller than 0.06 because 6 is smaller than 60

0.6 = 0.60 which is greater than 0.06. Always align decimal points and compare place values.

Differentiation

Support:
Use number lines with marked intervals. Provide place value grids for decimals. Start with positive numbers only.
Stretch:
Order numbers in standard form (e.g., 3.2 × 10³, 4.1 × 10²). Include recurring decimals (0.3̇, 0.16̇).

Plenary (5 minutes)

True or False?

-3.5 < -2.8 → True
0.07 > 0.7 → False
-1 ≤ -1 → True

Assessment Criteria

  • Got it: Correctly orders mixed sets including negatives, decimals to 3dp, uses inequality symbols accurately
  • Getting there: Orders positives and negatives separately; struggles with decimal place alignment
  • Not yet: Confuses direction of inequality; thinks more decimal digits = larger number

Lesson 2: Ordering Fractions and Mixed Sets

Duration: 50 minutes

Starter Activity (5 minutes)

Fraction to Decimal

Convert to decimals: 1/2, 3/4, 2/5, 5/8. Use calculator if needed.

Main Content (35 minutes)

Teaching Notes:
Method 1 - Common Denominator: Convert fractions to equivalent fractions with the same denominator.
Example: Order 2/3, 3/4, 5/6. LCM of 3,4,6 = 12.
2/3 = 8/12, 3/4 = 9/12, 5/6 = 10/12 → 2/3 < 3/4 < 5/6

Method 2 - Decimal Conversion: Divide numerator by denominator.
2/3 ≈ 0.667, 3/4 = 0.75, 5/6 ≈ 0.833 → Same order.

Mixed sets: Convert everything to decimals for easiest comparison.
Example: Order 0.6, 2/3, 0.65, 5/8
2/3 ≈ 0.667, 5/8 = 0.625
Order: 0.6 < 0.625 < 0.65 < 0.667 → 0.6 < 5/8 < 0.65 < 2/3
Worked Example: Mixed Fractions, Decimals, Integers

Order from smallest to largest: -1/2, 0.4, -0.3, 3/5, -1

Convert fractions: -1/2 = -0.5, 3/5 = 0.6
List as decimals: -1, -0.5, -0.3, 0.4, 0.6
Order: -1 < -0.5 < -0.3 < 0.4 < 0.6
Answer: -1 < -1/2 < -0.3 < 0.4 < 3/5

Fraction Comparison Methods:
1. Common Denominator: LCM of denominators
2. Decimal Conversion: Numerator ÷ Denominator
3. Cross-multiplication: For a/b and c/d, compare ad and bc
If ad < bc then a/b < c/d

Negative Fractions: More negative = smaller
-3/4 < -1/2 because -0.75 < -0.5

Common Misconception

Larger denominator means larger fraction (e.g., 1/8 > 1/4)

For unit fractions, larger denominator = smaller fraction. 1/8 = 0.125, 1/4 = 0.25, so 1/8 < 1/4.

Differentiation

Support:
Use fraction walls. Stick to denominators 2,3,4,5,8,10. Provide conversion tables.
Stretch:
Order algebraic fractions (e.g., x/3, x/4 for x > 0). Include improper fractions and mixed numbers.

Plenary (5 minutes)

Exit Ticket

Order: 2/5, 0.35, 3/8, 0.4. Show your method.

Assessment Criteria

  • Got it: Chooses efficient method, orders mixed sets correctly, explains reasoning
  • Getting there: Can order fractions with common denominator; struggles with mixed sets
  • Not yet: Cannot convert fractions to decimals; confuses denominator size

Homework Suggestions

  • Textbook exercise: Ordering integers, decimals, fractions (mixed)
  • Create 5 sets of 5 numbers each (mixed types) for a partner to order
  • Real-world: Record temperatures for 7 days, order from coldest to warmest
  • Online practice: MathsWatch / CorbettMaths / DrFrost N1 ordering questions
