N16: Upper and Lower Bounds

Higher All Boards

Higher tier only. Calculate with upper and lower bounds. Find bounds of compound measures (speed, density, pressure). Determine suitable degree of accuracy for answers.

Lesson Overview

Estimated Lessons: 3
Tier: Higher only
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, Eduqas, CCEA

Learning Objectives

  • Find upper and lower bounds of rounded values
  • Calculate bounds for addition, subtraction, multiplication, division
  • Find bounds of compound measures (speed, density, pressure)
  • Determine maximum/minimum possible values
  • Express answers to appropriate degree of accuracy using bounds

Prerequisites

  • Error intervals and rounding (N15)
  • Inequality notation and number lines
  • Compound measures: speed = d/t, density = m/v, pressure = F/A
  • Rearranging formulae

Materials & Equipment

  • Scientific calculator
  • Bounds calculation templates
  • Compound measure formula triangles
  • Practical measuring equipment for context

Lesson 1: Calculating with Bounds

Duration: 50 minutes

Starter Activity (5 minutes)

Bounds Recap

x = 5.3 (1 dp). Write error interval. LB = ?, UB = ?

Main Content (35 minutes)

Teaching Notes:
Bounds Terminology: Lower Bound (LB) = minimum possible value. Upper Bound (UB) = maximum possible value (exclusive).

Rules for Calculations (to find overall LB/UB):
ADDITION: LB = LB₁ + LB₂, UB = UB₁ + UB₂
SUBTRACTION: LB = LB₁ - UB₂, UB = UB₁ - LB₂ (subtract largest from smallest for LB)
MULTIPLICATION: LB = LB₁ × LB₂, UB = UB₁ × UB₂ (all positive)
DIVISION: LB = LB₁ ÷ UB₂, UB = UB₁ ÷ LB₂ (divide by largest for LB)

Key Principle: For LB make result as small as possible. For UB make result as large as possible.
Worked Example 1: Addition and Subtraction

x = 4.2 (1 dp), y = 1.8 (1 dp).
LBₓ = 4.15, UBₓ = 4.25
LBy = 1.75, UBy = 1.85

x + y: LB = 4.15 + 1.75 = 5.90, UB = 4.25 + 1.85 = 6.10
x - y: LB = 4.15 - 1.85 = 2.30, UB = 4.25 - 1.75 = 2.50

Worked Example 2: Multiplication and Division

x = 4.2 (1 dp), y = 1.8 (1 dp). All positive.
LBₓ = 4.15, UBₓ = 4.25
LBy = 1.75, UBy = 1.85

x × y: LB = 4.15 × 1.75 = 7.2625, UB = 4.25 × 1.85 = 7.8625
x ÷ y: LB = 4.15 ÷ 1.85 = 2.243..., UB = 4.25 ÷ 1.75 = 2.428...

Worked Example 3: Negative Bounds (Subtraction)

a = 8.3 (1 dp), b = 5.7 (1 dp). Find bounds of a - b.
LBa = 8.25, UBa = 8.35
LBb = 5.65, UBb = 5.75
LB(a-b) = LBa - UBb = 8.25 - 5.75 = 2.50
UB(a-b) = UBa - LBb = 8.35 - 5.65 = 2.70

Check: actual range of a-b = [8.25-5.75, 8.35-5.65] = [2.50, 2.70] ✓

Bounds Calculation Rules (positive values):
+ : LB = LB₁+LB₂, UB = UB₁+UB₂
- : LB = LB₁-UB₂, UB = UB₁-LB₂
× : LB = LB₁×LB₂, UB = UB₁×UB₂
÷ : LB = LB₁÷UB₂, UB = UB₁÷LB₂

Memory: For LB, make result SMALLEST. For UB, make result LARGEST.
Subtraction: LB₁ - UB₂ (smallest minus largest)
Division: LB₁ ÷ UB₂ (smallest divided by largest)

Common Misconception

UB - LB for subtraction

LB = LB₁ - UB₂ (subtract LARGEST possible second from SMALLEST possible first). UB = UB₁ - LB₂.

Differentiation

Support:
"Smallest possible" / "Largest possible" language. Visual number lines for each operation. Fill-in tables for each operation.
Stretch:
Bounds with negative numbers. Bounds for powers/roots: (LB)², (UB)². Multiple operations: (x+y)×z. Bounds of bounds.

Plenary (5 minutes)

Quick Bounds

x = 3.4 (1 dp), y = 2.1 (1 dp).
LB(x+y) = 3.35+2.05 = 5.40
UB(x+y) = 3.45+2.15 = 5.60
LB(x-y) = 3.35-2.15 = 1.20
UB(x-y) = 3.45-2.05 = 1.40
LB(x×y) = 3.35×2.05 = 6.8675
UB(x×y) = 3.45×2.15 = 7.4175
LB(x÷y) = 3.35÷2.15 = 1.558
UB(x÷y) = 3.45÷2.05 = 1.683

Assessment Criteria

  • Got it: Applies all four operations bounds correctly; explains reasoning for subtraction/division
  • Getting there: Addition/multiplication correct; subtraction/division rules reversed; sign confusion
  • Not yet: No bounds concept; uses rounded values instead of bounds; wrong inequality direction

Lesson 2: Bounds of Compound Measures

Duration: 50 minutes

Starter Activity (5 minutes)

Speed Bounds Intuition

Distance = 100m (nearest m), Time = 12.0s (1 dp). Is speed definitely > 8 m/s? < 9 m/s?

Main Content (35 minutes)

Teaching Notes:
Speed = Distance / Time
LB(speed) = LB(distance) / UB(time) (smallest distance, largest time → slowest)
UB(speed) = UB(distance) / LB(time) (largest distance, smallest time → fastest)

Density = Mass / Volume
LB(density) = LB(mass) / UB(volume)
UB(density) = UB(mass) / LB(volume)

Pressure = Force / Area
LB(pressure) = LB(force) / UB(area)
UB(pressure) = UB(force) / LB(area)

Multiplication types: Distance = Speed × Time
LB(distance) = LB(speed) × LB(time)
UB(distance) = UB(speed) × UB(time)
Worked Example 1: Speed Bounds

Car travels 120 miles (nearest 10 miles) in 2.5 hours (1 dp).
Distance: LB = 115, UB = 125
Time: LB = 2.45, UB = 2.55

Speed LB = 115 / 2.55 = 45.098... mph
Speed UB = 125 / 2.45 = 51.020... mph
Speed between 45.1 and 51.0 mph (to 1 dp)
Can we say speed = 48 mph (1 dp)? Both bounds round to 45 and 51... no common 1 dp.

Worked Example 2: Density Bounds

Mass = 500g (nearest 10g). Volume = 45 cm³ (nearest cm³).
Mass: LB = 495, UB = 505
Volume: LB = 44.5, UB = 45.5

Density LB = 495 / 45.5 = 10.879... g/cm³
Density UB = 505 / 44.5 = 11.348... g/cm³
Density between 10.9 and 11.3 g/cm³ (1 dp)

Worked Example 3: Distance from Speed/Time

Speed = 60 mph (nearest 10 mph). Time = 1.5 hours (1 dp).
Speed: LB = 55, UB = 65
Time: LB = 1.45, UB = 1.55

Distance LB = 55 × 1.45 = 79.75 miles
Distance UB = 65 × 1.55 = 100.75 miles
Distance between 80 and 101 miles (nearest mile)

Compound Measure Bounds:
Speed = Distance / Time
LB = LB_dist ÷ UB_time, UB = UB_dist ÷ LB_time

Density = Mass / Volume
LB = LB_mass ÷ UB_vol, UB = UB_mass ÷ LB_vol

Pressure = Force / Area
LB = LB_force ÷ UB_area, UB = UB_force ÷ LB_area

Distance = Speed × Time (multiplication rules)
Area = Force / Pressure (division rules)
Volume = Mass / Density (division rules)

Common Misconception

For speed, use LB distance and LB time for LB speed

LB speed = SLOWEST possible = shortest distance / longest time = LB_dist / UB_time.

Differentiation

Support:
Formula triangles with LB/UB labels. "Slowest = min distance, max time" mnemonic. Colour-code LB (blue) UB (red).
Stretch:Bounds with standard form. Bounds of acceleration (v-u)/t. Bounds of area/volume from length bounds. Multi-step: speed from distance/time, then distance from speed/time.

Plenary (5 minutes)

Speed Check

d = 45m (nearest m), t = 5.0s (1 dp).
LB speed = 44.5/5.05 = 8.81 m/s
UB speed = 45.5/4.95 = 9.19 m/s
Speed = 9 m/s (nearest integer)? Both bounds round to 9? LB=8.81→9, UB=9.19→9. Yes!

Assessment Criteria

  • Got it: Correctly applies bounds to all compound measures; identifies min/max combinations
  • Getting there: Knows formulae; sometimes reverses LB/UB for division; calculation errors
  • Not yet: Uses rounded values; no min/max reasoning; confuses multiplication/division rules

Lesson 3: Degree of Accuracy and Problem Solving

Duration: 50 minutes

Starter Activity (5 minutes)

Appropriate Accuracy

LB = 4.123, UB = 4.127. What accuracy can we give? Both round to 4.12 (2 dp) or 4.1 (1 dp). Best = 2 dp.

Main Content (35 minutes)

Teaching Notes:
Appropriate Degree of Accuracy: Find LB and UB. Round both to same decimal places/significant figures. If they round to SAME value, that's the appropriate accuracy.

Example: LB = 12.345, UB = 12.355
1 dp: 12.3 vs 12.4 → DIFFERENT → not 1 dp
2 dp: 12.35 vs 12.36 → DIFFERENT → not 2 dp
3 dp: 12.345 vs 12.355 → DIFFERENT → not 3 dp
Wait... 12.345 rounds to 12.345 (3 dp), 12.355 rounds to 12.355. Different.
Actually: need to check where they FIRST agree.
Better example: LB = 7.212, UB = 7.218
3 dp: 7.212, 7.218 → different
2 dp: 7.21, 7.22 → different
1 dp: 7.2, 7.2 → SAME! Answer: 7.2 (1 dp)

Maximum/Minimum Problems: "Maximum possible area" = UB × UB. "Minimum possible perimeter" = 2(LB+LB).
Worked Example 1: Degree of Accuracy

Rectangle: length = 12.4 cm (1 dp), width = 8.7 cm (1 dp).
LBl = 12.35, UBl = 12.45
LBw = 8.65, UBw = 8.75

Area LB = 12.35 × 8.65 = 106.8275 cm²
Area UB = 12.45 × 8.75 = 108.9375 cm²

1 dp: 106.8 vs 108.9 → different
Integer: 107 vs 109 → different
10s: 110 vs 110 → SAME!
Area = 110 cm² (nearest 10 cm²) or 1.1×10² cm²

Worked Example 2: Max/Min Problems

Field: 50m × 30m (nearest metre).
Max area = 50.5 × 30.5 = 1540.25 m²
Min area = 49.5 × 29.5 = 1460.25 m²
Max perimeter = 2(50.5 + 30.5) = 162 m
Min perimeter = 2(49.5 + 29.5) = 158 m

Worked Example 3: Complex Problem

A cylindrical can: radius = 3.5 cm (1 dp), height = 12.0 cm (1 dp).
Find bounds for volume. V = πr²h
LB: r = 3.45, h = 11.95 → V = π × 3.45² × 11.95 = 447.5... cm³
UB: r = 3.55, h = 12.05 → V = π × 3.55² × 12.05 = 477.2... cm³
Volume between 448 and 477 cm³ (nearest cm³)
Check 2 sf: 450 vs 480 → different. 1 sf: 400 vs 500 → different. Nearest 10: 450 vs 480 → different. Nearest 50? 450 vs 450 → SAME! V = 450 cm³ (nearest 50 cm³)

Appropriate Degree of Accuracy:
1. Find LB and UB of result
2. Round both to 1 dp, 2 dp, 3 dp... until they match
3. That decimal place is the appropriate accuracy

Maximum/Minimum:
Max sum/product: UB + UB, UB × UB
Min sum/product: LB + LB, LB × LB
Max quotient: UB ÷ LB
Min quotient: LB ÷ UB
Max difference: UB - LB
Min difference: LB - UB

Common Misconception

LB = 4.24, UB = 4.26 → answer 4.3 (1 dp) because both round to 4.3? Wait: 4.24→4.2, 4.26→4.3. Different!

Must round BOTH to same accuracy. 4.24→4.2, 4.26→4.3 (1 dp: different). 4.24→4.24, 4.26→4.26 (2 dp: different). Integer: 4 vs 4 (same!). So integer accuracy.

Differentiation

Support:
Step-by-step table: LB | UB | 1dp | 2dp | 3dp... Highlight first matching column. Template for max/min problems.
Stretch:Given answer to appropriate accuracy, find possible original bounds. Bounds with standard form. Optimisation: "largest possible volume given perimeter bounds".

Plenary (5 minutes)

Accuracy Check

LB = 15.24, UB = 15.26 → 2 dp: 15.24, 15.26 (diff). 1 dp: 15.2, 15.3 (diff). Integer: 15, 15 (SAME). Answer: 15
LB = 0.0445, UB = 0.0455 → 3 dp: 0.045, 0.046 (diff). 2 dp: 0.04, 0.05 (diff). 1 sf: 0.04, 0.05 (diff). 0.04 and 0.05... wait. Actually: 0.0445 (2sf=0.045), 0.0455 (2sf=0.046). Need 1sf: 0.04 vs 0.05. Different. So NO common accuracy? Actually bounds method: if no common, state bounds.

Assessment Criteria

  • Got it: Finds appropriate accuracy by matching bounds; solves max/min problems; explains reasoning
  • Getting there: Calculates bounds correctly; finds appropriate accuracy with guidance; max/min OK
  • Not yet: Uses rounded values; cannot find matching accuracy; max/min reversed

Homework Suggestions

  • Bounds calculation worksheet (+, -, ×, ÷, compound measures)
  • "Appropriate degree of accuracy" problems (find LB/UB, match rounding)
  • Max/min area, perimeter, volume, speed problems
  • Past paper questions on bounds (Edexcel/AQA Higher)
