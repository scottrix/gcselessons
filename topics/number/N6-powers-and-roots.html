N6: Powers and Roots

Foundation Higher All Boards

Calculate squares, cubes, higher powers and their roots. Use index notation. Estimate powers and roots. Apply to area, volume, and Pythagoras contexts.

Lesson Overview

Estimated Lessons: 2
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, Eduqas, CCEA

Learning Objectives

  • Calculate squares, cubes, and higher powers (including with calculator)
  • Find square roots and cube roots (exact and approximate)
  • Use index notation (e.g., 5³, 2⁴)
  • Estimate powers and roots between known values
  • Apply powers and roots to geometry problems (area, volume, Pythagoras)

Prerequisites

  • Multiplication tables up to 12 × 12
  • Understanding of multiplication as repeated addition
  • Area of rectangle, volume of cuboid
  • Calculator use for x², x³, √, ³√ buttons

Materials & Equipment

  • Scientific calculator (x², x³, √, ³√, x^y)
  • Square and cube number reference cards
  • Multilink cubes for volume models
  • Number lines for root estimation

Lesson 1: Squares, Cubes and Higher Powers

Duration: 50 minutes

Starter Activity (5 minutes)

Spot the Pattern

1, 4, 9, 16, 25, 36, ... What's next? What are these numbers?

Main Content (35 minutes)

Teaching Notes:
Square Numbers: n² = n × n. Geometric: square with side n.
First 15 squares: 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, 169, 196, 225

Cube Numbers: n³ = n × n × n. Geometric: cube with side n.
First 10 cubes: 1, 8, 27, 64, 125, 216, 343, 512, 729, 1000

Higher Powers: n⁴ = n×n×n×n, n⁵, etc. Use calculator x^y button.

Index Notation: 5³ means base 5, index 3 = 5×5×5 = 125.
(-3)² = 9, -3² = -9 (indices before negative)
Worked Example 1: Evaluating Powers

Calculate: (a) 7² (b) 4³ (c) 2⁵ (d) (-4)² (e) -4² (f) 1.5²

(a) 7² = 7×7 = 49
(b) 4³ = 4×4×4 = 64
(c) 2⁵ = 2×2×2×2×2 = 32
(d) (-4)² = (-4)×(-4) = 16
(e) -4² = -(4×4) = -16
(f) 1.5² = 1.5×1.5 = 2.25

Worked Example 2: Geometry Applications

Square area = 64 cm². Find side length.
Side = √64 = 8 cm

Cube volume = 125 cm³. Find side length.
Side = ³√125 = 5 cm

Right triangle: legs 6cm, 8cm. Hypotenuse?
h² = 6² + 8² = 36 + 64 = 100
h = √100 = 10 cm

Key Powers to Know:
Squares: 1²=1, 2²=4, 3²=9, 4²=16, 5²=25, 6²=36, 7²=49, 8²=64, 9²=81, 10²=100, 11²=121, 12²=144, 13²=169, 14²=196, 15²=225
Cubes: 1³=1, 2³=8, 3³=27, 4³=64, 5³=125, 6³=216, 7³=343, 8³=512, 9³=729, 10³=1000

Powers of 2: 2¹=2, 2²=4, 2³=8, 2⁴=16, 2⁵=32, 2⁶=64, 2⁷=128, 2⁸=256, 2⁹=512, 2¹⁰=1024
Powers of 10: 10¹=10, 10²=100, 10³=1000, 10⁴=10000, 10⁵=100000

Common Misconception

5² = 10 (5×2)

5² = 5×5 = 25. The index means multiply the base by ITSELF that many times.

Differentiation

Support:
Multiplication grid for squares. Physical cubes for volume. Calculator practice with x², x³ buttons.
Stretch:
Powers of negatives: (-2)ⁿ pattern. Large powers with calculator (2²⁰). Sum of squares investigations.

Plenary (5 minutes)

Mental Maths

11² = 121, 12² = 144, 13² = 169, 14² = 196, 15² = 225
5³ = 125, 6³ = 216, 7³ = 343
√144 = 12, ³√216 = 6

Assessment Criteria

  • Got it: Recalls squares/cubes to 15/10; evaluates powers with negatives/decimals; applies to geometry
  • Getting there: Knows squares to 12²; uses calculator for cubes; sign errors with negatives
  • Not yet: Confuses n² with 2n; no recall of square numbers; calculator dependency

Lesson 2: Roots and Estimation

Duration: 50 minutes

Starter Activity (5 minutes)

Inverse Operations

If 7² = 49, what is √49? If 4³ = 64, what is ³√64?

Main Content (35 minutes)

Teaching Notes:
Square Root: √x = the positive number that squares to x. √25 = 5 (not ±5).
Cube Root: ³√x = number that cubes to x. ³√27 = 3, ³√(-27) = -3.

Estimating Roots: Sandwich between known squares/cubes.
√50: 7²=49, 8²=64 → √50 is between 7 and 8, closer to 7 (≈7.07)
³√50: 3³=27, 4³=64 → ³√50 is between 3 and 4, closer to 4 (≈3.68)

Calculator: √ button, ³√ button (often SHIFT + x³), x^y for other roots (x^(1/n)).
Worked Example 1: Exact Roots

Evaluate: (a) √169 (b) ³√343 (c) √0.25 (d) ³√0.001

(a) 13² = 169 → √169 = 13
(b) 7³ = 343 → ³√343 = 7
(c) 0.5² = 0.25 → √0.25 = 0.5
(d) 0.1³ = 0.001 → ³√0.001 = 0.1

Worked Example 2: Estimating Roots

Estimate √30 to 1 decimal place.

5² = 25, 6² = 36 → √30 is between 5 and 6
30 is 5/11 of the way from 25 to 36
Try 5.5: 5.5² = 30.25 (too high)
Try 5.4: 5.4² = 29.16 (too low)
Try 5.48: 5.48² = 30.0304 (very close)
Answer: √30 ≈ 5.5 (to 1dp) or 5.48 (to 2dp)

Worked Example 3: Calculator Skills

Find √17.64 and ³√15.625 using calculator.

√17.64 = 4.2 (exact, since 4.2² = 17.64)
³√15.625 = 2.5 (exact, since 2.5³ = 15.625)

For √50: √50 = 7.071067... → 7.07 (2dp)
For ³√50: 50^(1/3) = 3.68403... → 3.68 (2dp)

Root Notation:
√x = x^(1/2) — square root
³√x = x^(1/3) — cube root
ⁿ√x = x^(1/n) — nth root

Properties:
√(ab) = √a × √b
√(a/b) = √a / √b
(√a)² = a (for a ≥ 0)
³√(-a) = -³√a

Common Misconception

√25 = ±5

√25 = 5 (principal/positive root). The equation x² = 25 has solutions x = ±5.

Differentiation

Support:
Number line with squares marked. Guess-check-improve method. Calculator for all but simple roots.
Stretch:
Prove √2 is irrational. Estimate √n to 3dp without calculator. Nested roots: √(2+√3). Solve x² = 50 by iteration.

Plenary (5 minutes)

Order These

√10, ³√10, 10^0.5, 10^(1/3), 3.1, 3.2
Answer: ³√10 (=10^(1/3)) ≈ 2.15, √10 (=10^0.5) ≈ 3.16
Order: ³√10 < √10 < 3.1 < 3.2

Assessment Criteria

  • Got it: Finds exact roots; estimates between integers; uses calculator efficiently; knows √ gives positive
  • Getting there: Finds perfect square/cube roots; estimates roughly; calculator syntax issues
  • Not yet: Confuses root with division; √25 = 5±; cannot estimate

Homework Suggestions

  • Squares, cubes, roots mixed practice (mental and calculator)
  • Estimation worksheet: √n and ³√n to 1dp and 2dp
  • Geometry problems: find missing sides using Pythagoras
  • Learn squares to 15² and cubes to 10³ by heart
  • CorbettMaths "Powers and Roots" practice
