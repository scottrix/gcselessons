N15: Rounding and Error Intervals

Foundation Higher All Boards

Round to decimal places and significant figures. Write error intervals for rounded numbers. Understand truncation vs rounding. Use inequality notation for bounds.

Lesson Overview

Estimated Lessons: 2
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, Eduqas, CCEA

Learning Objectives

  • Round numbers to given decimal places (dp) and significant figures (sf)
  • Write error intervals using inequality notation: a ≤ x < b
  • Find lower and upper bounds for rounded values
  • Distinguish between rounding and truncation
  • Apply rounding/error intervals to measurement contexts

Prerequisites

  • Place value (decimal places, significant figures)
  • Inequality symbols (<, >, ≤, ≥)
  • Number line understanding
  • Rounding to nearest 10, 100, 1000 (N1)

Materials & Equipment

  • Number lines (for visualising rounding)
  • Rounding rule cards (dp vs sf)
  • Error interval templates
  • Measuring tools (rulers, scales) for practical context

Lesson 1: Rounding to dp and sf

Duration: 50 minutes

Starter Activity (5 minutes)

Round to Nearest...

Round 47.638 to: nearest 10, nearest whole, 1 dp, 2 dp, 1 sf, 2 sf, 3 sf

Main Content (35 minutes)

Teaching Notes:
Decimal Places (dp): Count digits AFTER decimal point.
Round to 2 dp: 3.14159 → 3.14 (3rd dp is 1 < 5)
Round to 3 dp: 3.14159 → 3.142 (4th dp is 5 ≥ 5)

Significant Figures (sf): Count from FIRST non-zero digit.
Round to 3 sf: 0.004567 → 0.00457 (4th sf is 7 ≥ 5)
Round to 2 sf: 4567 → 4600 (3rd sf is 6 ≥ 5)
Round to 1 sf: 0.0504 → 0.05 (2nd sf is 0 < 5)

Key Difference: dp counts from decimal point. sf counts from first non-zero digit.
Trailing zeros after decimal COUNT for sf: 2.50 has 3 sf. 2500 has 2 sf (unless decimal shown: 2500.)
Worked Example 1: Rounding to dp

Round 27.4368 to: (a) 1 dp (b) 2 dp (c) 3 dp

(a) 1 dp: 27.4 (next digit 3 < 5)
(b) 2 dp: 27.44 (next digit 6 ≥ 5, round up 3→4)
(c) 3 dp: 27.437 (next digit 8 ≥ 5, round up 6→7)

Worked Example 2: Rounding to sf

Round to 2 significant figures:
(a) 347 → 350 (3rd digit 7 ≥ 5)
(b) 0.00483 → 0.0048 (3rd sf 3 < 5)
(c) 5.06 → 5.1 (3rd sf 6 ≥ 5)
(d) 0.0504 → 0.050 (3rd sf 4 < 5, keep trailing zero for 2 sf)
(e) 999 → 1000 (write as 1.0×10³ or 1000 with understanding)

Worked Example 3: Truncation

Truncate 3.14159 to 3 dp: 3.141 (chop off, don't round)
Truncate 4.678 to 2 sf: 4.6 (chop off after 2nd sf)

Rounding: 3.14159 to 3 dp = 3.142
Truncation: 3.14159 to 3 dp = 3.141

Rounding Rules:
• Identify cut-off digit (last one to keep)
• Look at NEXT digit
• Next digit 0-4: keep cut-off digit (round down)
• Next digit 5-9: increase cut-off digit by 1 (round up)

Decimal Places: Count from decimal point →
Significant Figures: Count from first non-zero digit →

Truncation: Simply cut off after required digits (no rounding)

Common Misconception

0.0045 to 1 sf = 0.005 (correct) but to 2 sf = 0.0045 (incorrect - should be 0.0045)

0.0045 to 2 sf: first non-zero is 4 (1st sf), 5 is 2nd sf. No more digits, so 0.0045 is already 2 sf. To 1 sf: look at 2nd sf (5) → round up 4→5 = 0.005.

Differentiation

Support:
Colour-code: decimal point red, first non-zero green. "5 or more, raise the score; 4 or less, let it rest." Number line visual.
Stretch:
Round to n sf where n varies. Standard form rounding: 4.56×10⁴ to 2 sf. Truncation vs rounding difference analysis.

Plenary (5 minutes)

Quick Round

2.746 to 2 dp = 2.75
2.746 to 2 sf = 2.7
0.0473 to 2 dp = 0.05
0.0473 to 2 sf = 0.047
4500 to 2 sf = 4500 (ambiguous) or 4.5×10³

Assessment Criteria

  • Got it: Rounds to any dp/sf correctly; distinguishes dp vs sf; handles truncation
  • Getting there: dp rounding secure; sf with leading zeros tricky; truncation confused with rounding
  • Not yet: Counts from wrong place; rounds 5 down; trailing zero confusion

Lesson 2: Error Intervals and Bounds

Duration: 50 minutes

Starter Activity (5 minutes)

What Could It Be?

Number rounded to nearest 10 is 50. What values could it have been? 45 to 54.999... = 45 ≤ x < 55

Main Content (35 minutes)

Teaching Notes:
Error Interval: Range of values that round to a given value.
If x rounded to 1 dp = 3.4, then 3.35 ≤ x < 3.45
Lower bound = 3.35, Upper bound = 3.45

General Rule: Half the rounding unit below and above.
Rounded to nearest 10: ±5 → 45 ≤ x < 55
Rounded to 1 dp: ±0.05 → 3.35 ≤ x < 3.45
Rounded to 2 sf: depends on value. 450 (2 sf) → 445 ≤ x < 455
0.045 (2 sf) → 0.0445 ≤ x < 0.0455

Truncation Bounds: Different!
Truncated to 1 dp = 3.4 means 3.4 ≤ x < 3.5
Lower bound = 3.4, Upper bound = 3.5
Worked Example 1: Error Intervals (Rounding)

Write error interval for x rounded to given degree:
(a) 7.3 (1 dp): 7.25 ≤ x < 7.35
(b) 0.045 (2 sf): 0.0445 ≤ x < 0.0455
(c) 4500 (2 sf): 4450 ≤ x < 4550
(d) 100 (1 sf): 95 ≤ x < 150
(e) 0.0080 (2 dp): 0.00795 ≤ x < 0.00805

Worked Example 2: Error Intervals (Truncation)

y truncated to 2 dp = 3.14. Error interval?
Truncation means chopped, not rounded.
Smallest: 3.14 exactly
Largest: just below 3.15
Interval: 3.14 ≤ y < 3.15

Worked Example 3: Measurement Context

Length measured as 15 cm (nearest cm). Error interval?
Rounding unit = 1 cm. Half = 0.5 cm
14.5 ≤ length < 15.5 cm

Mass = 2.4 kg (1 dp). 2.35 ≤ mass < 2.45 kg
Time = 40 s (nearest 10 s). 35 ≤ time < 45 s

Error Interval for Rounded Value:
Rounding unit = place value of last digit
Half unit = rounding unit / 2
Lower bound = rounded value - half unit
Upper bound = rounded value + half unit
Inequality: lower ≤ x < upper

Truncation Error Interval:
Lower bound = truncated value
Upper bound = truncated value + rounding unit
Inequality: lower ≤ x < upper

Examples:
Rounded to 1 dp (0.1): ±0.05
Rounded to 2 sf: depends on magnitude

Common Misconception

Upper bound is the largest possible value (e.g., 3.44 for 3.4 to 1 dp)

Upper bound is the CUT-OFF value: 3.45. The actual value is strictly LESS than upper bound. x < 3.45, not x ≤ 3.44.

Differentiation

Support:
Number line with bounds marked. "Halfway between" concept. Fill-in templates: ___ ≤ x < ___.
Stretch:
Error intervals for standard form. Truncation vs rounding comparison. "Write the error interval for x if x² rounded to 1 sf = 20".

Plenary (5 minutes)

Bounds Check

x = 6.3 (1 dp) → 6.25 ≤ x < 6.35
y = 6.3 (truncated 1 dp) → 6.3 ≤ y < 6.4
z = 400 (1 sf) → 350 ≤ z < 450
w = 400 (truncated 1 sf) → 400 ≤ w < 500

Assessment Criteria

  • Got it: Writes error intervals for rounding and truncation; uses correct inequality notation; identifies bounds
  • Getting there: Rounding error intervals OK; truncation intervals confused; inequality direction errors
  • Not yet: No concept of range; uses ≤ for upper bound; rounding unit wrong

  • Error interval worksheet: write interval for given rounded values
  • Measurement task: measure 5 objects, record with error intervals
