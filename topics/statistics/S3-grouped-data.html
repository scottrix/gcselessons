S3: Grouped Data

Higher All Boards

Work with grouped continuous data: estimate mean, median, mode; understand frequency density; construct and interpret histograms with unequal class widths; work with modal class and median class.

Lesson Overview

Estimated Lessons: 3
Tier: Higher only
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, Eduqas, CCEA

Learning Objectives

  • Estimate the mean from grouped frequency tables using midpoints
  • Identify the modal class and median class
  • Estimate the median using linear interpolation (or cumulative frequency graph)
  • Calculate and use frequency density for histograms with unequal class widths
  • Estimate frequencies and proportions from histograms
  • Understand the limitations of estimates from grouped data

Prerequisites

  • Understanding of mean, median, mode from raw data
  • Frequency tables and grouped data notation (e.g. 10 ≤ x < 20)
  • Calculating midpoints of intervals
  • Cumulative frequency graphs (from S2)
  • Area of rectangles (base × height)

Materials & Equipment

  • Grouped frequency tables (printed)
  • Graph paper / squared paper
  • Calculators
  • Rulers for interpolation
  • Pre-drawn histogram axes

Lesson 1: Estimating Mean, Modal Class, Median Class

Duration: 50 minutes

Starter Activity (5 minutes)

Why Estimate?

Show raw data: 50 reaction times. Then show grouped version. "We lost the exact values. Can we still find the mean? How?" Discuss: use midpoint as representative value.

Main Content (35 minutes)

Teaching Notes:
Estimated mean: Σ (midpoint × frequency) / Σ frequency
Midpoint = (lower bound + upper bound) / 2. For class 10 ≤ x < 20, midpoint = 15.
Modal class: The class with the highest frequency. Not "the mode" — we don't know the exact mode, only which class it lies in.
Median class: The class containing the median. Find median position = (n+1)/2 (or n/2 for grouped). Locate which class this falls into using cumulative frequencies.

Key point: These are estimates. The true mean/median could be anywhere within the class. We assume uniform distribution within each class.
Worked Example: Estimated Mean

Height (cm) | Frequency | Midpoint (x) | f×x
140 ≤ h < 150 | 8 | 145 | 1160
150 ≤ h < 160 | 15 | 155 | 2325
160 ≤ h < 170 | 22 | 165 | 3630
170 ≤ h < 180 | 18 | 175 | 3150
180 ≤ h < 200 | 7 | 190 | 1330
Total | 70 | | 11595
Estimated mean = 11595 / 70 = 165.6 cm

Worked Example: Median Class

Same data. Total n = 70. Median position = 35.5th value (or 35th).
Cumulative: 8, 23, 45, 63, 70.
35th value falls in 3rd class (cumulative 23 to 45).
Median class: 160 ≤ h < 170.
Modal class: 160 ≤ h < 170 (highest frequency 22).

Estimated mean = Σ (midpoint × frequency) / Σ frequency
Modal class = class with highest frequency
Median class = class containing the (n/2)th value (using cumulative frequency)

Common Misconception

"The modal class is the mode."

The modal class is the interval containing the mode. The exact mode is unknown. We say "modal class is 160–170" not "mode is 165".

Differentiation

Support:
Provide table template with columns for class, frequency, midpoint, f×x. Use simple numbers. Colour-code: midpoint column one colour, f×x another.
Stretch:
Given estimated mean and all but one frequency, find the missing frequency. Discuss: "When is the estimated mean exactly the true mean? When is it most inaccurate?" (Symmetric vs skewed distributions).

Plenary (5 minutes)

True Mean vs Estimated

Give a small raw dataset. Students calculate true mean. Then group it, estimate mean. Compare. "Why different? When would they be equal?"

Assessment Criteria

  • Got it: Calculates estimated mean correctly, identifies modal/median class, explains they are estimates.
  • Getting there: Calculates mean but uses wrong midpoints (e.g. lower bound) or forgets to divide by total frequency.
  • Not yet: Confuses modal class with mode, or cannot find median class. Reteach cumulative frequency.

Lesson 2: Frequency Density and Histograms (Unequal Widths)

Duration: 50 minutes

Starter Activity (5 minutes)

Area Check

Draw a rectangle: width 10, height 5. Area = 50. "If this represents frequency 50, what if width changes to 20? Height must be 2.5 to keep area 50." Frequency density = frequency / width.

Main Content (35 minutes)

Teaching Notes:
Frequency density: Frequency per unit of class width. FD = frequency / class width.
In a histogram, area of bar = frequency. Height = frequency density.
When class widths are equal, FD ∝ frequency, so height ∝ frequency — can just use frequency as height.
When class widths differ, MUST use frequency density for height, or areas will be wrong.

Steps to draw histogram with unequal widths:
1. Add columns: class width, frequency density (freq/width)
2. Draw axes: x-axis = variable (continuous scale), y-axis = frequency density
3. Draw bars: width = class width, height = frequency density, no gaps
4. Label axes, title

Estimating from histogram: Frequency in a range = sum of areas of bars (or parts of bars) covering that range.
Worked Example: Frequency Density Table

Time (s) | Freq | Width | Freq Density
0 ≤ t < 10 | 20 | 10 | 2.0
10 ≤ t < 20 | 30 | 10 | 3.0
20 ≤ t < 30 | 25 | 10 | 2.5
30 ≤ t < 50 | 15 | 20 | 0.75
50 ≤ t < 60 | 10 | 10 | 1.0
Check: Area = Σ (FD × width) = 20+30+25+15+10 = 100 = total frequency ✓

Worked Example: Estimating from Histogram

"Estimate number of people with time between 15 and 35 seconds."
15–20: part of 2nd bar. Width = 5. FD = 3.0. Area = 5 × 3.0 = 15.
20–30: whole 3rd bar. Freq = 25.
30–35: part of 4th bar. Width = 5. FD = 0.75. Area = 5 × 0.75 = 3.75.
Total ≈ 15 + 25 + 3.75 = 43.75 ≈ 44 people.

Frequency density = Frequency ÷ Class width
Frequency = Frequency density × Class width
Area of bar = Frequency

Common Misconception

"Frequency density is just another name for frequency."

Frequency density = frequency per unit width. It allows comparison of bars of different widths. Units: e.g. "people per cm" or "frequency per second".

Differentiation

Support:
Provide table with width and FD columns. Pre-calculate class widths. Use grid where 1 square = 1 unit area.
Stretch:
Given a histogram with some bars missing, use total frequency to find missing frequencies. Work backwards: given histogram, find original grouped frequency table.

Plenary (5 minutes)

Spot the Error

Show a histogram drawn with frequency as height for unequal widths. "What's wrong? Which bar is too tall? Redraw correctly."

Assessment Criteria

  • Got it: Calculates FD correctly, draws accurate histogram, estimates frequencies from partial bars.
  • Getting there: Calculates FD but draws bars with height = frequency, or cannot estimate partial bars.
  • Not yet: Does not understand why frequency density is needed. Reteach area principle with physical rectangles.

Lesson 3: Linear Interpolation for Median (and Percentiles)

Duration: 50 minutes

Starter Activity (5 minutes)

Proportional Thinking

"In a class of 20 students, the 10th person is 160 cm, the 11th is 162 cm. Estimate the median height." (161 cm — halfway between). "What if 10th is 160, 11th is 170?" Discuss linear assumption.

Main Content (35 minutes)

Teaching Notes:
Linear interpolation: Assume values are evenly distributed within the median class. Use proportion to estimate median.
Formula: Median = L + [(n/2 − CFb) / f] × w
Where: L = lower boundary of median class, n = total frequency, CFb = cumulative frequency before median class, f = frequency of median class, w = class width.

Same logic for any percentile: Pth percentile = L + [(Pn/100 − CFb) / f] × w
For Q1: P=25. For Q3: P=75. For D1 (1st decile): P=10.

Alternative: Use cumulative frequency graph (from S2). Interpolation gives same result if distribution is uniform within class.
Worked Example: Linear Interpolation

Same height data. Median class: 160 ≤ h < 170.
L = 160, n = 70, CFb = 23, f = 22, w = 10.
Median = 160 + [(35 − 23) / 22] × 10
= 160 + (12/22) × 10
= 160 + 5.45
= 165.45 cm
(Compare to estimated mean 165.6 — close, slightly negatively skewed)

Worked Example: Q1 and Q3

Q1 position = 70/4 = 17.5th value. Falls in 2nd class (150–160, CFb=8, f=15, w=10).
Q1 = 150 + [(17.5 − 8) / 15] × 10 = 150 + (9.5/15)×10 = 150 + 6.33 = 156.33 cm
Q3 position = 3×70/4 = 52.5th value. Falls in 4th class (170–180, CFb=45, f=18, w=10).
Q3 = 170 + [(52.5 − 45) / 18] × 10 = 170 + (7.5/18)×10 = 170 + 4.17 = 174.17 cm
IQR = 174.17 − 156.33 = 17.84 cm

Linear interpolation for median:
Median = L + [(n/2 − CFb) / f] × w

General percentile P:
Value = L + [(Pn/100 − CFb) / f] × w

Common Misconception

"Use the midpoint of the median class as the median."

Midpoint assumes median is exactly in the middle of the class. Interpolation uses the actual position within the class based on cumulative frequency.

Differentiation

Support:
Use the cumulative frequency graph method instead (read off median at n/2). Provide interpolation formula as fill-in template. Practice with simpler numbers (f divides n/2 − CFb).
Stretch:
Derive the interpolation formula from similar triangles on a cumulative frequency graph. Estimate 10th and 90th percentiles. Discuss: when does interpolation over/underestimate? (When distribution within class is not uniform).

Plenary (5 minutes)

Compare Methods

Students find median by: (a) interpolation formula, (b) cumulative frequency graph. Compare answers. "Why might they differ slightly?" (Graph reading accuracy vs formula precision; uniform assumption).

Assessment Criteria

  • Got it: Applies interpolation formula correctly for median, quartiles, percentiles. Interprets result in context.
  • Getting there: Substitutes correctly but makes arithmetic errors, or confuses CFb with CF of median class.
  • Not yet: Uses midpoint instead of interpolation. Reteach with visual: similar triangles on cumulative frequency graph.

Homework Suggestions

  • Given a grouped frequency table, calculate estimated mean, identify modal/median class, estimate median via interpolation.
  • Draw a histogram with unequal class widths from a frequency table. Estimate frequency in a given range.
  • Compare estimated mean vs interpolated median for skewed data. Explain the difference.
  • Past paper questions on grouped data (AQA, Edexcel, OCR).
