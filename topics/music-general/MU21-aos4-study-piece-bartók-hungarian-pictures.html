Main Content (35 minutes)

Key Fact: Movement 1 (Evening in the Village) alternates between slow modal folk melody and lively dance — depicts a peaceful evening scene in rural Hungary.
Key Fact: Movement 2 (The Bear Dance) uses heavy, irregular rhythm and rough string techniques to depict a clumsy bear — humour through musical characterisation.
Key Fact: Movement 4 (Slightly Tipsy) depicts drunkenness through unstable rhythm, sliding pitches and wavering dynamics — musical word painting.
Key Fact: Movement 5 (Swineherd's Dance) is fast and rhythmic with virtuosic string writing — folk dance energy translated into orchestral brilliance.
Music Exam Tips: Know all FOUR movements (NOT Movement 3). Analyse folk elements in each. Explain musical word painting. Identify string techniques. Use elements vocabulary precisely.

Extended Answer

Extended question: Full-Mark Response Critically appraise two movements from Bartók's Hungarian Pictures. Analyse how Bartók uses musical elements to create character and depict the scene in each movement. <div class="

A grade 9 response will: identify folk-derived elements in each movement; explain how specific musical elements create the depicted character; analyse Bartók's orchestration and string techniques; show understanding of polymodal harmony; compare movements; use precise AQA vocabulary. Mark scheme: AO3 (analyse and evaluate) + AO4 (knowledge and understanding) = total marks for listening; AO1 (perform) + AO2 (compose) for coursework components

Exam Tips: Always use PRECISE musical vocabulary — not vague descriptions like it sounds nice | Reference SPECIFIC musical elements when analysing any piece | For listening questions: identify elements FIRST, then explain their effect | For study pieces: know the context, structure and key features in detail | For performing: focus on accuracy, expression and interpretation | For composing: show development of ideas, not just repetition
Common Errors: Watch Out! Students often make mistakes here. Wrong: For Hungarian Pictures you just need to describe what each movement sounds like. Correct: The exam requires CRITICAL APPRAISAL using musical vocabulary: identify specific elements (modal melody, irregular metre, polymodal harmony, string techniques), explain HOW they create the depicted scene, and analyse Bartók's transformation of folk material. Description alone is insufficient.
