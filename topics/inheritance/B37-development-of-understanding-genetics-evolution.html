📝 Mark Scheme Guidance

How examiners mark B37: Read the command word carefully — State = one word/phrase (1 mark), Describe = pattern or detail (2 marks), Explain = reason with "because" (2–3 marks), Compare = similarities AND differences, Evaluate = both sides + conclusion. Method marks are awarded for correct working even if the final answer is wrong. Always show your working — unexplained answers score zero for AO2.

Success on B37 questions: Underline the command word, count the marks (one mark per point expected), and answer in the format the command word demands.
