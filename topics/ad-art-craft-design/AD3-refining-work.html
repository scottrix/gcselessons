AD3: Refining Work & Portfolio Development

Foundation Higher All Boards

Learn to critically select, refine, and present your best work for assessment. Develop editing skills, understand portfolio requirements, and create a coherent body of work that demonstrates your creative journey.

Lesson Overview

Estimated Lessons: 4
Tier: Foundation and Higher
Duration: 60 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, CCEA, WJEC
Practical: Yes

Learning Objectives

  • Apply critical selection criteria to own work
  • Refine pieces through reworking, cropping, re-presenting
  • Understand portfolio requirements for chosen specification
  • Create coherent narrative through sequencing and annotation
  • Prepare work for digital submission/photography

Prerequisites

  • Substantial body of work from AD1-AD2 investigations (15+ hours)
  • Experience with photography/scanning artwork
  • Basic digital editing (cropping, levels, colour correction)

Materials & Equipment

  • Selection: Printed thumbnails of all work (contact sheets), selection criteria cards, highlighters, sticky tabs
  • Refining: All media from AD1, tracing paper, lightbox/window, cutting mat, craft knife, mounting board, spray mount
  • Documentation: DSLR/phone camera, tripod, softbox/even lighting, grey card, laptop with editing software (Photoshop/GIMP/Photos)
  • Presentation: Portfolio case/folder, mounting squares, acetate sleeves, labels, USB/cloud storage
  • Space: Wall space for layout review, photography station (plain background, controlled light), clean flat surfaces
  • Safety: Craft knife safety, spray mount ventilation, screen time breaks, safe file backup

Lesson 1: Critical Selection

Duration: 60 minutes

Warm-up (10 minutes)

Rapid Ranking

Print all work as thumbnails (contact sheet). In 5 minutes: circle top 10, cross bottom 10, star 5 "maybe". No overthinking — gut response.

Skill Development (35 minutes)

Teaching Notes:
Structured selection process:
  • Assessment Objectives Mapping: For each specification (AO1 Develop, AO2 Refine, AO3 Record, AO4 Present), which pieces evidence which AO?
  • Selection Criteria: Technical competence, idea development, risk-taking, personal engagement, resolution, relevance to enquiry.
  • Red Flags: Unfinished work (unless process evidence), derivative copies, repetitive similar pieces, poor documentation.
  • Gap Analysis: Which AOs are weak? Plan targeted work to address gaps.

Required Practical: Selection Matrix

Create A3 matrix: rows = selected works (15-20), columns = AO1, AO2, AO3, AO4, Technical Quality, Personal Investment. Score each 1-5. Identify top 10 for portfolio. Annotate: "Keep because...", "Refine by...", "Replace with..."

Common Misconception

"More work = better portfolio"

Examiners value QUALITY and COHERENCE over quantity. 15 resolved, well-documented pieces beat 40 repetitive sketches. Edit ruthlessly.

Differentiation

Support: Provide pre-filled matrix with example scores. Work 1:1 to discuss each piece. Limit to selecting 8 pieces.
Stretch: Write 200-word curatorial statement explaining selection rationale. Design portfolio sequence for maximum narrative impact.

Creative Work (10 minutes)

Quick Refine

Take one "maybe" piece. Spend 10 minutes improving it: crop, add detail, adjust contrast, extend background. Photograph before/after.

Reflection (5 minutes)

Selection Justification

Verbally justify top 3 choices to partner using AO language. Partner challenges: "Where's the risk?" "How does this show development?"

Assessment Criteria

  • Technical Skill: Accurate self-assessment, identifying technical strengths/weaknesses
  • Creativity: Recognising innovative vs safe work, valuing experimentation
  • Understanding: Clear AO mapping, evidence-based decisions
  • Presentation: Organised matrix, clear annotations, professional contact sheets

Lesson 2: Refining & Reworking

Duration: 60 minutes

Warm-up (10 minutes)

Critique Carousel

Display selected works. Students rotate, leaving one specific refinement suggestion per piece on sticky notes: "Darken shadows here", "Crop to remove distraction", "Unify colour palette".

Skill Development (35 minutes)

Teaching Notes:
Refinement strategies:
  • Physical Reworking: Drawing into prints, collage over painting, digital over physical, bleeding tissue over dry media.
  • Digital Refinement: Levels/curves for contrast, colour balance, cropping for composition, removing distractions, combining elements.
  • Re-presenting: Mounting, sequencing, scale changes (A4→A3), diptych/triptych groupings, book format.
  • Knowing When to Stop: Set time limits. "Good enough" vs perfect. Document stages — process IS assessment evidence.

Required Practical: Refinement Series

Select 3 pieces for refinement. For each: photograph original → apply 2+ refinement strategies → photograph final → annotate changes and why. Time limit: 45 minutes total. Show restraint — refinement ≠ starting over.

Common Misconception

"Refining means making it look 'finished' and perfect"

Refining means IMPROVING communication of your intention. Sometimes leaving raw edges, visible corrections, or unfinished areas IS the refined state if it serves the concept.

Differentiation

Support: Focus on digital refinement only (cropping, levels). Provide refinement checklist. Pair with peer mentor.
Stretch: Create a "failed" piece deliberately, then refine it into something successful. Document the transformation as a case study.

Creative Work (10 minutes)

Micro-Refinement

Choose one small area (5x5cm) of a work. Redraw/rework just that area to higher finish. Tests patience and observation.

Reflection (5 minutes)

Refinement Log

Note: What changed? Why? Did it improve the work? What would you do differently next time?

Assessment Criteria

  • Technical Skill: Control in reworking, digital editing competence
  • Creativity: Inventive refinement methods, not just "neatening"
  • Understanding: Clear rationale for each change, links to intention
  • Presentation: Before/after documentation, professional final images

Lesson 3: Portfolio Structure & Narrative

Duration: 60 minutes

Warm-up (5 minutes)

Storyboard Your Portfolio

Sketch 6-8 thumbnail rectangles representing portfolio sequence. What starts the story? What ends it? Where are the turning points?

Skill Development (25 minutes)

Teaching Notes:
Portfolio architecture:
  • Opening: Strong, accessible work that declares the enquiry. Not necessarily "best" — most communicative.
  • Development: Show journey: experiments → failures → breakthroughs → refinement. Include process pages.
  • Resolution: Final outcomes (2-3) that answer the enquiry. Supported by development work.
  • Annotation Strategy: Minimal but meaningful. "This experiment led to..." not "I used blue paint."
  • Digital vs Physical: Check spec requirements. Digital: file naming, order, format. Physical: mounting, sequence, protection.

Required Practical: Portfolio Mock-Up

Create portfolio sequence (physical or digital): 15-20 selected/refined works in order. Each with 30-word annotation: context, decision, outcome. Photograph/scan entire sequence. Test digital submission format if applicable.

Creative Work (25 minutes)

Sequence Testing

Lay out physical prints or arrange digital files. Walk away, return with fresh eyes. Reorder. Ask peer: "What story do you see?" Adjust until narrative is clear.

Reflection (5 minutes)

Portfolio Pitch

30-second elevator pitch: "This portfolio investigates [theme] through [media], showing development from [start] to [resolution]."

Assessment Criteria

  • Technical Skill: Consistent documentation quality, appropriate formatting
  • Creativity: Inventive sequencing, unexpected juxtapositions that create meaning
  • Understanding: Clear narrative arc, annotations use specialist vocabulary
  • Presentation: Professional standard, specification-compliant, easy to navigate

Lesson 4: Final Preparation & Photography

Duration: 60 minutes

Warm-up (5 minutes)

Spec Check

Review exam board specification checklist: number of pieces, media requirements, digital specs (file size, format, naming), submission deadline.

Skill Development (20 minutes)

Teaching Notes:
Professional documentation:
  • Photography Setup: Even lighting (2x 45°), tripod, square to work, grey card for white balance, no glare, fill frame.
  • 3D Work: Multiple angles, detail shots, scale reference, neutral background.
  • File Management: Naming convention: "AD3_Surname_01_EnquiryTitle.jpg", folders per project, backup x2 (cloud + local).
  • Metadata: Embed copyright, title, description in file properties.

Required Practical: Final Portfolio Photography

Photograph/scan all portfolio pieces to specification standard. Create master folder with correctly named files. Generate contact sheet with thumbnails and file names. Backup to two locations. Complete specification compliance checklist.

Creative Work (25 minutes)

Photography Station Rotation

Students rotate through photography station (10 min each) while others finalise annotations/backups. Teacher supervises lighting/technique.

Reflection (10 minutes)

Final Review

Paired final review against spec checklist. Sign off each other's compliance sheet. Celebrate completion!

Assessment Criteria

  • Technical Skill: Accurate colour, sharp focus, correct exposure, proper file specs
  • Creativity: Portfolio as designed object, not just container
  • Understanding: Meets all specification requirements, professional workflow
  • Presentation: Flawless digital/physical submission, organised, backed up

Homework Suggestions

  • Complete any remaining refinement work identified in lessons
  • Write 500-word reflective statement on the portfolio journey (many specs require this)
  • Create a "behind the scenes" page showing process, failures, decisions for interview/portfolio talk
  • Mock interview: Present portfolio to family member, answer questions
  • Backup everything. Again.
