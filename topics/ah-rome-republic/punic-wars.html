Lesson 2: Source Analysis & Interpretation

Duration: 50 minutes

Starter Activity (5 minutes)

Source Starter / Key Term

Display a short source extract or key term. Students annotate or define in pairs.

Main Content (35 minutes)

Teaching Notes:
Analyse primary and secondary sources relevant to this topic:
  • Identify the nature, origin, and purpose of each source
  • Evaluate utility and reliability for specific enquiries
  • Compare and contrast differing interpretations
  • Practice AO3 source analysis questions

Use the PEE/PEEL structure for extended responses.

Source Analysis Practice

AO3 Focus: Analyse, evaluate and use sources to make judgements

Source A: [Primary Source Extract]

[Relevant ancient text, inscription, or archaeological evidence]

Source B: [Secondary Source / Modern Interpretation]

[Historian's view or modern analysis]

Questions

  1. Utility: How useful is Source A for understanding [specific aspect]? Explain your answer using the source and your knowledge. [6 marks]
  2. Reliability: To what extent can we trust Source B's interpretation? Consider the author's purpose and context. [6 marks]
  3. Comparison: Compare Source A and Source B. How far do they agree about [issue]? [8 marks]

Writing Frame (PEEL)

  • Point: Make a clear judgement
  • Evidence: Quote or reference the source
  • Explain: What does this show? Link to context
  • Link: Connect back to the question
