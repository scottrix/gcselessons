Lesson 2: Core Concepts: letters

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on letters. Check them against the notes below.

Main Content (35 minutes)

Two main types: Formal letters (to officials, businesses, newspapers) and Informal letters (to friends and family). The exam usually requires formal letters.
Salutations: Dear Mr/Mrs/Ms [Surname] - if you know the name Dear Sir/Madam - if you don't know the name To the Editor - for letters to newspapers
Sign-offs: "Yours sincerely" - if you used a name (Dear Mr Smith) "Yours faithfully" - if you used Dear Sir/Madam
Top Tip: In exams, you're almost always asked to write a formal letter. Avoid contractions and slang. Use sophisticated vocabulary appropriately.
Purpose: To express an opinion, agree/disagree with an article, or raise awareness about an issue.
Examiner's Tip: Get the format right straight away. Write your address, skip a line, write the date, then the recipient's address. This sets up your letter correctly and shows you understand the conventions.

Practice (10 minutes)

Q: When should you use "Yours faithfully" versus "Yours sincerely"?

Answer: "Yours faithfully" with Dear Sir/Madam; "Yours sincerely" when using a specific name (Dear Mr Smith).

Lesson 3: Application: letters

Duration: 50 minutes

Starter Activity (5 minutes)

Quick Recall

Recall the key terms: Two main types, Salutations, Sign-offs. Define each in one sentence.

Main Content (35 minutes)

Parent/Teacher Guide: Let your student attempt each question alone first, then compare with the model answer. Award method marks for correct working even if the final answer is wrong.

Q1: When should you use "Yours faithfully" versus "Yours sincerely"?

Answer: "Yours faithfully" with Dear Sir/Madam; "Yours sincerely" when using a specific name (Dear Mr Smith).

Q2: What is the correct order for a formal letter's components?

Answer: Sender's address, date, recipient's address, salutation, content, sign-off, signature.

Q3: Write the opening of a letter to your local council about litter in your area.

Answer: Your opening should include: sender's address, date, council's address, "Dear Sir/Madam", and a clear statement of purpose.

Q4: Why should you avoid contractions in formal letters?

Answer: Contractions are too informal for formal writing. Writing "do not" instead of "don't" maintains a professional, respectful tone.

Plenary (5 minutes)

Error Review

Review any questions answered incorrectly. Identify whether the error was knowledge, method, or reading the question.

Lesson 4: Exam Practice: letters

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Review what these command words require: state (one point), describe (say what happens), explain (say why), compare (both sides), evaluate (judgement).

Main Content (35 minutes)

Exam-Style Question

Attempt a past-paper style question on letters from the exam board past paper finder (see Resources), then mark it against the scheme.

Exam Tips: Always check if formal or informal is required | Set out addresses correctly - they're easy marks | Never use contractions in formal letters | Match your sign-off to your salutation | State your purpose clearly in the first paragraph | Use persuasive techniques appropriate to your purpose | Keep paragraphs focused - one main idea each
Common Errors: Watch Out! Students often use the wrong sign-off. Wrong: "Yours sincerely" after "Dear Sir/Madam" — this is an error that examiners always spot. Correct: "Yours faithfully" with Dear Sir/Madam; "Yours sincerely" with Dear Mr Smith / Dear Dr Jones — use "faithfully" when you don't know the name. Students often use contractions in formal letters. Wrong: "I can't accept this. It's not fair and I don't think you should've done it." Correct: Write contractions in full — "I cannot accept this. It is not fair, and I do not believe you should have done it." Formal letters demand full forms throughout. Students often omit addresses and date.
