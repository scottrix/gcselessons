Lesson 2: Core Concepts: charts &amp; diagrams

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on charts &amp; diagrams. Check them against the notes below.

Main Content (35 minutes)

Key Fact: A pictogram uses symbols or pictures to represent data; each symbol represents a fixed quantity stated in the key.
Key Fact: In a pie chart, the angle of each sector is proportional to the frequency it represents: angle = (frequency ÷ total) × 360°.
Key Fact: To construct a pie chart, calculate each sector angle, draw a circle, and use a protractor to measure each angle from the previous sector.
Key Fact: A stem-and-leaf diagram displays data in order while retaining the original values; the stem shows the leading digits and the leaf shows the final digit.
Key Fact: In a stem-and-leaf diagram, leaves must be ordered from smallest to largest and a key must be provided (e.g. 3 | 7 means 37).
Key Fact: A back-to-back stem-and-leaf diagram compares two datasets using the same stem, with leaves of one dataset on each side.

Extended question: Full-Mark Response The table shows the number of students in each year group at a school. Draw a pie chart to represent the data. Year 7: 130, Year 8: 120, Year 9: 110, Year 10: 100, Year 11: 90 <div class="

Total = 130 + 120 + 110 + 100 + 90 = 550 Year 7: (130 ÷ 550) × 360° = 85.1° Year 8: (120 ÷ 550) × 360° = 78.5° Year 9: (110 ÷ 550) × 360° = 72.0° Year 10: (100 ÷ 550) × 360° = 65.5° Year 11: (90 ÷ 550) × 360° = 58.9° Check: 85.1 + 78.5 + 72.0 + 65.5 + 58.9 = 360.0° Draw a circle, draw a radius, then measure each angle in order using a protractor. Label each sector with the year group and angle.

Exam Tips: Always include a key on stem-and-leaf diagrams and pictograms — you will lose marks without one. | When drawing pie charts, always label each sector with the category name and preferably the percentage or frequency. | In a Venn diagram, the region outside both circles represents elements that are in neither set — do not forget this in probability questions. | When comparing two datasets using a back-to-back stem-and-leaf, comment on the shape, median, and spread. | Population pyramids can show ageing populations (narrow base, wide top) or young populations (wide base, narrow top) — use these terms in your comparisons.
Common Errors: ✗ Forgetting to include a key on a stem-and-leaf diagram or pictogram ✓ Always write a key, e.g. '3 | 7 means 37' for stem-and-leaf, or use a symbol key for pictograms. ✗ Calculating pie chart angles using percentages instead of frequencies ✓ Angle = (frequency ÷ total frequency) × 360°; percentages can be used but must total 100% and the formula becomes (percentage ÷ 100) × 360°. ✗ Not ordering leaves in a stem-and-leaf diagram ✓ Leaves must be arranged in ascending order from the stem; unordered leaves lose marks and make it harder to find the median. ✗ Confusing union and intersection in Venn diagrams ✓ Union (A ∪ B) is all elements in A or B or both; intersection (A ∩ B) is only elements
