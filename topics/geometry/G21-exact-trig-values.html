G21: Exact Trigonometric Values

Foundation Higher All Boards

Learn exact values of sin, cos, tan for 0°, 30°, 45°, 60°, 90°. Derive using special triangles. Apply in non-calculator problems and simplify surd expressions.

Lesson Overview

Estimated Lessons: 2
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, CCEA

Learning Objectives

  • Know exact values of sin, cos, tan for 0°, 30°, 45°, 60°, 90°
  • Derive values using 30-60-90 and 45-45-90 triangles
  • Use exact values in non-calculator trigonometry problems
  • Simplify expressions with surds (rationalise denominators)

Prerequisites

  • Pythagoras and trigonometry (G20)
  • Surds (N8 - Higher)
  • Special triangles (30-60-90, 45-45-90)

Materials & Equipment

  • Exact values table (memorisation aid initially)
  • Special triangle templates
  • Surds simplification reference

Lesson 1: Deriving and Memorising Exact Values

Duration: 50 minutes

Starter Activity (5 minutes)

Special Triangles

Equilateral triangle side 2. Bisect → two 30-60-90 triangles. Sides: 1, √3, 2. Square diagonal 1. Sides: 1, 1, √2 (45-45-90).

Main Content (35 minutes)

Teaching Notes:
30-60-90 triangle (from equilateral side 2):
- Hypotenuse = 2
- Short side (opp 30°) = 1
- Long side (opp 60°) = √3 (by Pythagoras: √(2²−1²) = √3)
45-45-90 triangle (from square side 1):
- Legs = 1, 1
- Hypotenuse = √2 (Pythagoras: √(1²+1²) = √2)
Exact values table:
| θ | sin θ | cos θ | tan θ |
| 0° | 0 | 1 | 0 |
| 30° | ½ | √3/2 | 1/√3 = √3/3 |
| 45° | 1/√2 = √2/2 | 1/√2 = √2/2 | 1 |
| 60° | √3/2 | ½ | √3 |
| 90° | 1 | 0 | undefined |
Patterns to remember:
- sin increases: 0, ½, √2/2, √3/2, 1
- cos decreases: 1, √3/2, √2/2, ½, 0
- tan: 0, √3/3, 1, √3, ∞
- sin θ = cos(90°−θ), cos θ = sin(90°−θ)
Rationalising denominators: 1/√2 = √2/2, 1/√3 = √3/3. Multiply numerator and denominator by the surd.
Worked Example

"Find exact value of sin 60° + cos 30°." Answer: sin 60° = √3/2, cos 30° = √3/2. Sum = √3/2 + √3/2 = √3.

Worked Example

"Find exact value of tan 45° × sin 30°." Answer: tan 45° = 1, sin 30° = ½. Product = ½.

"tan 90° = 0 or 1"

tan 90° is UNDEFINED (division by zero). cos 90° = 0, so tan 90° = sin 90°/cos 90° = 1/0 = undefined. As θ→90°, tan θ→∞.

Differentiation

Support (SEN/Lower Ability): Two special triangles as reference. Build table together. Mnemonic: "1, 2, 3 for sin: √1/2, √2/2, √3/2" (i.e., ½, √2/2, √3/2). Cos reverse.
Stretch (Higher/Gifted): Exact values for 15° and 75° (using compound angle formulas: 15° = 45°−30°, 75° = 45°+30°). Exact values for 18°, 36°, 54°, 72° (pentagon/golden ratio). Derive sin 18° = (√5−1)/4.

Plenary (5 minutes)

Table Race

Students complete blank exact values table from memory. Time challenge.

Assessment Criteria

  • Got it: Recalls all values, derives from triangles, rationalises denominators
  • Getting there: Knows 30/45/60 but forgets 0/90 or rationalising
  • Not yet: Cannot recall or derive values

Lesson 2: Non-Calculator Problems with Exact Values

Duration: 50 minutes

Starter Activity (5 minutes)

Surd Practice

Simplify: √12, 2/√3, √2/√8, (√3+1)/(√3−1). Rationalise denominators.

Main Content (35 minutes)

Teaching Notes:
Non-calculator trig problems: Use exact values instead of decimals. Answer in surd form.
Finding sides: Known angle (30/45/60), known side. Use exact ratio. Answer may be surd.
Finding angles: Given sides in surd form. Recognise ratio → exact angle.
Compound expressions: Simplify using surd rules: √a × √b = √(ab), √a/√b = √(a/b), (√a)² = a.
Common problem types:
- Right triangle with 30/45/60° angle
- 30-60-90 or 45-45-90 triangle with algebraic sides
- Area of triangle using ½ab sin C with exact angle
- Sector area/arc length with exact angle
- Vector/components with exact bearings (e.g., 060° → sin 60° = √3/2, cos 60° = ½)
Worked Example

"Right triangle: angle 30°, hypotenuse 10 cm. Find exact opposite and adjacent." Answer: sin 30° = ½ = opp/10 → opp = 5. cos 30° = √3/2 = adj/10 → adj = 5√3. Check: 5² + (5√3)² = 25 + 75 = 100 = 10². ✓

Worked Example

"Triangle sides 6, 6√3, 12. Show it's a 30-60-90 triangle and find angles." Answer: Ratio 1 : √3 : 2 (divide by 6). Hypotenuse = 12. Short side = 6 (opp 30°). Long side = 6√3 (opp 60°). Angles: 30°, 60°, 90°.

Worked Example

"Simplify: sin 45° + cos 45°." Answer: √2/2 + √2/2 = √2.

"√2/2 + √2/2 = √4/4 = 2/4 = ½"

√2/2 + √2/2 = 2(√2/2) = √2. You add the coefficients, not the surds inside. Like x/2 + x/2 = x, not 2x/4.

Differentiation

Support (SEN/Lower Ability): Exact values table provided. Step-by-step: 1) Identify angle, 2) Write exact ratio, 3) Substitute known side, 4) Solve, 5) Simplify surds.
Stretch (Higher/Gifted): Problems with 15°/75° (sin 15° = (√6−√2)/4). Area of regular polygons using exact values (e.g., hexagon = 6 × ½r²sin60° = 3r²√3/2). Trig identities: sin²θ+cos²θ=1 with exact values.

Plenary (5 minutes)

Simplify

Expressions: sin 60°/cos 30°, tan 30° × tan 60°, sin²45° + cos²45°, (sin 60°)² − (cos 60°)².

Assessment Criteria

  • Got it: Solves non-calculator problems fluently, simplifies surd expressions correctly
  • Getting there: Uses exact values but makes surd arithmetic errors
  • Not yet: Relies on calculator, cannot recognise exact value ratios

Homework Suggestions

  • Exact values memorisation: write table from memory daily
  • Non-calculator worksheet: find sides/angles with exact values
  • Surd simplification practice: rationalise denominators, add/multiply surds
  • Problem: "Equilateral triangle side 10 cm. Exact height? Exact area?" (Height = 5√3, Area = 25√3)
  • Past paper non-calculator trig questions
