G24: Vectors

Foundation Higher All Boards

Understand vectors as quantities with magnitude and direction. Use column vector notation. Perform vector addition, subtraction, scalar multiplication. Find magnitude. Solve geometric problems with vectors.

Lesson Overview

Estimated Lessons: 3
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, CCEA

Learning Objectives

  • Understand vector notation: column vectors, bold letters, AB with arrow
  • Add and subtract vectors (graphically and column-wise)
  • Multiply vectors by scalars
  • Find magnitude of a vector: |(x,y)| = √(x²+y²)
  • Identify parallel vectors (scalar multiples)
  • Solve geometric problems: midpoints, ratios, resultant vectors

Prerequisites

  • Coordinates (A8)
  • Pythagoras (G20)
  • Translations (G7)

Materials & Equipment

  • Squared paper
  • Vector diagram templates
  • Calculators for magnitude

Lesson 1: Vector Basics and Operations

Duration: 50 minutes

Starter Activity (5 minutes)

Vector vs Scalar

Speed (scalar) vs velocity (vector). Distance vs displacement. Force, acceleration, momentum are vectors.

Main Content (35 minutes)

Teaching Notes:
Vector notation: Column vector (x/y) or \begin{pmatrix} x \\ y \end{pmatrix}. x = horizontal (right +), y = vertical (up +). Bold a or underlined a. Arrow AB (from A to B).
Equal vectors: Same magnitude AND direction. Position doesn't matter. AB = DC means parallel, same length, same direction.
Vector addition: a + b = (a₁+b₁, a₂+b₂). Graphically: nose-to-tail. Resultant = start of first to end of last. Commutative: a+b = b+a.
Vector subtraction: a − b = a + (−b). −b = same magnitude, opposite direction. Graphically: tail-to-tail, resultant from tip of b to tip of a.
Scalar multiplication: k(a₁, a₂) = (ka₁, ka₂). k > 1: longer, same direction. 0 < k < 1: shorter, same direction. k < 0: opposite direction, magnitude |k| times.
Zero vector: (0,0). No magnitude, no direction. a + (−a) = 0.
Resultant vector: Sum of multiple vectors. Path A→B→C→D: AB + BC + CD = AD.
Worked Example

"a = (3, 2), b = (−1, 4). Find a+b, a−b, 2a, magnitude of a." Answer: a+b = (2, 6). a−b = (4, −2). 2a = (6, 4). |a| = √(3²+2²) = √13.

Worked Example

"AB = (4, 3), BC = (−2, 5). Find AC." Answer: AC = AB + BC = (4, 3) + (−2, 5) = (2, 8).

Common Misconception

"Vector (3, 4) has magnitude 7 (3+4)"

Magnitude = √(3²+4²) = 5. Pythagoras! Components are perpendicular legs.

Differentiation

Support (SEN/Lower Ability): Graphical methods first: draw vectors nose-to-tail. Column arithmetic as check. Use grid: count squares for components. Colour-code: a (red), b (blue), resultant (green).
Stretch (Higher/Gifted): Vector in 3D: (x, y, z). Magnitude √(x²+y²+z²). Unit vector = a/|a|. Dot product a·b = |a||b|cosθ. Cross product (3D only). Position vectors relative to origin O.

Plenary (5 minutes)

Vector Arithmetic

Quick: (2,3)+(4,−1)=? (5,−2)−(1,−3)=? 3(−2,1)=? |(5,12)|=?

Assessment Criteria

  • Got it: Performs all operations correctly, finds magnitude, identifies parallel vectors
  • Getting there: Column arithmetic OK, struggles with graphical representation or magnitude
  • Not yet: Confuses addition/subtraction, adds components for magnitude

Lesson 2: Geometric Problems with Vectors

Duration: 50 minutes

Starter Activity (5 minutes)

Midpoint Vector

A(2,3), B(8,7). Midpoint M = ((2+8)/2, (3+7)/2) = (5,5). Vector AM = (3,2). Vector MB = (3,2). AM = MB.

Main Content (35 minutes)

Teaching Notes:
Position vectors: Vector from origin O to point A = a. OA = a. AB = b − a (final − initial).
Midpoint: M midpoint of AB → OM = (a+b)/2. AM = ½(b−a) = ½AB.
Ratio division: P divides AB in ratio m:n (AP:PB = m:n).
Internal: OP = (na + mb)/(m+n). (Weighted average, closer to B if m > n).
External: AP:PB = m:n with P outside segment → OP = (na − mb)/(n−m) or similar.
Parallel vectors: a ∥ b if a = kb for some scalar k. Check: components proportional.
Collinear points: A, B, C collinear if AB = k·AC (or AB ∥ AC and shared point).
Geometric proofs with vectors: Express all vectors in terms of basis vectors (e.g., a = OA, b = OB). Show parallelism (one is scalar multiple of other) or collinearity.
Worked Example

"OABC parallelogram. OA = a, OC = c. Find OB, AC, midpoint of AC." Answer: OB = a + c. AC = c − a. Midpoint M: OM = (a+c)/2.

Worked Example

"Triangle OAB. OA = a, OB = b. M on AB with AM:MB = 2:1. Find OM." Answer: OM = (1·a + 2·b)/(2+1) = (a+2b)/3. Check: AM = OM−a = (a+2b)/3 − a = (2b−2a)/3 = ⅔(b−a). MB = b−OM = b−(a+2b)/3 = (b−a)/3. Ratio 2:1. ✓

Common Misconception

"AB = a − b (initial − final)"

AB = b − a (FINAL − INITIAL). Vector from A to B = position of B minus position of A.

Differentiation

Support (SEN/Lower Ability): Formula cards: AB = b−a, midpoint = (a+b)/2, ratio = (na+mb)/(m+n). Step-by-step: 1) Write position vectors, 2) Find AB, 3) Apply formula. Use diagrams.
Stretch (Higher/Gifted): Vector equation of line: r = a + λb. Intersection of lines. Vector equation of plane (3D). Prove: diagonals of parallelogram bisect (done). Prove: medians of triangle concurrent (centroid = (a+b+c)/3).

Plenary (5 minutes)

Ratio Practice

AB, ratio 3:2. Formula? (2a+3b)/5. AP:PB = 1:3? (3a+b)/4. External division 2:1? (a−2b)/−1 = 2b−a.

Assessment Criteria

  • Got it: Uses position vectors, finds midpoints, ratio division, proves parallel/collinear
  • Getting there: Finds AB = b−a, midpoints, struggles with ratio formula
  • Not yet: Confuses AB = a−b, cannot use position vectors

Lesson 3: Vector Proofs and Advanced Problems

Duration: 50 minutes

Starter Activity (5 minutes)

Prove Parallel

a = (2, 3), b = (4, 6). b = 2a → parallel. a = (3, 2), b = (6, 3). 6/3=2, 3/2=1.5 → not parallel.

Main Content (35 minutes)

Teaching Notes:Vector proof structure:
1. Define basis vectors (e.g., OA = a, OB = b)
2. Express all needed vectors in terms of a, b
3. Simplify using algebra
4. Show parallelism: one vector = scalar × other
5. Show collinearity: vectors share point AND are parallel
6. Conclude geometric result
Standard vector proofs:
- Midpoints of quadrilateral form parallelogram (Varignon)
- Diagonals of parallelogram bisect each other
- Medians of triangle concurrent at centroid (2:1 ratio)
- Line joining midpoints of two sides of triangle is parallel to third side and half its length
- Trapezium: line joining midpoints of non-parallel sides is parallel to parallel sides
Working with ratios in proofs: Use section formula. If M divides AB in ratio λ:1, OM = (a+λb)/(1+λ). (Often λ = 1 for midpoint, λ = 2 for 2:1, etc.)
Worked Example

"Prove: Midpoints of any quadrilateral form a parallelogram."
Let vertices O, A, B, C. Position vectors: 0, a, b, c.
Midpoints: P = a/2 (OA), Q = (a+b)/2 (AB), R = (b+c)/2 (BC), S = c/2 (CO).
PQ = Q−P = (a+b)/2 − a/2 = b/2.
SR = R−S = (b+c)/2 − c/2 = b/2.
PQ = SR → PQ ∥ SR and PQ = SR.
Similarly QR = c/2, PS = c/2 → QR ∥ PS.
PQRS is a parallelogram. □

Worked Example

"OABC parallelogram. M midpoint of BC. N on AB with AN:NB = 2:1. Prove O, M, N collinear."
OA = a, OC = c. OB = a+c. M on BC: BC = a. BM = ½a. OM = OB + BM? Wait. B = a+c. BC = a. M = B + ½BC = a+c + ½a = 1.5a + c. N on AB: AN:NB = 2:1. ON = (1·a + 2·(a+c))/3 = (3a+2c)/3 = a + ⅔c. NM = OM − ON = (1.5a+c) − (a+⅔c) = 0.5a + ⅓c = ½(a + ⅔c) = ½ ON. So NM = ½ ON → NM ∥ ON and shared point N → O, M, N collinear. □

Common Misconception

"In vector proofs, you can just state 'this is parallel to that' without showing scalar multiple"

Must EXPLICITLY show one vector = k × other vector. Factor out common expression. "PQ = ½ SR" is proof. "PQ is parallel to SR" is just statement.

Differentiation

Support (SEN/Lower Ability): Proof templates with blanks. Provide list of standard results to prove. Focus on showing parallelism via factoring. Use numerical examples first (a=(2,1), b=(1,3)).
Stretch (Higher/Gifted): Prove: "In a tetrahedron, lines joining vertices to centroids of opposite faces are concurrent." Use vector methods. Affine transformations preserve parallelism and ratios. Barycentric coordinates.

Plenary (5 minutes)

Proof Step

Given: PQ = 2a − b, RS = 4a − 2b. Prove PQ ∥ RS. Students write: RS = 2(2a − b) = 2 PQ. Therefore parallel.

Assessment Criteria

  • Got it: Constructs complete vector proofs, expresses vectors in basis, shows parallelism by factoring
  • Getting there: Finds vectors correctly, but struggles to factor and conclude
  • Not yet: Cannot set up position vectors for a given diagram

Homework Suggestions

  • Vector worksheet: arithmetic, magnitude, geometric problems
  • Prove: "The line joining the midpoints of two sides of a triangle is parallel to the third side and half its length" using vectors
  • Prove: "The medians of a triangle intersect at a point that divides each median in the ratio 2:1"
  • Past paper vector questions (including geometric proofs)
