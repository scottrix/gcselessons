Lesson 1: Introduction: Transformations

Duration: 50 minutes

Starter Activity (5 minutes)

Quick Recall

3 quick questions to activate prior knowledge about transformations. Use mini-whiteboard or paper.

Main Content (35 minutes)

Parent/Teacher Guide:
Before lesson: Read script below. Prepare materials. Pre-teach key vocab: G7.
If stuck: See Troubleshooting below. Break into smaller steps.
Extension: See Stretch & Challenge section.
Teaching Script (35 mins):
Mins 0-5 - Hook: "Today: Transformations. Goal: by the end you can reflect the point (2, 5) in the line y = x, using the method shown step by step. Connects to combined transformations (G8) because you'll reuse its method throughout today's work."
Mins 5-15 - Direct Instruction: 1) Define: "Transformations is..." 2) Key principle: "Most important:..." 3) Draw diagram, label live. 4) Real example: "Like Reflect the point (2, 5) in the line y = x. - a real example worked through in full..."
Mins 15-25 - Guided Practice: Ex1: Teacher models. Ex2: Student tries with guidance. Ex3: Student independent.
Mins 25-35 - Independent Practice: 3-5 questions. Immediate feedback.
Worked Example 1: Basic

Q: Reflect the point (2, 5) in the line y = x.

  1. What is asked? Reflect
  2. Recall knowledge: Translation by (a, b): right a, up b — shape unchanged; Reflection: mirror line named (x = a, y = b, y = x, y = −x, axes)
  3. Apply: Swap the coordinates: (5, 2)
  4. Check: Check the units named in the question and sense-check the size of your answer.
  5. Answer: State the complete final answer.

Tip: "Show working - method marks > answer marks."

Worked Example 2: Multi-step

Q: Describe fully the single transformation taking (1, 1) to (4, 5) with no other information.

  1. Break down: Separate parts?
  2. Solve each: Cannot be done uniquely — describe A possible one: translation by the vector (3, 4). Full description format matters: "Translation by the vector (3, 4)" — naming the transformation type, then its parameter.
  3. Combine: The parts chain: each answer feeds the next step of the question.
  4. Final answer: B1 for a correct full description. 'Fully' always means type + (vector / line / angle-direction-centre / factor-centre).
Worked Example 3: Data/Application

Q: Describe fully the single transformation taking (1, 1) to (4, 5) with no other information.

  1. Read data: Axes, units, scale
  2. Patterns: Trends, anomalies
  3. Explain: Why? Using transformations
  4. Conclude: Evidence-based

Common Questions & Troubleshooting

Q: "Why does Translation by (a, b): right a, up b — shape unchanged work this way?"
A: Analogy: "Reflect the point (2, 5) in the line y = x.". Try re-draw or re-write the worked example from memory, then check it against the model answer.
Q: "Wrong answers on calculations."
A: Checklist: units? formula? calculator mode? sig figs?
Q: "Can't remember key terms."
A: Flashcards (term front, def+diagram back). Spaced repetition: day 1, 3, 7.
Q: "Exam wording confuses me."
A: Commands: Describe=what you see; Explain=reasons; Evaluate=pros/cons+judgement; Calculate=working+units.
Q: "Running out of time."
A: 1 mark/min. Skip hard, return. Attempt all - partial marks count.

📝 Mark Scheme Guidance

How examiners mark G7: Read the command word carefully — State = one word/phrase (1 mark), Describe = pattern or detail (2 marks), Explain = reason with "because" (2–3 marks), Compare = similarities AND differences, Evaluate = both sides + conclusion. Method marks are awarded for correct working even if the final answer is wrong. Always show your working — unexplained answers score zero for AO2.

Success on G7 questions: Underline the command word, count the marks (one mark per point expected), and answer in the format the command word demands.
