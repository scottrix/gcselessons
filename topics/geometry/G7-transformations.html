G7: Transformations

Foundation Higher All Boards

Master the four transformations: reflection, rotation, translation, and enlargement. Describe transformations fully, perform them on grids, and understand invariant properties.

Lesson Overview

Estimated Lessons: 4
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, CCEA

Learning Objectives

  • Perform and describe reflections (mirror line given or equation)
  • Perform and describe rotations (centre, angle, direction)
  • Perform and describe translations (column vector)
  • Perform and describe enlargements (centre, scale factor, including fractional/negative)
  • Identify invariant points and lines under transformations

Prerequisites

  • Coordinates (A8)
  • Column vectors (G24 basics)
  • Equations of lines (x = a, y = b, y = mx + c)

Materials & Equipment

  • Squared paper, tracing paper
  • Mirrors (for reflection)
  • Coordinate grids (print or digital)

Lesson 1: Reflection and Rotation

Duration: 50 minutes

Starter Activity (5 minutes)

Mirror Images

Students hold up hands — which is reflection? Use tracing paper: draw shape, flip over line, trace. Physical experience of reflection.

Main Content (35 minutes)

Teaching Notes:
Reflection: Mirror line (line of symmetry). Every point maps to point same perpendicular distance on other side. Mirror line is perpendicular bisector of segment joining point and image.
Describing reflection: "Reflection in the line x = 2" or "Reflection in the line y = x". Must state line equation.
Common mirror lines: x-axis (y = 0), y-axis (x = 0), y = x, y = −x, x = a, y = b.
Rotation: Turn about a centre. Three pieces of info: centre of rotation, angle (90°, 180°, 270°), direction (clockwise/anticlockwise).
Describing rotation: "Rotation 90° anticlockwise about (2, 3)" or "Rotation 180° about (0, 0)". 180° rotation = point reflection (same as two perpendicular reflections).
Performing on grid: Use tracing paper. Trace shape, pin at centre, rotate, trace image. Or coordinate rules: 90° anticlockwise about origin: (x, y) → (−y, x). 180°: (x, y) → (−x, −y). 270° anticlockwise = 90° clockwise: (x, y) → (y, −x).
Worked Example

"Reflect triangle A(1,2), B(3,2), C(2,4) in the line y = x." Answer: Swap coordinates. A'(2,1), B'(2,3), C'(4,2). Check: midpoint of AA' is (1.5, 1.5) which lies on y = x. AA' gradient = -1 (perpendicular to y = x gradient 1).

Worked Example

"Rotate triangle (1,1), (3,1), (2,3) 90° clockwise about (0,0)." Answer: Rule (x, y) → (y, −x). (1,1)→(1,−1), (3,1)→(1,−3), (2,3)→(3,−2).

Common Misconception

"Reflection in y = x is the same as reflection in y = -x"

y = x: (x,y)→(y,x). y = -x: (x,y)→(-y,-x). Different! y = x swaps; y = -x swaps and negates both.

Differentiation

Support (SEN/Lower Ability):
Use physical mirrors and tracing paper extensively. Start with axis reflections (x=0, y=0). Provide coordinate rule cards. Use colour-coded axes.
Stretch (Higher/Gifted):
Reflection in line y = mx + c (general formula). Rotation about arbitrary point (not origin) — translate to origin, rotate, translate back. Composition: two reflections in intersecting lines = rotation (angle = 2×angle between lines).

Plenary (5 minutes)

Describe the Transformation

Show object and image. Students write full description. Emphasise: "Reflection in line..." not just "Reflection". "Rotation 90° clockwise about..." not just "Rotation".

Assessment Criteria

  • Got it: Performs and describes all reflections/rotations accurately, including y=x, y=-x, arbitrary centres
  • Getting there: Can do axis reflections and origin rotations, struggles with y=x or non-origin centres
  • Not yet: Confuses reflection/rotation, cannot describe fully

Lesson 2: Translation and Enlargement

Duration: 50 minutes

Starter Activity (5 minutes)

Vector Translation

Given vector (3, -2). Move shape 3 right, 2 down. All points move same vector. Shape unchanged (congruent).

Main Content (35 minutes)

Teaching Notes:
Translation: Slide without turning or resizing. Described by column vector (x, y) where x = horizontal (right +), y = vertical (up +). Every point moves by same vector. Shape congruent, same orientation.
Describing translation: "Translation by vector (3, −2)" or "Translation 3 right, 2 down".
Enlargement: Resize from a centre. Scale factor (SF) determines size change.
- SF > 1: larger
- 0 < SF < 1: smaller (fractional)
- SF = 1: same size (identity)
- SF < 0: negative enlargement — flipped through centre, opposite side
Describing enlargement: "Enlargement, scale factor 2, centre (1, 1)" or "Enlargement, scale factor -½, centre (0, 0)".
Performing enlargement: Draw rays from centre through vertices. Measure distance centre→vertex. Multiply by SF. Mark new vertex on ray (opposite side if SF negative).
Area/volume scale factors: Area SF = (length SF)². Volume SF = (length SF)³.
Worked Example

"Enlarge shape by SF -2, centre (0,0). Vertex at (2, 1). Find image." Answer: Ray from (0,0) through (2,1). Distance = √5. New distance = 2√5. Direction opposite → (-4, -2). Or coordinate rule: (x,y)→(SF×x, SF×y) = (-4, -2).

Worked Example

"Shape area 6 cm² enlarged by SF 3. New area?" Answer: Area SF = 3² = 9. New area = 6 × 9 = 54 cm².

Common Misconception

"Negative enlargement makes the shape smaller"

Negative enlargement FLIPS the shape through the centre. Size depends on |SF|. SF = -2 makes it 2x larger AND flipped. SF = -½ makes it half size AND flipped.

Differentiation

Support (SEN/Lower Ability):
Use ray method with ruler. Start with positive integer SF. Use squared paper for translations. Provide step-by-step: 1) Draw rays, 2) Measure, 3) Multiply, 4) Mark.
Stretch (Higher/Gifted):
Enlargement with fractional/negative SF combined with other transformations. Find centre of enlargement given object and image (intersect rays). Prove area SF = (length SF)² using similar triangles. Enlargement in 3D (volume SF).

Plenary (5 minutes)

Transformation Sort

Cards with transformation descriptions. Sort into: reflection, rotation, translation, enlargement. Identify which are congruent (reflection, rotation, translation) vs similar (enlargement).

Assessment Criteria

  • Got it: Performs/describes all four types including fractional/negative enlargement, finds centre of enlargement
  • Getting there: Does positive integer enlargement and translations, struggles with negative/fractional SF
  • Not yet: Confuses translation vector direction, cannot enlarge from centre

Lesson 3: Combined Transformations and Invariant Points

Duration: 50 minutes

Starter Activity (5 minutes)

Two Reflections

Reflect shape in x=1, then in x=4. Result = translation by (6, 0). Two parallel reflections = translation (distance = 2×gap between lines).

Main Content (35 minutes)

Teaching Notes:
Combined transformations: Apply one after another. Order matters!
Equivalent single transformations:
- Two reflections in parallel lines → translation (2×distance between lines, perpendicular to lines)
- Two reflections in intersecting lines → rotation (centre = intersection, angle = 2×angle between lines)
- Two rotations about same centre → rotation (sum of angles)
- Translation + rotation ≠ single simple transformation generally
Invariant points: Points that map to themselves.
- Reflection: all points on mirror line are invariant
- Rotation: only centre of rotation is invariant (unless 360°)
- Translation: NO invariant points (unless zero vector)
- Enlargement: centre of enlargement is invariant (unless SF = 1)
Invariant lines: Lines that map to themselves (not necessarily pointwise).
- Reflection: mirror line (pointwise), any perpendicular line (as set)
- Rotation: no invariant lines (unless 180° — any line through centre)
- Translation: lines parallel to translation vector
- Enlargement: any line through centre
Worked Example

"Reflect in x-axis, then rotate 90° clockwise about origin. Find single equivalent transformation." Answer: (x,y) → (x,-y) → (-y,-x). This is reflection in y = -x. Check: (1,2)→(1,-2)→(-2,-1). Reflection in y=-x: (1,2)→(-2,-1). Matches.

Common Misconception

"Order of transformations doesn't matter"

Order ALWAYS matters (except special cases like two translations). Reflect then rotate ≠ rotate then reflect. Always apply transformations in the order given.

Differentiation

Support (SEN/Lower Ability):
Focus on identifying invariant points for each transformation type. Use tracing paper for combined transformations. Provide summary table of invariant points/lines.
Stretch (Higher/Gifted):
Matrix representation of transformations (2×2 matrices). Composition via matrix multiplication. Eigenvalues/eigenvectors as invariant directions. Glide reflections (reflection + translation parallel to mirror).

Plenary (5 minutes)

Invariant Hunt

Given transformation, find all invariant points and lines. E.g., "Enlargement SF 2, centre (1,1)" → invariant point: (1,1). Invariant lines: any line through (1,1).

Assessment Criteria

  • Got it: Finds equivalent single transformations, identifies invariant points/lines correctly
  • Getting there: Can do combined transformations with tracing paper, struggles to find single equivalent
  • Not yet: Cannot perform combined transformations in order

Lesson 4: Describing Transformations Fully (Exam Focus)

Duration: 50 minutes

Starter Activity (5 minutes)

Mark the Description

Show student answers: "Reflection" (1/3 marks), "Reflection in y-axis" (2/3), "Reflection in the line x = 0" (3/3). Discuss what makes full description.

Main Content (35 minutes)

Teaching Notes:
Full description requirements:
- Reflection: "Reflection in the line [equation]"
- Rotation: "Rotation [angle]° [clockwise/anticlockwise] about [centre coordinates]"
- Translation: "Translation by vector [column vector]"
- Enlargement: "Enlargement, scale factor [SF], centre [centre coordinates]"
Common errors losing marks:
- Missing direction for rotation (assume anticlockwise if not stated? No — must state!)
- Giving vector as coordinates not column vector
- Forgetting centre for enlargement/rotation
- Not simplifying vector (e.g., (2,4) instead of (1,2) — both accepted but simplified better)
- Saying "enlarged by 2" instead of "scale factor 2"
Finding centre of enlargement: Join corresponding vertices on object and image. Extend lines — intersection = centre. Works for positive and negative SF.
Worked Example

"Object A(1,1), B(2,1), C(1,2). Image A'(3,3), B'(5,3), C'(3,5). Describe fully." Answer: Vectors: A→A' = (2,2), B→B' = (3,2)? No, not translation. Check rays: A to A' ray, B to B' ray. Intersection? Line through (1,1) and (3,3): y=x. Line through (2,1) and (5,3): gradient 2/3. Not same. Try centre (0,0): A→A' ×3, B→B'? (2,1)→(6,3)≠(5,3). Not from origin.
Actually: A'(3,3) = 3×(1,1). B'(5,3) not 3×(2,1)=(6,3). C'(3,5) not 3×(1,2)=(3,6). Not enlargement from origin.
Try vector: B→B' = (3,2), A→A' = (2,2). Different vectors → not translation.
This is TWO transformations. Not single. Exam would ask "describe fully the single transformation" implying one exists.

Common Misconception

"Scale factor -1 is a rotation of 180°"

SF -1 about centre C IS a 180° rotation about C. But SF -1 about (0,0) is rotation 180° about (0,0). They are equivalent. However, description must match the transformation type: "Enlargement SF -1" or "Rotation 180°". Both correct if accurate.

Differentiation

Support (SEN/Lower Ability):
Provide description templates with blanks. Practise "Reflection in the line ___", "Rotation ___° ___ about ___". Use past paper questions with mark schemes.
Stretch (Higher/Gifted):
"Describe fully the single transformation that maps shape A to shape B" where it's a combination (e.g., reflection then rotation = glide reflection). Investigate which combinations simplify to a single basic transformation.

Plenary (5 minutes)

Exam Question Practice

Timed: 3 transformation descriptions in 5 minutes. Peer mark using mark scheme criteria.

Assessment Criteria

  • Got it: Writes full descriptions for all 4 types, finds centres, identifies invariant points
  • Getting there: Describes 3/4 types fully, misses details (direction, centre, vector format)
  • Not yet: Cannot give complete description for any type

Homework Suggestions

  • Transformation worksheet: perform and describe all 4 types
  • Create a transformation summary poster with rules, notation, and invariant properties
  • Find centre of enlargement for 5 object-image pairs
  • Investigate: Which pairs of transformations commute (order doesn't matter)?
