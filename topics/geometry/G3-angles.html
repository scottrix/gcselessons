G3: Angles

Foundation Higher All Boards

Master angle facts: angles on a line, around a point, in triangles, quadrilaterals, parallel lines, and polygons. Solve multi-step angle problems with clear reasoning.

Lesson Overview

Estimated Lessons: 3
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, CCEA

Learning Objectives

  • Apply angle facts: straight line (180°), point (360°), vertically opposite, triangle (180°), quadrilateral (360°)
  • Identify and use angles in parallel lines: alternate, corresponding, co-interior
  • Calculate interior and exterior angles of regular and irregular polygons
  • Solve multi-step angle problems with clear mathematical reasoning

Prerequisites

  • Geometric notation (G1)
  • Angle types: acute, obtuse, reflex, right angle
  • Basic algebra for angle equations

Materials & Equipment

  • Protractors, rulers
  • Angle fact reference cards
  • Polygon cut-outs or dynamic geometry software

Lesson 1: Basic Angle Facts and Parallel Lines

Duration: 50 minutes

Starter Activity (5 minutes)

Angle Fact Recall

Quick fire: "Angles on a straight line sum to?" "Angles around a point?" "Vertically opposite angles?" "Angles in a triangle?" "Angles in a quadrilateral?"

Main Content (35 minutes)

Teaching Notes:
Angle facts:
- Straight line: 180°
- Around a point: 360°
- Vertically opposite: equal
- Triangle: 180° (prove by drawing parallel line)
- Quadrilateral: 360° (split into two triangles)
- Isosceles triangle: base angles equal
Parallel lines: Transversal creates 8 angles. Key pairs:
- Alternate (Z-angles): equal, between parallels, opposite sides of transversal
- Corresponding (F-angles): equal, same relative position at each intersection
- Co-interior (C-angles): sum to 180°, between parallels, same side of transversal
Reasoning: Always state the angle fact used. "∠x = 50° because alternate angles are equal (AB ∥ CD)". "∠y = 130° because co-interior angles sum to 180°".
Worked Example

"Find x and y. AB ∥ CD. ∠AEF = 50°, ∠EFD = 70°." Answer: x = 50° (alternate, AB ∥ CD). y = 110° (co-interior with 70°). Or: ∠BEF = 130° (straight line), y = 130° (corresponding with ∠BEF). Multiple routes — all valid if reasoning given.

Common Misconception

"Alternate and corresponding angles are always equal"

Only when lines are PARALLEL. Always state "because AB ∥ CD" or given parallel lines. Without parallel lines, these angles are not necessarily equal.

Differentiation

Support (SEN/Lower Ability):
Use coloured highlighters for Z, F, C patterns. Provide angle fact sheet. Practise identifying angle pairs before calculating. Use "angle chase" worksheets with simple diagrams.
Stretch (Higher/Gifted):
Prove angle sum of triangle using parallel lines. Prove alternate angles equal using corresponding + vertically opposite. Multi-step problems with algebra (e.g., angles as 2x, 3x+10). Bearings problems using angle facts.

Plenary (5 minutes)

Spot the Error

Show a solution with a reasoning error (e.g., using alternate angles when lines aren't marked parallel). Students identify and correct.

Assessment Criteria

  • Got it: Correctly applies all angle facts, states reasons clearly, solves multi-step problems
  • Getting there: Knows facts but omits reasons or confuses alternate/corresponding
  • Not yet: Cannot identify angle pairs or apply basic facts

Lesson 2: Polygon Angles

Duration: 50 minutes

Starter Activity (5 minutes)

Divide and Conquer

Draw a pentagon. How many triangles can you make from one vertex? (3). Sum of interior angles? (3 × 180° = 540°).

Main Content (35 minutes)

Teaching Notes:
Interior angle sum: (n−2) × 180° where n = number of sides. Derive by drawing diagonals from one vertex.
Exterior angle sum: Always 360° (walk around polygon, turn at each vertex).
Regular polygon: Interior angle = (n−2) × 180° / n. Exterior angle = 360° / n.
Relationship: Interior + Exterior = 180° (straight line at each vertex).
Finding n: If exterior angle given, n = 360° / exterior. If interior given, exterior = 180° − interior, then n = 360° / exterior.
Worked Example

"A regular polygon has interior angle 156°. How many sides?" Answer: Exterior = 180° − 156° = 24°. n = 360° / 24° = 15 sides.

Worked Example

"Irregular pentagon has angles 100°, 110°, 120°, 130°, x. Find x." Answer: Sum = 540°. x = 540° − (100+110+120+130) = 540° − 460° = 80°.

Common Misconception

"Exterior angle is the reflex angle outside the polygon"

Exterior angle is the angle between one side and the extension of the adjacent side (the "turn angle"). It's the supplement of the interior angle, not the reflex angle. For regular polygons, exterior = 360°/n.

Differentiation

Support (SEN/Lower Ability):
Provide formula cards. Use polygon templates to draw diagonals physically. Focus on regular polygons first. Use table: n, interior sum, interior (regular), exterior (regular).
Stretch (Higher/Gifted):
Prove exterior sum = 360° for any polygon (induction or "walk around"). Tessellations: which regular polygons tessellate? (Interior angle must divide 360°). Angle problems combining polygons (e.g., two polygons sharing a side).

Plenary (5 minutes)

Polygon Puzzle

"A regular polygon has interior angle 5 times its exterior angle. How many sides?" Answer: Let exterior = x. Interior = 5x. x + 5x = 180° → 6x = 180° → x = 30°. n = 360°/30° = 12.

Assessment Criteria

  • Got it: Uses formulas fluently, solves for n, handles irregular polygons
  • Getting there: Uses formulas but confuses interior/exterior, or forgets to divide by n
  • Not yet: Cannot recall or apply interior angle sum formula

Lesson 3: Multi-Step Angle Problems

Duration: 50 minutes

Starter Activity (5 minutes)

Angle Chase

Complex diagram with parallel lines, triangles, and polygons. Find as many angles as possible in 3 minutes.

Main Content (35 minutes)

Teaching Notes:
Problem-solving strategy:
1. Mark known angles on diagram
2. Identify which angle facts apply at each step
3. Work systematically — don't jump to target angle
4. Write reasons for EVERY step
5. Check: do angles make sense? (e.g., not > 180° in triangle)
Algebra in angles: Angles expressed as expressions (2x, 3x−20). Form and solve equations using angle facts.
Bearings: Measured clockwise from North, 3 figures. Use parallel line angle facts (North lines are parallel).
Worked Example

"In triangle ABC, ∠A = 2x, ∠B = 3x−10, ∠C = x+20. Find all angles." Answer: 2x + 3x−10 + x+20 = 180° → 6x + 10 = 180° → 6x = 170° → x = 28.33°. ∠A = 56.7°, ∠B = 75°, ∠C = 48.3°. Check: 56.7+75+48.3 = 180°.

Common Misconception

"Bearings are measured anticlockwise from North"

Bearings are ALWAYS measured CLOCKWISE from North, written as 3 figures (045°, not 45°). North lines are parallel — use corresponding/alternate angles.

Differentiation

Support (SEN/Lower Ability):
Scaffolded worksheets: step 1 find this angle, step 2 find that angle. Provide sentence starters for reasons. Use colour-coded angle types.
Stretch (Higher/Gifted):
Problems with multiple polygons sharing sides. Circle theorems preview (angles in same segment). Bearings with scale drawings. "Prove that..." style questions requiring formal geometric proof.

Plenary (5 minutes)

Create a Problem

Students design a multi-step angle problem with algebra. Must have a unique solution. Swap and solve.

Assessment Criteria

  • Got it: Solves complex multi-step problems with clear reasoning and algebra
  • Getting there: Solves straightforward problems but struggles to plan multi-step routes
  • Not yet: Cannot combine multiple angle facts in one problem

Homework Suggestions

  • Complete mixed angle practice worksheet (parallel lines, polygons, algebra)
  • Create a poster summarising all angle facts with diagrams and colour-coded Z/F/C patterns
  • Find real-world examples of parallel lines and angle relationships (floor tiles, brickwork, window frames)
  • Solve: "The interior angle of a regular polygon is 170°. How many sides?" (Answer: 36)
