G22: Sine & Cosine Rules

Higher Only All Boards

Higher tier: Apply the sine rule and cosine rule to solve any triangle (not just right-angled). Find missing sides and angles. Solve ambiguous case (SSA) problems. Calculate area of triangle using ½ab sin C.

Lesson Overview

Estimated Lessons: 4
Tier: Higher only
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, CCEA

Learning Objectives

  • Use sine rule: a/sin A = b/sin B = c/sin C (sides and opposite angles)
  • Use cosine rule: a² = b² + c² − 2bc cos A (and rearrangements)
  • Choose correct rule for given information (SSS, SAS, ASA, AAS, SSA)
  • Solve ambiguous case (SSA) — 0, 1, or 2 possible triangles
  • Apply rules to 3D problems and bearings

Prerequisites

  • Pythagoras and trigonometry (G20)
  • Exact trig values (G21)
  • Rearranging formulae (A5)

Materials & Equipment

  • Scientific calculators (sin⁻¹, cos⁻¹)
  • Sine/cosine rule summary cards
  • Triangle templates for ambiguous case

Lesson 1: Sine Rule

Duration: 50 minutes

Starter Activity (5 minutes)

Right Triangle Limitation

Triangle with no right angle. Sides 7, 9, angle 40° opposite 7. Can we use SOHCAHTOA? No — need sine rule.

Main Content (35 minutes)

Teaching Notes:
Sine rule: In any triangle ABC, a/sin A = b/sin B = c/sin C. Side a opposite angle A, etc.
When to use: Given AAS (two angles, one side) or ASA (two angles, included side) or SSA (two sides, non-included angle).
Finding a side: a = (b sin A)/sin B. Need: one side, its opposite angle, and the angle opposite the unknown side.
Finding an angle: sin A = (a sin B)/b. Need: two sides and an angle opposite one of them.
Calculator use: sin⁻¹ for angles. Ensure DEGREE mode.
Ambiguous case (SSA): Given a, b, A (angle opposite a).
- If a < b sin A: 0 triangles (side too short)
- If a = b sin A: 1 right triangle
- If b sin A < a < b: 2 triangles (acute and obtuse angle B)
- If a ≥ b: 1 triangle (angle B acute)
Worked Example

"Triangle: a=8, b=10, A=30°. Find B." Answer: sin B = (b sin A)/a = (10 × sin 30°)/8 = (10 × 0.5)/8 = 5/8 = 0.625. B = sin⁻¹(0.625) = 38.7° or 180°−38.7° = 141.3°. Check: A+B < 180°? 30+141.3 = 171.3° < 180° → TWO possible triangles.

Worked Example

"Triangle: A=40°, B=70°, a=12. Find b." Answer: C = 70°. b = (a sin B)/sin A = (12 × sin 70°)/sin 40° = (12 × 0.9397)/0.6428 = 17.5 (3 sf).

"sin⁻¹ gives the only angle"

sin θ = sin(180°−θ). sin⁻¹ gives acute angle (0°–90°). Obtuse possibility = 180° − acute. MUST check if obtuse gives valid triangle (A + B < 180°).

Differentiation

Support (SEN/Lower Ability): Flowchart: Given what? → Which rule? Sine rule template: a/sin A = b/sin B. Highlight known values. Ambiguous case: draw both possibilities with compass.
Stretch (Higher/Gifted): Prove sine rule: drop perpendicular from A to BC. h = c sin B = b sin C → b/sin B = c/sin C. Extend to circumcircle: a/sin A = 2R (R = circumradius). Use sine rule in 3D (spherical trigonometry intro).

Plenary (5 minutes)

Rule Choice

Given: a, b, C → Cosine. A, B, c → Sine. a, b, c → Cosine. a, A, B → Sine. a, b, A → Sine (ambiguous check).

Assessment Criteria

  • Got it: Applies sine rule correctly, identifies and resolves ambiguous case
  • Getting there: Finds sides/angles, misses obtuse possibility in SSA
  • Not yet: Cannot set up sine rule proportion

Lesson 2: Cosine Rule

Duration: 50 minutes

Starter Activity (5 minutes)

Generalising Pythagoras

Pythagoras: c² = a² + b² (C=90°, cos 90°=0). Cosine rule: c² = a² + b² − 2ab cos C. Works for ANY angle.

Main Content (35 minutes)

Teaching Notes:
Cosine rule (three forms):
a² = b² + c² − 2bc cos A
b² = a² + c² − 2ac cos B
c² = a² + b² − 2ab cos C
Pattern: side² = sum of other two sides² − 2(product)cos(included angle).
When to use: SAS (two sides, included angle) → find third side. SSS (three sides) → find any angle.
Finding side: Substitute known sides and included angle. c² = a² + b² − 2ab cos C. Square root.
Finding angle: Rearrange: cos C = (a² + b² − c²) / (2ab). Then C = cos⁻¹(...).
Check: Largest angle opposite largest side. cos θ negative for obtuse angles (>90°).
Worked Example

"Triangle: a=7, b=9, C=60°. Find c." Answer: c² = 7² + 9² − 2×7×9×cos 60° = 49 + 81 − 126×0.5 = 130 − 63 = 67. c = √67 ≈ 8.19.

Worked Example

"Triangle sides 5, 7, 9. Find largest angle." Answer: Largest angle opposite 9. cos C = (5²+7²−9²)/(2×5×7) = (25+49−81)/70 = −7/70 = −0.1. C = cos⁻¹(−0.1) = 95.7° (obtuse).

"Cosine rule: a² = b² + c² − 2bc cos A, so cos A = (b²+c²−a²)/(2bc)"

Correct rearrangement: cos A = (b² + c² − a²) / (2bc). But common error: forget brackets → b²+c²−a²/2bc = b²+c²−(a²/2bc). ALWAYS use brackets!

Differentiation

Support (SEN/Lower Ability): Cosine rule formula card with pattern highlighted. "Side² = sum² − 2×product×cos(angle)". Step-by-step: 1) Label triangle, 2) Choose form, 3) Substitute, 4) Calculate, 5) Square root or cos⁻¹.
Stretch (Higher/Gifted): Prove cosine rule using Pythagoras (drop altitude, split base into x and c−x). Cosine rule in vector form: |a−b|² = |a|²+|b|²−2|a||b|cosθ. Use cosine rule to derive area formula ½ab sin C.

Plenary (5 minutes)

Cosine Rule Check

"Triangle 6, 8, 10. Largest angle?" cos C = (36+64−100)/96 = 0 → C = 90°. Pythagoras check: 6²+8²=10². Right triangle!

Assessment Criteria

  • Got it: Applies cosine rule for sides and angles, rearranges correctly, identifies obtuse angles
  • Getting there: Finds side given SAS, struggles with rearranging for angle
  • Not yet: Cannot identify included angle or substitute correctly

Lesson 3: Choosing Rules and Mixed Problems

Duration: 50 minutes

Starter Activity (5 minutes)

Decision Tree

Right triangle? → Pythagoras/SOHCAHTOA. Non-right? Two angles known? → Sine. Two sides + included angle? → Cosine. Two sides + non-included angle? → Sine (ambiguous). Three sides? → Cosine.

Main Content (35 minutes)

Teaching Notes:
Decision flow:
1. Right angle? → Pythagoras / SOHCAHTOA (G20)
2. No right angle:
- AAS / ASA → Sine rule
- SAS → Cosine rule (find third side), then Sine rule for angles
- SSS → Cosine rule (find largest angle first)
- SSA → Sine rule (check ambiguous case)
Multi-step problems: Often find one missing piece with cosine, then use sine for rest. E.g., SAS → cosine for third side → sine for other angles.
Bearings (G15): Non-right triangles in navigation. Use sine/cosine rules for distances and bearings.
Area of triangle (G23): ½ab sin C (included angle).
Worked Example

"Triangle: a=8, b=12, c=15. Find all angles." Answer: Largest angle C opposite 15. cos C = (64+144−225)/(2×8×12) = −17/192 ≈ −0.0885. C = 95.1°. Sine rule: sin A / 8 = sin 95.1° / 15 → sin A = 8×0.996/15 = 0.531. A = 32.1°. B = 180−95.1−32.1 = 52.8°.

"Always use cosine rule first because it works for everything"

Cosine rule is more complex. Use simplest rule that fits: right triangle → Pythagoras/SOHCAHTOA. AAS/ASA → Sine (simpler). SAS → Cosine then Sine. SSS → Cosine.

Differentiation

Support (SEN/Lower Ability): Decision flowchart card. Practice classifying given info: SSS, SAS, ASA, AAS, SSA. Then choose rule.
Stretch (Higher/Gifted): Problems requiring both rules multiple times. 3D problems: tetrahedron face angles. Prove: "In any triangle, a = b cos C + c cos B" (projection formula).

Plenary (5 minutes)

Mixed Practice

5 quick problems. Students write: "Sine", "Cosine", "Pythagoras", "SOHCAHTOA", or "Ambiguous".

Assessment Criteria

  • Got it: Selects correct rule instantly, solves multi-step problems efficiently
  • Getting there: Eventually chooses right rule, but slow or misses ambiguous case
  • Not yet: Confuses SAS with SSA, or uses Pythagoras on non-right triangles

Lesson 4: Applications and Exam Questions

Duration: 50 minutes

Starter Activity (5 minutes)

3D Triangle

Cuboid. Diagonal of face, space diagonal, edge form triangle. Use cosine rule for angle between diagonals.

Main Content (35 minutes)

Teaching Notes:
3D applications: Identify triangle in 3D. Find its sides (using Pythagoras in 2D slices). Apply sine/cosine rule.
Bearings problems: Two ships/planes from same point. Distances and bearings known. Find distance between them and bearing of one from other. Use cosine rule for distance, sine rule for angles, convert to bearings.
Area of triangle (G23): ½ab sin C. Often combined: find angle with cosine rule, then area.
Exam technique:
- Label triangle clearly (A,B,C and a,b,c)
- State which rule you're using
- Show substitution clearly
- Use brackets in cosine rule!
- Check: largest angle opposite largest side
- Give angles to 1 dp, sides to 3 sf (unless exact)
Worked Example

"Ship A sails 30 km on bearing 040°. Ship B sails 40 km on bearing 130°. Distance between ships?" Answer: Angle between paths = 130°−40° = 90°. Right triangle! Distance = √(30²+40²) = 50 km. Bearing of B from A: tan θ = 40/30 → θ = 53.1°. Bearing = 040° + 53.1° = 093°. (If not 90°, use cosine rule for distance, sine for angle).

Worked Example

"Triangle sides 10, 12, 16. Area?" Answer: Largest angle C opposite 16. cos C = (100+144−256)/(2×10×12) = −12/240 = −0.05. C = 92.9°. Area = ½×10×12×sin 92.9° = 60 × 0.9987 = 59.9.

"Bearing of B from A = bearing of A from B ± 180°" (always works)

Only works if A, B, and North point are collinear (i.e., simple back-bearing). In triangle problems, bearing of B from A ≠ bearing of A from B ± 180° generally. Must use geometry.

Differentiation

Support (SEN/Lower Ability): Provide structured exam question templates. Break into parts: a) Find distance AB, b) Find angle ABC, c) Find bearing. Colour-code steps.
Stretch (Higher/Gifted): Navigation with currents/wind (vector addition + sine/cosine). Three-point resection (find position from three bearings). Spherical cosine rule for great circle distances.

Plenary (5 minutes)

Exam Question Practice

Past paper question combining sine/cosine rules with bearings or 3D. Timed 10 minutes. Peer mark.

Assessment Criteria

  • Got it: Solves exam-style problems combining rules with bearings/3D, clear working
  • Getting there: Solves standalone rule problems, struggles with multi-step applications
  • Not yet: Cannot apply rules to contextual problems

Homework Suggestions

  • Sine and cosine rule worksheet: all cases including ambiguous
  • Past paper Higher questions on sine/cosine rules
  • Bearing problem: "Two radar stations 50 km apart. Bearings of aircraft from stations: 030° and 330°. Find distance of aircraft from each station."
  • Prove sine rule and cosine rule
