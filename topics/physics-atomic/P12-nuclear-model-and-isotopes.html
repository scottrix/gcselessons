P12: Nuclear Model and Isotopes

Foundation Higher All Boards

Understanding the structure of the atom, the nuclear model, and how isotopes differ. Exploring the history of atomic theory and its development.

Lesson Overview

Estimated Lessons: 2
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, CCEA

Learning Objectives

  • Describe the nuclear model of the atom
  • Define atomic number and mass number
  • Explain what isotopes are and how they differ
  • Use notation to represent atoms and isotopes
  • Describe the development of the atomic model historically

Prerequisites

  • Basic knowledge of atoms from KS3 chemistry
  • Understanding of the three subatomic particles
  • Familiarity with the periodic table

Materials & Equipment

  • Scientific calculator
  • Periodic table
  • Coloured balls or modelling clay (for building atoms)
  • Printed cards with atomic data

Lesson 1: Structure of the Atom

Duration: 50 minutes

Starter Activity (5 minutes)

Atom Challenge

Give students the atomic data for carbon-12: 6 protons, 6 neutrons, 6 electrons. Ask them to calculate the atomic number and mass number, then write the symbol notation.

Main Content (35 minutes)

Teaching Notes:
The nuclear model of the atom:
An atom consists of:
- A small, dense nucleus containing protons and neutrons
- Electrons orbit the nucleus in energy levels (shells)
- The nucleus contains almost all the mass of the atom (protons and neutrons each have mass 1, electrons have negligible mass)
- The atom is mostly empty space

Subatomic particles:
ParticleChargeRelative MassLocation
Proton+11Nucleus
Neutron01Nucleus
Electron−1~0 (1/1836)Energy levels

Key definitions:
- Atomic number (Z) = number of protons in the nucleus
- Mass number (A) = total number of protons + neutrons
- Number of neutrons = Mass number − Atomic number
- In a neutral atom: number of electrons = number of protons

Notation:
The symbol for an atom is written as:AZX, where X is the chemical symbol.
For example: 126C (carbon-12), 2311Na (sodium-23)
Worked Example

An atom has 17 protons, 18 neutrons, and 17 electrons.
(a) Atomic number = 17 (number of protons)
(b) Mass number = 17 + 18 = 35
(c) Element = Chlorine (Cl, atomic number 17)
(d) Notation: 3517Cl
(e) This is a chlorine atom (neutral, since electrons = protons = 17)

Common Misconception: Students think the mass number includes electrons. It does not — the mass number counts only protons and neutrons in the nucleus. Electrons have negligible mass.

Differentiation

Support:
Provide a template with the notation format AZX. Students fill in A, Z, and X for given atoms.
Stretch:
An ion has 26 protons, 30 neutrons, and 23 electrons. Identify the element, write its notation, and explain why it is an ion.

Plenary (5 minutes)

Quick Quiz

Students identify the element, number of neutrons, and write the notation for: (a) 8 protons, 8 neutrons (b) 20 protons, 20 neutrons (c) 53 protons, 74 neutrons

Assessment Criteria

  • Got it: Can identify all subatomic particles, calculate atomic/mass numbers, and use notation correctly
  • Getting there: Can identify particles but struggles with notation or calculating neutrons
  • Not yet: Cannot distinguish between protons, neutrons, and electrons or their roles

Lesson 2: Isotopes and Atomic Models

Duration: 50 minutes

Starter Activity (5 minutes)

Same or Different?

Show: 126C and 146C. Ask: "What is the same about these two atoms? What is different? Are they the same element?"

Main Content (35 minutes)

Teaching Notes:
Isotopes are atoms of the same element (same atomic number) with different numbers of neutrons (different mass number).

Key points about isotopes:
- Same number of protons → same element → same chemical properties
- Different number of neutrons → different mass number
- Same number of electrons (in neutral atoms) → same chemical behaviour
- Isotopes have nearly identical chemical properties but different physical properties (e.g., density)

Examples of isotopes:
- Carbon-12 (126C): 6p, 6n, 6e (98.9% of all carbon)
- Carbon-13 (136C): 6p, 7n, 6e (1.1% of all carbon)
- Carbon-14 (146C): 6p, 8n, 6e (radioactive, used in dating)

History of the atomic model:
1. Dalton (1803): Solid sphere model — atoms are indivisible balls
2. Thomson (1904): Plum pudding model — electrons embedded in positive "soup"
3. Rutherford (1911): Nuclear model — small positive nucleus with electrons orbiting
4. Bohr (1913): Electrons orbit in fixed energy levels
5. Modern model: Electron cloud / quantum model — electrons in probability clouds

Key experiments:
- Thomson's cathode ray experiment discovered the electron
- Rutherford's gold foil experiment discovered the nucleus — most alpha particles passed through, some were deflected at large angles
Worked Example

Hydrogen has three isotopes:
- Protium: 11H (1p, 0n, 1e) — most common
- Deuterium: 21H (1p, 1n, 1e) — used in "heavy water"
- Tritium: 31H (1p, 2n, 1e) — radioactive, used in nuclear weapons

All three are hydrogen (atomic number 1) because they each have 1 proton. They differ only in the number of neutrons.

Key Definitions:
Isotope = atoms with the same atomic number but different mass number
Same number of protons, different number of neutrons

Differentiation

Support:
Provide a table of isotopes with some values missing. Students complete the table using the relationship: mass number = protons + neutrons.
Stretch:
Research carbon-14 dating. Explain how the ratio of carbon-14 to carbon-12 in a fossil can be used to estimate its age.

Plenary (5 minutes)

Timeline

Students arrange the five atomic models in chronological order and write one key feature of each in their own words.

Assessment Criteria

  • Got it: Can define isotopes, give examples, and describe the development of the atomic model
  • Getting there: Can define isotopes but cannot describe the historical development of atomic theory
  • Not yet: Cannot distinguish between isotopes or explain the nuclear model

Homework Suggestions

  • Create a poster showing the five historical models of the atom with key scientists and dates
  • Identify the isotopes of oxygen: 168O, 178O, 188O — calculate the number of neutrons in each
  • Research how Rutherford's gold foil experiment led to the nuclear model
  • Write a paragraph explaining why isotopes of the same element have the same chemical properties
