Lesson 2: Core Concepts: skill classification

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on skill classification. Check them against the notes below.

Main Content (35 minutes)

Skill: A learned action with a predetermined result that can be reproduced consistently with minimum effort and time. Skills are developed through practice and experience.
Ability: An innate, inherited trait that underpins skilled performance. Abilities are the building blocks of skills and are largely genetically determined.
Exam Tip: Most skills fall somewhere between the two extremes. A netball chest pass is basic, but adding a defender and deciding when to pass makes it more complex. Context matters.
Key Principle: The more open and externally paced a skill is, the more decision-making is required. Practice should therefore include game-like situations. Closed, self-paced skills can be practised in isolated, repetitive drills.
PE Exam Tips — Skill Classification: 1. For Skill Classification questions, use subject-specific terminology precisely 2. Support every point with specific evidence or examples 3. Practice (10 minutes)

Q: Define the terms 'skill' and 'ability' and explain the relationship between them.

Answer: A skill is a learned action with a predetermined result that can be reproduced consistently with minimum effort. An ability is an innate, inherited trait that underpins skilled performance. The relationship is that abilities form the foundation for skills - without the necessary abilities, a skill cannot be fully developed, and practice turns ability into skill.

Lesson 3: Application: skill classification

Duration: 50 minutes

Starter Activity (5 minutes)

Quick Recall

Recall the key terms: Skill, Ability, Exam Tip. Define each in one sentence.

Main Content (35 minutes)

Parent/Teacher Guide: Let your student attempt each question alone first, then compare with the model answer. Award method marks for correct working even if the final answer is wrong.

Q1: Define the terms 'skill' and 'ability' and explain the relationship between them.

Answer: A skill is a learned action with a predetermined result that can be reproduced consistently with minimum effort. An ability is an innate, inherited trait that underpins skilled performance. The relationship is that abilities form the foundation for skills - without the necessary abilities, a skill cannot be fully developed, and practice turns ability into skill.

Q2: Using a named sporting example, explain the difference between an open skill and a closed skill.

Answer: An open skill is performed in an unpredictable environment and must be adapted to changing conditions. A closed skill is performed in a predictable, stable environment. Example: A football pass is open because the player must adapt to the position of opponents and teammates, the movement of the ball, and the playing surface. A swimming start is closed because the water is still, the blocks are fixed, and the swimmer controls when to dive.

Q3: Classify a golf drive using all four skill classification continua.

Answer: A golf drive: Knapp's continuum - complex (requires coordination of grip, stance, backswing, downswing, follow-through); Open/Closed - closed (stable environment, no opponents interfering); Self/Externally paced - self-paced (golfer decides when to swing); Gross/Fine - mixed (large muscle groups for power, fine wrist/hand control for club face accuracy).

Q4: Why is it important for a coach to understand skill classification when planning practice sessions?

Answer: A coach needs to understand skill classification because it determines the type of practice required. Open and externally paced skills need game-like, variable practice with decision-making. Closed and self-paced skills benefit from fixed, repetitive drills. Complex skills may need to be broken down into sub-routines (part practice), while basic skills can be practised whole.

Q5: Explain the difference between a self-paced skill and an externally paced skill, giving one example of each.

Answer: A self-paced skill is one where the performer controls when to initiate the movement, e.g. a free throw in basketball where the player decides when to shoot. An externally paced skill is one where external factors determine the timing, e.g. returning a tennis serve where the opponent's delivery dictates when the return must be played.

Q6: A gymnastics floor routine is classified as complex and closed. Explain why.

Answer: A gymnastics floor routine is complex because it involves many sub-routines (tumbling, jumps, spins, balances) that must be performed in a precise sequence, requiring high concentration and coordination. It is closed because the environment is predictable - the performer is alone on a set apparatus with no opponents to react to, and the routine follows a predetermined pattern.

Lesson 4: Exam Practice: skill classification

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Review what these command words require: state (one point), describe (say what happens), explain (say why), compare (both sides), evaluate (judgement).

Main Content (35 minutes)

Exam-Style Question

Attempt a past-paper style question on skill classification from the exam board past paper finder (see Resources), then mark it against the scheme.

Exam Tips: Always give sporting examples when classifying skills - marks depend on application | Remember that skills are on a continuum, not either/or - explain where on the continuum | Use the terminology precisely: "open/closed continuum" not "open or closed skill type" | When asked to classify a skill, use all four continua where possible | Link classification to practice type - open skills need variable practice, closed skills need fixed practice | Know the difference between skill and ability - this is a common 2-mark question
Common Errors: Watch Out! Students often treat continua as categories rather than spectrums. Wrong: "A tennis serve is a closed skill." Correct: "A tennis serve is towards the closed end of the open/closed continuum because the server controls the initiation, though the serve must still consider the receiver's position." Students often confuse ability with fitness. Wrong: "Ability is how fit you are." Correct: "Ability is an innate, inherited trait such as balance, coordination or reaction time - it is not the same as fitness."
