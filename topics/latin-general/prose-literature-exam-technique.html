Lesson 2: Core Concepts: prose literature exam technique

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on prose literature exam technique. Check them against the notes below.

Main Content (35 minutes)

Key Fact: Prose literature exams typically test three skills: translation (accurate rendering of the Latin), analysis (identifying language and style features), and evaluation (discussing themes, context, and the author's purpose).
Key Fact: Translation questions require precise, idiomatic English that captures the exact meaning of the Latin. Avoid over-literal or over-free translations.
Key Fact: For analysis questions, name the stylistic feature, quote the Latin, and explain the effect: 'Caesar uses tricolon (lines 4-5) to build a sense of overwhelming force'.
Key Fact: Evaluation questions (8-10 marks) require a structured argument with introduction, multiple points supported by textual evidence, and a conclusion.
Key Fact: Always support your answers with specific Latin quotations from the set text — vague references like 'Caesar says they were brave' earn no marks without the Latin.
Key Fact: Context questions ask about the historical background: who, when, why, and what was happening. Prepare notes on the author's life, the period, and the work's purpose.

Main Content (35 minutes)

Exam-Style Question

Attempt a past-paper style question on prose literature exam technique from the exam board past paper finder (see Resources), then mark it against the scheme.

Exam Tips: Always PEA: Point, Evidence (Latin quote), Analysis (effect). Never make a point without supporting it with Latin. | For translation, aim for accuracy first, then idiom. A translation that is wrong but sounds good scores less than one that is accurate but slightly awkward. | Prepare a 'toolkit' of stylistic features for each set text author: know their characteristic devices before the exam. | In the exam, underline key words in the question and check each paragraph of your answer against them.
Common Errors: ✗ You can answer literature questions in general terms without quoting the Latin. ✓ Every analytical point must be supported by a specific Latin quotation from the set text. General observations without textual evidence will not score above basic level. ✗ A good summary of the passage is sufficient for an analysis question. ✓ Summary (telling the story) scores very few marks. Analysis requires you to identify specific language and style features and explain their effects on the reader. ✗ You should write everything you know about the author in a context question. ✓ Only include context that is relevant to the specific question.
