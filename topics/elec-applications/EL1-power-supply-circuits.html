EL1: Power Supply Circuits

Foundation Higher Eduqas

Rectification (half/full wave), smoothing, regulation (linear, switching), voltage references, protection circuits.

EL2: Audio and Signal Processing →

Lesson Overview

Estimated Lessons: 2-3
Tier: Foundation and Higher
Duration: 50 minutes per lesson (+ practical time where applicable)
Exam Board: Eduqas

Learning Objectives

  • Understand the principles and theory behind power supply circuits
  • Analyse and design circuits involving power supply circuits
  • Build, test, and troubleshoot practical circuits
  • Apply relevant formulae and interpret results
  • Communicate technical information using standard symbols and notation

Prerequisites

  • Basic electrical quantities: charge, current, voltage, resistance, power
  • Ohm's law and Kirchhoff's laws
  • Component symbols and schematic reading
  • Use of multimeter and breadboard
  • For digital topics: binary, logic gates, truth tables

Materials & Equipment

  • Breadboards, jumper wires, wire strippers, cutters
  • Component kits: resistors (E12/E24 series), capacitors, diodes, transistors (BJT, MOSFET)
  • ICs: 555 timer, 741 op-amp, 7400/74LS00 series logic gates, microcontroller (Arduino/PIC)
  • Sensors: LDR, thermistor, LM35, microphone, IR receiver
  • Test equipment: multimeter, oscilloscope, function generator, logic probe
  • Power supplies: benchtop PSU, battery packs (5V, 9V, 12V)
  • PCB design software (KiCad, Eagle) and/or stripboard for permanent circuits

Lesson 1: Theory and Circuit Analysis

Duration: 50 minutes

Starter Activity (5 minutes)

Circuit Recognition

Show schematic fragments. Students identify: circuit type, key components, expected behaviour.

Main Content (35 minutes)

Teaching Notes:
Cover the theoretical foundation for power supply circuits: • Underlying physics principles
• Component models and characteristics
• Key equations and design formulae
• Standard circuit configurations
• Performance metrics and limitations
Worked Example: Circuit Analysis

Step-by-step analysis of a representative power supply circuits circuit. Calculate all node voltages, branch currents, power dissipation. Show multimeter/oscilloscope measurement points.

Key design equations for power supply circuits — students must be able to select, rearrange, and apply.

Common Misconception

A typical student error in circuit analysis or component behaviour.

Correct understanding with reference to component physics and circuit laws.

Differentiation

Support:
Provide circuit templates with component values. Use circuit simulator (Falstad, EveryCircuit) for visualisation. Colour-code schematic by function.
Stretch:
Design a circuit to meet a specification. Compare topologies. Analyse tolerance effects. Simulate in SPICE.

Plenary (5 minutes)

Circuit Function

Given a schematic, students write 3 sentences: what it does, how it works, one limitation.

Assessment Criteria

  • Got it: Explains operation, calculates correctly, predicts behaviour under changes.
  • Getting there: Follows analysis steps but makes arithmetic or conceptual errors.
  • Not yet: Cannot identify circuit type or apply basic laws. Reteach with simpler circuit.

Lesson 2: Practical Implementation and Testing

Duration: 50-100 minutes (includes build time)

Starter Activity (5 minutes)

Component Check

Students identify components from a kit using colour codes, markings, and datasheets. Verify values with multimeter.

Main Content (40-85 minutes)

Teaching Notes:
Guided build → test → analyse cycle:
1. Layout planning: Breadboard mapping, power rail assignment, signal flow
2. Assembly: Component placement, lead forming, secure connections
3. Pre-power check: Visual inspection, continuity, short-circuit test
4. Power-up and measurement: Systematic testing at each test point
5. Characterisation: Vary inputs, record outputs, plot graphs
6. Fault finding: If not working — systematic debug (power, connections, component values, orientation)
Build Guide: Power Supply Circuits

Schematic with breadboard layout overlay. Test point labels. Expected readings table. Troubleshooting checklist.

Maths Skills

Relevant calculations: power supply circuits formulae, percentage error, uncertainty propagation, graph gradients, log scales.

Differentiation

Support:
Pre-cut wires, labelled breadboard template, step-by-step photo guide, buddy system with confident peer.
Stretch:
Modify circuit for new specification. Add indicator LED. Interface with microcontroller. Design PCB layout.

Plenary (5 minutes)

Results Review

Compare experimental vs theoretical values. Discuss discrepancies: tolerance, temperature, measurement loading, breadboard parasitics.

Assessment Criteria

  • Got it: Circuit works, measurements accurate, results table complete, graphs plotted correctly, anomalies discussed.
  • Getting there: Circuit functions with help, measurements mostly correct, minor recording errors.
  • Not yet: Circuit doesn't function, cannot use test equipment. Revisit breadboarding basics.

Homework Suggestions

  • Complete textbook/exam questions on power supply circuits
  • Simulate the circuit in Falstad/EveryCircuit/LTSpice — vary parameters, observe effects
  • Design a circuit variant: change one component to achieve a different specification
  • Write a practical report: aim, method, results, analysis, conclusion, evaluation
  • Research a real-world application of power supply circuits — present as 3-slide summary
