Worked Example 1: Basic

Q: ✗ Describing a closed-loop system as having no feedback. ✓ A closed-loop system uses feedback from the output to correct errors; open-loop systems have no feedback.

  1. What is asked? Explain
  2. Recall knowledge:
  3. Apply: ✗ Confusing ADC and DAC functions. ✓ An ADC converts analogue signals to digital (for reading sensors); a DAC converts digital to analogue (for driving actuators). ✗ Assuming a microcontroller can read analogue sensors directly without an ADC. ✓ Analogue sensor voltages must be converted to digital by the ADC peripheral before the microcontroller processor can use them.

📝 Mark Scheme Guidance

How examiners mark EL3: Read the command word carefully — State = one word/phrase (1 mark), Describe = pattern or detail (2 marks), Explain = reason with "because" (2–3 marks), Compare = similarities AND differences, Evaluate = both sides + conclusion. Method marks are awarded for correct working even if the final answer is wrong. Always show your working — unexplained answers score zero for AO2.

Success on EL3 questions: Underline the command word, count the marks (one mark per point expected), and answer in the format the command word demands.
