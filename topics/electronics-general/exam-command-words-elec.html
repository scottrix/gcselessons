Lesson 2: Core Concepts: command words &amp; question types

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on command words &amp; question types. Check them against the notes below.

Main Content (35 minutes)

Key Fact: 'State' requires a brief factual answer without explanation; just give the fact or definition directly.
Key Fact: 'Describe' requires saying what happens or what a process is, without explaining why it happens.
Key Fact: 'Explain' requires giving reasons — say what happens and why, linking cause and effect in your answer.
Key Fact: 'Compare' requires stating similarities and differences between two or more things; use comparative language.
Key Fact: 'Calculate' requires showing a numerical method: write the formula, substitute values and give the final answer with units.
Key Fact: 'Evaluate' requires making a judgement using evidence; weigh up strengths and weaknesses and reach a supported conclusion.

Lesson 4: Exam Practice: command words &amp; question types

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Review what these command words require: state (one point), describe (say what happens), explain (say why), compare (both sides), evaluate (judgement).

Main Content (35 minutes)

Exam-Style Question

Attempt a past-paper style question on command words &amp; question types from the exam board past paper finder (see Resources), then mark it against the scheme.

Exam Tips: Underline the command word and the key subject in each question before you start writing. | For 'explain' questions, use 'because', 'therefore' or 'due to' to clearly link cause and effect. | In 'compare' answers, use a structured format: point about A, then matching point about B, for each feature. | For 'calculate' questions, always show your working — marks are awarded for the method, not just the answer. | Match the length of your answer to the marks: 1 mark = one sentence; 4 marks = four developed points.
Common Errors: ✗ Explaining when the question only asks you to state. ✓ If the command word is 'state', give a brief factual answer only; save time by not adding unnecessary explanation. ✗ Describing when the question asks you to explain. ✓ 'Explain' requires reasons and cause-effect links; just saying what happens (describing) will not gain full marks. ✗ Listing features separately instead of comparing them side by side. ✓ For 'compare' questions, present each point as a direct comparison: 'A does X whereas B does Y.' ✗ Giving a one-word answer to a 3-mark question. ✓ Check the mark allocation; a 3-mark question needs three distinct points or steps of working.
