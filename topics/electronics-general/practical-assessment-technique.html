Lesson 2: Core Concepts: practical assessment technique

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on practical assessment technique. Check them against the notes below.

Main Content (35 minutes)

Key Fact: The practical assessment requires you to build, test and document a circuit under controlled conditions within a set time.
Key Fact: Read the task brief completely before starting; identify the circuit to build, the measurements required and the documentation expected.
Key Fact: Plan your construction before building: identify components, plan the breadboard layout and check you have all parts.
Key Fact: Build the circuit methodically, section by section, and visually inspect each connection before powering on.
Key Fact: Always check the power supply voltage and polarity before connecting it to your circuit to prevent component damage.
Key Fact: Take measurements systematically: start with the power supply voltage, then measure key node voltages and signal levels.

Main Content (35 minutes)

Extended Answer

Extended question: Full-Mark Response Describe how to approach a practical circuit assessment, from reading the task brief to submitting your documented work, explaining how to maximise marks at each stage. <div class="

Maximising marks in a practical assessment requires a disciplined approach across three phases. First, read the entire task brief carefully, identifying what circuit to build, what measurements to record and what documentation is expected. Plan your time: roughly 40% for building, 30% for testing and 30% for documentation. Second, during construction, plan the breadboard layout before inserting components. Build the circuit section by section, performing a visual inspection after each stage to check component values, orientation (especially ICs, electrolytic capacitors and diodes) and connections. Before powering on, verify the supply voltage and polarity. Third, during testing, measure the power supply voltage first, then systematically measure node voltages from input to output. Record every measurement immediately in a clear table showing the quantity, expected value, measured value and correct SI units. If the circuit fails, use the half-split method to locate the fault: check power, then measure at the midpoint and narrow down. Fourth, for documentation, draw a neat circuit diagram with all component values and reference designators, include the completed measurement table and

Exam Tips: Read the brief fully, then plan your approach before touching any components. | Build section by section and test each stage as you go, rather than building the whole circuit at once. | Always measure the power supply voltage first before checking any other part of the circuit. | Record measurements as you take them — do not rely on memory to fill in the table later. | If a fault occurs, stay calm and use the half-split method: check at the midpoint, then narrow down.
Common Errors: ✗ Starting to build the circuit without reading the full task brief. ✓ Read the entire brief first, identify all requirements and plan your time allocation before beginning construction. ✗ Powering on the circuit without a visual inspection of connections and component orientation. ✓ Always inspect the circuit visually first: check polarised components (ICs, electrolytic capacitors, diodes) and verify all connections match the circuit diagram. ✗ Recording measurements without units or without noting the expected values. ✓ Use a table with columns for quantity, expected value, measured value and units; this allows comparison and shows the examiner your method. ✗ Spending too long on building
