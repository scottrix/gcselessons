L4: Theme Analysis

Foundation Higher All Boards

Develop your understanding of theme analysis for GCSE English Literature with detailed teaching notes, model analysis, and practice tasks.

Lesson Overview

Estimated Lessons: 2
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, Eduqas, CCEA

Learning Objectives

  • Understand key concepts related to theme analysis
  • Analyse how writers use techniques to create effects
  • Write analytical paragraphs using evidence
  • Link analysis to context and themes

Prerequisites

  • Basic understanding of literary analysis
  • Ability to select evidence from texts

Materials & Equipment

  • Set text copies
  • Analysing literature vocabulary list
  • Notebooks for written responses
  • Model analytical paragraphs

Lesson 1: Introduction

Duration: 50 minutes

Starter Activity (5 minutes)

Prior Knowledge

What do you already know about theme analysis? Discuss as a class and create a mind map of initial ideas on the board.

Main Content (35 minutes)

Teaching Notes:
Introduce the key concepts of theme analysis. Cover the fundamental skills students need:
  • Identify and explain key terminology
  • Recognise how writers use specific techniques
  • Begin to explain the effect on the reader
  • Link observations to the wider text
Use model examples to demonstrate analytical writing. Focus on building from identification to explanation.
Worked Example

Model an analytical paragraph demonstrating the skills covered in this lesson. Show the process of moving from observation to analysis.

Practice Task

Apply the skills learned in this lesson to a passage from your set text. Write an analytical paragraph of 8-10 sentences.

Model answer demonstrating the skills and techniques taught in this lesson.

Differentiation

Support:
Provide sentence starters and a vocabulary glossary. Work through examples together before independent practice.
Stretch:
Challenge students to write without sentence starters and to include contextual links.

Plenary (5 minutes)

Key Learning

What are the three most important things you learned today? Write them on a mini-whiteboard.

Assessment Criteria

  • Got it: Can identify and analyse key features with detailed explanation
  • Getting there: Can identify features but explanation is developing
  • Not yet: Struggles to identify key features without support

Lesson 2: Developing Analytical Skills

Duration: 50 minutes

Starter Activity (5 minutes)

Recap

Quick quiz on key concepts from Lesson 1. Students write answers on mini-whiteboards.

Main Content (35 minutes)

Teaching Notes:
Build on Lesson 1 by developing analytical depth:
  • Move from 'what' to 'why' and 'how'
  • Use subject terminology accurately
  • Develop the PEER technique (Point, Evidence, Explain, Reader response)
  • Begin to consider the writer's choices and their effects
Worked Example

Show how to develop analytical writing from identification to detailed explanation with reader response.

Practice Task

Write two analytical paragraphs about a passage from your set text, using the techniques developed in this lesson.

Model answer showing developed analytical writing.

Differentiation

Support:
Provide an analytical writing frame (P-E-E-R structure). Model the thinking process aloud.
Stretch:
Write a comparative paragraph linking two moments in the text.

Plenary (5 minutes)

Self-Assessment

Students read their own paragraph and check: Clear point? Evidence? Detailed explanation? Reader response?

Assessment Criteria

  • Got it: Writes detailed analytical paragraphs with evidence, explanation, and reader response
  • Getting there: Shows development but may miss reader response
  • Not yet: Still identifies rather than analyses

Homework Suggestions

  • Read and annotate a section of the set text focusing on theme analysis
  • Write an analytical paragraph using the skills learned
  • Create a glossary of key terms related to theme analysis
