AD11: Typography & Layout

Foundation Higher All Boards

Master the fundamentals of typography and layout design. Learn font classification, hierarchy, grid systems, and compositional principles to create effective graphic communications across print and digital media.

Lesson Overview

Estimated Lessons: 5
Tier: Foundation and Higher
Duration: 60 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, CCEA, WJEC
Practical: Yes

Learning Objectives

  • Classify typefaces and select appropriate fonts for context
  • Apply typographic hierarchy: scale, weight, colour, position
  • Construct and use grid systems for layout organisation
  • Understand readability, legibility, and accessibility principles
  • Create cohesive multi-page layouts with consistent systems

Prerequisites

  • Basic computer literacy and design software access (Canva, Figma, Adobe, or hand-drawn)
  • Understanding of basic design principles (contrast, alignment, repetition, proximity)
  • Sketchbook for typographic sketches and notes

Materials & Equipment

  • Digital: Computer/laptop, design software (Figma free, Canva free, Adobe Creative Cloud, or Inkscape/GIMP free), Google Fonts/Adobe Fonts access
  • Analogue: Layout paper, tracing paper, fineliners (0.1-0.8mm), rulers, set squares, scalpels, cutting mat, mounting board
  • Reference: Typography books (Bringhurst, Lupton, Spiekermann), printed specimens, letterpress samples if available
  • Printing: Access to colour printer (A3 ideal), paper stocks (coated, uncoated, coloured)
  • Space: Desk space for analogue work, screen calibration for digital, good lighting
  • Safety: Scalpel safety (cutting mat, ruler guard, blade disposal), screen breaks (20-20-20 rule), ergonomics

Lesson 1: Type Classification & Anatomy

Duration: 60 minutes

Warm-up (10 minutes)

Font Hunt

In 5 minutes, find 10 different typefaces in the room (books, packaging, posters, screens). Photograph/sketch. Classify each: Serif, Sans-serif, Slab, Script, Display, Monospace.

Skill Development (35 minutes)

Teaching Notes:
Type anatomy and classification:
  • Anatomy: Baseline, x-height, cap height, ascender, descender, counter, bowl, stem, serif (bracketed/unbracketed), terminal, spur, ear, link, loop. Learn 20 key terms.
  • Classification (Vox-ATypI): Humanist, Garalde, Transitional, Didone, Slab Serif, Lineale (Grotesque, Neo-grotesque, Geometric, Humanist), Script, Graphic, Display.
  • Personality & Connotation: Serif = tradition, authority, readability. Sans = modern, clean, neutral. Script = elegance, personal. Display = impact, personality. Context matters.
  • Pairing Principles: Contrast (serif/sans), Concord (same family), Conflict (avoid similar but different). Max 2-3 faces per project.

Required Practical: Type Specimen Portfolio

Create 6 specimen pages (A5 each): 1. Anatomical diagram (labelled) 2. Classification chart (examples + characteristics) 3. 5 font pairs with rationale 4. Historical timeline (10 key typefaces) 5. Expressive word settings (same word, 10 personalities) 6. Personal "font palette" (5 faces you'll use + why).

Common Misconception

"More fonts = more creative"

Constraint breeds creativity. Professional work typically uses 1-2 type families (with weights/styles). Mastery = doing MORE with LESS.

Differentiation

Support: Provide anatomy diagram template. Pre-selected font pairs to analyse. Limited to 3 classifications.
Stretch: Design a custom letterform (modular or hand-drawn). Research type design process (Bézier curves, spacing, kerning). Create a type specimen poster for one font.

Creative Work (10 minutes)

Expressive Typography

Set the word "LOUD" quietly, "quiet" loudly, "fast" slowly, "slow" quickly. Type only — no images. 2 min each.

Reflection (5 minutes)

Font Personality

Choose one font. Write 3 adjectives describing its personality. Find a brand using it. Does it match?

Assessment Criteria

  • Technical Skill: Accurate anatomy labelling, correct classification, clean specimens
  • Creativity: Inventive expressive settings, thoughtful pairings
  • Understanding: Articulate rationale, historical awareness, connotation sensitivity
  • Presentation: Professional specimen pages, consistent format, clear hierarchy

Lesson 2: Hierarchy & Grid Systems

Duration: 60 minutes

Warm-up (10 minutes)

Hierarchy Deconstruction

Printed magazine spread. Students annotate: 1. What do you read FIRST? 2. SECOND? 3. THIRD? How is this achieved? (Scale, weight, colour, position, space, style)

Skill Development (35 minutes)

Teaching Notes:
Hierarchy and grids:
  • Hierarchy Tools: Scale (size), Weight (bold/light), Colour (contrast), Position (top/left/centre), Space (isolation), Style (italic, caps, underline). Combine for levels.
  • Grid Anatomy: Margins, columns, gutters, modules, flowlines, fields. Types: Manuscript, Column, Modular, Hierarchical, Baseline.
  • Grid Construction: Paper size → margins → columns (2,3,4,6,12) → gutters (3-6mm) → modules → baseline grid (leading).
  • Breaking the Grid: Intentional disruption for emphasis. Know rules before breaking.
  • Responsive/Digital: Fluid grids, breakpoints, CSS grid/flexbox concepts.

Required Practical: Grid & Hierarchy Exercises

1. Design 3 grids (A5): 3-column, 4-column, modular (4x4). Show measurements. 2. Same content (headline, subhead, body, caption, quote) set in each grid. 3. Annotate: how hierarchy changes with grid. 4. Choose best for a magazine article — develop to finished spread.

Common Misconception

"Grids restrict creativity"

Grids ENABLE creativity by handling alignment/organisation automatically. You spend energy on CONTENT decisions, not "where does this go?"

Differentiation

Support: Pre-drawn grid templates. Content provided. Focus on 2-column grid only.
Stretch: Design a complex modular grid for a 16-page brochure. Show how it adapts across spreads. Create baseline grid aligned typography.

Creative Work (10 minutes)

Grid Break

Take your best grid spread. Intentionally break the grid in 3 places for emphasis. Annotate why each break works.

Reflection (5 minutes)

Grid Reflection

Which grid felt most natural? Why? How does column count affect reading rhythm?

Assessment Criteria

  • Technical Skill: Accurate grid construction, consistent application, clean execution
  • Creativity: Effective hierarchy, purposeful grid breaks, visual interest
  • Understanding: Clear hierarchy rationale, grid theory knowledge
  • Presentation: Precise measurements, annotated comparisons, finished spread

Lesson 3: Readability, Legibility & Accessibility

Duration: 60 minutes

Warm-up (10 minutes)

Readability Test

Print same text: 8pt/10pt/12pt/14pt, tight/normal/wide leading, narrow/wide measure, low/high contrast. Students read at distance. Record comfort/speed.

Skill Development (35 minutes)

Teaching Notes:
Technical typography:
  • Readability vs Legibility: Readability = ease of reading extended text. Legibility = distinguishability of individual characters.
  • Key Factors: Font choice (open counters, generous x-height), size (min 9pt print, 16px screen), leading (1.2-1.5x size), measure (45-75 chars/line), contrast (WCAG AA 4.5:1, AAA 7:1), alignment (left-aligned for LTR languages).
  • Accessibility: Dyslexia-friendly fonts (avoid mirrored forms), sufficient contrast, scalable text, avoid justified text (rivers), clear hierarchy for screen readers.
  • Micro-typography: Kerning (pair spacing), tracking (overall spacing), ligatures, old-style figures, small caps, punctuation hanging.

Required Practical: Accessibility Audit & Fix

Find a poorly designed text-heavy page (menu, poster, webpage). Audit: measure size, leading, measure, contrast, font. Redesign fixing all issues. Present before/after with WCAG compliance notes. Test with peer.

Common Misconception

"Justified text looks more professional"

Justified text creates uneven word spacing ("rivers") harming readability. Left-aligned (ragged right) is standard for body text. Justified only with hyphenation + expert spacing control.

Differentiation

Support: Provide audit checklist. Pre-selected problematic text. Focus on 3 fixes: size, leading, alignment.
Stretch: Research WCAG 2.2 guidelines. Test designs with screen reader (NVDA/VoiceOver). Design for colour-blind simulation (protanopia/deuteranopia).

Creative Work (10 minutes)

Micro-typography Detail

Set a paragraph with: proper quotes ("smart quotes"), en/em dashes, old-style figures, ligatures, hanging punctuation. Compare to default.

Reflection (5 minutes)

Detail Spotting

Exchange audits. Spot one micro-typography detail peer missed. One detail they caught that you missed.

Assessment Criteria

  • Technical Skill: Accurate measurements, WCAG compliance, micro-typography control
  • Creativity: Accessible design that's also visually engaging
  • Understanding: Deep technical knowledge, user-centred thinking
  • Presentation: Clear audit, professional redesign, compliance documentation

Lesson 4: Multi-Page Layout Systems

Duration: 60 minutes

Warm-up (10 minutes)

Pagination Analysis

Examine a 8+ page brochure/magazine. Map: master pages, recurring elements, variation within system, navigation aids (page numbers, running heads, folios).

Skill Development (30 minutes)

Teaching Notes:
Multi-page systems:
  • Master Pages/Templates: Automatic elements (grid, folios, running heads, margins). Override for exceptions.
  • Consistency vs Variety: System = consistent structure. Variety = content-driven layout changes within system.
  • Navigation: Page numbers, section markers, running heads/feet, table of contents, thumb indexes.
  • Print Production: Facing pages (spreads), bleed (3mm), slug, creep (saddle stitch), imposition, colour separation (CMYK), spot colours.

Required Practical: Mini Publication

Design 8-page booklet (A5, saddle stitch): Cover, contents, 4 content spreads, back cover. Real or simulated content. Master page setup. Grid system. Consistent typography. Print mock-up (folded, trimmed). Document: grid, styles, master pages, print specs.

Creative Work (15 minutes)

Cover Variations

Design 3 cover concepts for your booklet. Same grid, different typographic treatment. 5 min each.

Reflection (5 minutes)

System Check

Check: Does every page align to grid? Are styles consistent? Do folios work on all pages? Any widows/orphans?

Assessment Criteria

  • Technical Skill: Master page usage, print specs correct, consistent styles
  • Creativity: Engaging cover, varied but systematic interior
  • Understanding: Production awareness, system thinking, navigation clarity
  • Presentation: Printed mock-up, digital file organised, spec sheet

Lesson 5: Brand Typography Application

Duration: 60 minutes

Warm-up (5 minutes)

Brand Font Audit

Analyse 3 brands' typography across touchpoints (logo, web, packaging, ads). How consistent? What flexibility?

Skill Development (20 minutes)

Teaching Notes:
Typography in branding:
  • Brand Type System: Primary (logo/headlines), Secondary (body/UI), Tertiary (captions/legal). Web-safe fallbacks.
  • Guidelines: Usage rules (sizes, colours, spacing, don'ts), pairings, hierarchy examples, digital/print specs.
  • Variable Fonts: Single file, multiple axes (weight, width, slant, optical size). Future-proofing.
  • Motion/Interaction: Kinetic typography principles, hover states, loading, transitions.

Required Practical: Brand Type Guidelines

Create 2-page type guidelines for a fictional brand: Brand personality (3 words) → Primary/Secondary faces with specimens → Hierarchy examples (H1-H4, body, caption) → Colour usage → Spacing rules → Do/Don't examples → Digital specs (web font, fallbacks, variable font axes).

Creative Work (25 minutes)

Touchpoint Application

Apply guidelines to 3 touchpoints: website hero, Instagram post, packaging label. Use same type system, adapt to format.

Reflection (10 minutes)

Guideline Review

Swap guidelines. Peer tests: "Can I implement this without asking questions?" Note ambiguities. Revise.

Assessment Criteria

  • Technical Skill: Complete guidelines, accurate specs, consistent application
  • Creativity: Distinctive brand voice, flexible but coherent system
  • Understanding: Cross-media awareness, implementation practicality
  • Presentation: Professional guidelines document, applied examples

Homework Suggestions

  • Complete mini publication printing and binding
  • Daily typography photo journal: 1 interesting type use per day for 2 weeks
  • Redesign a local business's typography (menu, signage, card) — full case study
  • Learn keyboard shortcuts for your design software — speed = flow
  • Read "Thinking with Type" (Ellen Lupton) or "The Elements of Typographic Style" (Robert Bringhurst)
