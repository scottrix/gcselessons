Lesson 2: Core Concepts: memory

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on memory. Check them against the notes below.

Main Content (35 minutes)

Key Fact: Memory is the process of encoding, storing and retrieving information. Encoding converts sensory input into a storable form; storage retains it; retrieval accesses it when needed.
Key Fact: The Multi-Store Model (Atkinson & Shiffrin, 1968): Sensory memory (brief, capacity limited by senses) -> Short-term memory (limited capacity 7+/-2 items, duration ~30 seconds) -> Long-term memory (potentially unlimited capacity and duration) via rehearsal.
Key Fact: Types of LTM: Episodic (personal experiences, e.g. your first day at school), Semantic (facts and knowledge, e.g. Paris is the capital of France), Procedural (skills and actions, e.g. riding a bike).
Key Fact: Eyewitness testimony is unreliable: Loftus & Palmer (1974) showed leading questions distort recall - participants estimated faster speeds when verbs like 'smashed' were used. Anxiety, weapon focus and post-event discussion also reduce accuracy.
Key Fact: Improving memory: elaborative rehearsal (linking new info to existing knowledge), chunking (grouping items), and mnemonic devices enhance encoding and retrieval.
Psychology Exam Tips: When evaluating memory research, use the GRAVE framework: Generalisability, Reliability, Applications, Validity, Ethics. Always compare lab studies (high control, low ecological validity) with real-world studies (high ecological validity, less control).

Practice (10 minutes)

Q: Describe the multi-store model of memory and evaluate its strengths and limitations.

Answer: The MSM provides a clear, testable framework: evidence supports the distinction between STM and LTM (case of HM, primacy-recency effect). Limitations: it oversimplifies memory - STM and LTM are not unitary stores (WMM shows STM has multiple components); rehearsal is not the only way to transfer to LTM (flashbulb memories).

Explain Back

Lesson 3: Application: memory

Duration: 50 minutes

Starter Activity (5 minutes)

Quick Recall

Recall the key terms: Psychology Exam Tips. Define each in one sentence.

Main Content (35 minutes)

Parent/Teacher Guide: Let your student attempt each question alone first, then compare with the model answer. Award method marks for correct working even if the final answer is wrong.

Q1: Describe the multi-store model of memory and evaluate its strengths and limitations.

Answer: The MSM provides a clear, testable framework: evidence supports the distinction between STM and LTM (case of HM, primacy-recency effect). Limitations: it oversimplifies memory - STM and LTM are not unitary stores (WMM shows STM has multiple components); rehearsal is not the only way to transfer to LTM (flashbulb memories).

Q2: Explain how leading questions can affect the accuracy of eyewitness testimony, referring to Loftus & Palmer's research.

Answer: Loftus & Palmer showed verb manipulation ('smashed' vs 'hit') changed speed estimates by up to 10 mph. This demonstrates that leading questions alter memory through response bias or actual memory distortion. However, real-world eyewitness testimony may be more accurate than lab studies due to higher anxiety and real consequences.

Q3: Compare and contrast episodic, semantic and procedural long-term memory.

Answer: Episodic: personal events, time-stamped, consciously recalled. Semantic: general facts, not time-stamped, consciously recalled. Procedural: skills/habits, not consciously recalled. All three are distinct LTM types with different brain regions.

Lesson 4: Exam Practice: memory

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Review what these command words require: state (one point), describe (say what happens), explain (say why), compare (both sides), evaluate (judgement).

Main Content (35 minutes)

Extended Answer

Extended question: Full-Mark Response Evaluate the usefulness of the multi-store model of memory for understanding how we remember and forget. <div class="

A grade 9 response will: outline the MSM with evidence (case of HM supports STM/LTM distinction, primacy-recency effect); evaluate strengths (clear framework, testable predictions, supported by brain scanning); evaluate limitations (oversimplifies STM and LTM, ignores working memory, doesn't explain procedural memory); conclude: the MSM was foundational and is supported by key evidence, but it is now considered an incomplete explanation - the Working Memory Model and LTM subtypes offer more comprehensive accounts of specific memory processes.

Exam Tips: STM has a capacity of 7+/-2 items and a duration of about 30 seconds. | Eyewitness testimony is unreliable - always mention Loftus & Palmer when discussing EWT. | Episodic = events you experienced. Semantic = facts you know. Procedural = things you can do.
Common Errors: Watch Out! Students often make mistakes here. Wrong: The multi-store model fully explains how memory works because it shows information flows from sensory to short-term to long-term memory. Correct: While the MSM describes a basic flow of information, it fails to account for: working memory (Baddeley & Hitch showed STM has multiple components), different types of LTM (episodic, semantic, procedural), and the fact that some memories form without conscious rehearsal (e.g. flashbulb memories). The model is a useful starting point but is oversimplified.
