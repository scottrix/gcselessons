C29: Testing for Ions and Gases

Foundation All Boards

Describe flame tests for cations, tests for carbonate, sulfate, chloride and ammonium ions, and tests for common gases.

Lesson Overview

Estimated Lessons: 2
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, CCEA

Learning Objectives

  • Describe flame tests for identifying cations
  • Describe tests for carbonate, sulfate, chloride and ammonium ions
  • Describe tests for hydrogen, oxygen, carbon dioxide, chlorine and ammonia gases

Prerequisites

  • Atomic Structure (C1) — ions, electron arrangements
  • Bonding (C5) — ionic compounds

Lesson 1: Flame Tests and Ion Tests

Duration: 50 minutes

Starter Activity (5 minutes)

Fireworks

Fireworks produce different colours: red, green, blue, yellow. Where do these colours come from? (Different metal compounds produce different colours when heated.)

Main Content (35 minutes)

Teaching Notes:
Flame tests identify metal cations by the colour they produce when heated in a flame. Clean a platinum/nichrome wire loop, dip in hydrochloric acid (to clean it), then dip in the solution and hold in a Bunsen burner flame.

Flame test colours:
• Lithium (Li⁺): red/crimson
• Sodium (Na⁺): yellow/orange
• Potassium (K⁺): lilac (purple)
• Calcium (Ca²⁺): orange-red
• Copper (Cu²⁺): green/blue-green
• Barium (Ba²⁺): green

Tests for anions:

Carbonate (CO₃²⁻):
Add dilute hydrochloric acid → effervescence (fizzing) → bubble gas through limewater → turns milky. This confirms CO₂ is produced, which confirms carbonate.

Sulfate (SO₄²⁻):
Add barium chloride solution → white precipitate forms (barium sulfate). The precipitate does not dissolve in acid.
Ba²⁺(aq) + SO₄²⁻(aq) → BaSO₄(s)

Chloride (Cl⁻):
Add silver nitrate solution → white precipitate forms (silver chloride). The precipitate dissolves in dilute ammonia solution.
Ag⁺(aq) + Cl⁻(aq) → AgCl(s)

Bromide (Br⁻):
Add silver nitrate solution → cream precipitate (silver bromide). Partially dissolves in ammonia.

Iodide (I⁻):
Add silver nitrate solution → yellow precipitate (silver iodide). Does not dissolve in ammonia.

Ammonium (NH₄⁺):
Add sodium hydroxide solution and warm → ammonia gas produced (turns damp red litmus paper blue).
Flame test procedure

1. Clean platinum wire in hydrochloric acid and heat until no colour
2. Dip clean wire in the solution
3. Hold in blue Bunsen flame
4. Observe the colour produced
5. Clean wire between each test

Sulfate test

Add BaCl₂ to the unknown solution. White precipitate = sulfate present (BaSO₄ is insoluble). Add dilute HCl — precipitate stays = definitely sulfate. If precipitate dissolves, it might be a different precipitate (e.g. barium carbonate).

Flame test colours:
Li = red, Na = yellow, K = lilac, Ca = orange-red, Cu = green, Ba = green

Carbonate: acid → CO₂ → limewater turns milky
Sulfate: BaCl₂ → white precipitate (BaSO₄)
Chloride: AgNO₃ → white precipitate (AgCl), soluble in ammonia
Ammonium: NaOH + warm → NH₃ gas (blue litmus)

Common Misconception

Flame tests work for all ions.

Flame tests only work for metal cations (positive ions). Anions (negative ions) do not produce characteristic flame colours. Anions are identified by precipitate reactions (e.g. silver nitrate for halides, barium chloride for sulfates).

Differentiation

Support:
Provide a summary table: Ion | Test | Observation | Conclusion. Fill in together.
Stretch:
Why is the wire cleaned in hydrochloric acid before each test? What would happen if you didn't clean it?

Plenary (5 minutes)

A solution gives a yellow flame test and a white precipitate with barium chloride. What ions does it contain?

Assessment Criteria

  • Got it: Describes flame tests and ion tests accurately, and can identify unknown ions from test results.
  • Getting there: Knows some flame test colours but cannot describe all ion tests.
  • Not yet: Cannot remember flame test colours or ion tests. Reteach with summary tables and practice questions.

Lesson 2: Testing for Gases

Duration: 50 minutes

Starter Activity (5 minutes)

Squeaky Pop

What happens when you bring a lit splint near hydrogen gas? Why does it make a 'pop' sound?

Main Content (35 minutes)

Teaching Notes:
Tests for common gases:

Hydrogen (H₂):
• Bring a lit splint near the gas
• Result: squeaky pop
• Hydrogen burns rapidly with oxygen: 2H₂ + O₂ → 2H₂O

Oxygen (O₂):
• Insert a glowing splint into the gas
• Result: relights the glowing splint
• Oxygen supports combustion (makes things burn better)

Carbon dioxide (CO₂):
• Bubble the gas through limewater (calcium hydroxide solution)
• Result: limewater turns milky/cloudy
• CO₂ + Ca(OH)₂ → CaCO₃ + H₂O (white precipitate of calcium carbonate)

Chlorine (Cl₂):
• Bring damp litmus paper near the gas
• Result: bleaches the litmus paper (turns it white)
• Chlorine is toxic — only do this in a fume cupboard

Ammonia (NH₃):
• Bring damp red litmus paper near the gas
• Result: turns blue (ammonia is alkaline in solution)
• Or: hold concentrated hydrochloric acid near the gas → white烟雾 of ammonium chloride forms
Squeaky pop test

Fill a test tube with hydrogen gas. Bring a lit splint to the mouth of the tube. The hydrogen ignites with a characteristic 'squeaky pop'. This is a rapid combustion reaction: 2H₂ + O₂ → 2H₂O. The pop is caused by the rapid expansion of heated air.

Limewater test

CO₂ turns clear limewater milky because it forms insoluble calcium carbonate: CO₂ + Ca(OH)₂ → CaCO₃(s) + H₂O. If you bubble CO₂ through for longer, the milkiness disappears — the CaCO₃ reacts with more CO₂ to form soluble calcium hydrogen carbonate: CaCO₃ + CO₂ + H₂O → Ca(HCO₃)₂.

Gas tests:
H₂: lit splint → squeaky pop
O₂: glowing splint → relights
CO₂: limewater → turns milky
Cl₂: damp litmus → bleaches white
NH₃: damp red litmus → turns blue

Common Misconception

CO₂ turns limewater white.

CO₂ turns limewater milky/cloudy (not completely white). The milky appearance is caused by tiny particles of insoluble calcium carbonate (CaCO₃) suspended in the solution. If excess CO₂ is bubbled through, the milkiness disappears because CaCO₃ dissolves to form calcium hydrogen carbonate.

Differentiation

Support:
Provide a flowchart: Gas → Test → Observation → Identity. Fill in together for each gas.
Stretch:
Write the equation for the reaction of ammonia with hydrochloric acid: NH₃ + HCl → NH₄Cl. What type of reaction is this?

Plenary (5 minutes)

Match each gas to its test: hydrogen, oxygen, carbon dioxide, ammonia. Describe the observation for each.

Assessment Criteria

  • Got it: Describes all gas tests accurately and can identify gases from test results.
  • Getting there: Knows some gas tests but cannot remember all observations.
  • Not yet: Cannot describe gas tests. Reteach with the summary table and practice identification questions.

Homework Suggestions

  • Create flashcards for flame test colours and ion tests
  • Practise identifying unknown ions from sets of test results
  • Research: how are flame tests used in fireworks? What metals produce which colours?
