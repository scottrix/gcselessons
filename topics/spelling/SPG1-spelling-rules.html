SPG1: Spelling Rules and Patterns

FoundationHigherAll Boards

Master spelling rules and patterns to write accurately at GCSE level.

Lesson Overview

Estimated Lessons: 2
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, Eduqas, CCEA

Learning Objectives

  • Apply spelling rules and patterns accurately
  • Use punctuation marks correctly and for effect
  • Construct grammatically accurate sentences
  • Write clear, well-organised paragraphs
  • Edit and proofread writing for accuracy

Prerequisites

  • Basic understanding of sentence structure
  • Familiarity with common spelling patterns

Materials & Equipment

  • Spelling rules reference sheets
  • Punctuation practice worksheets
  • Grammar exercises
  • Editing and proofreading checklists

Lesson 1: Spelling Rules and Homophones

Duration: 50 minutes

Starter Activity (5 minutes)

Quick Spell

Dictate 10 commonly misspelled words. Review patterns.

Main Content (35 minutes)

Teaching Notes:
  • Homophones: their/there/they're, to/too/two, its/it's, your/you're, know/no, which/witch
  • i before e: receive, believe — except: receive, ceiling. Exceptions: weird, foreign
  • Doubling consonants: run→running (short vowel), mail→mailing (long vowel)
  • Dropping silent e: make→making, hope→hoping — but keep after c/g/s: changeable
Worked Example

affect/effect: affect=verb (it affected me); effect=noun (the effect was powerful)

practice/practise: practice=noun (a doctor's practice); practise=verb (I practise daily)

Practice Task

Write 10 sentences, each using a different homophone pair correctly.

Differentiation

Support:
Provide a homophones reference card.
Stretch:
Write a paragraph using 5 different homophone pairs.

Plenary (5 minutes)

Spell It

Teacher dictates sentences with homophones.

Assessment Criteria

  • Got it: Spells homophones correctly
  • Getting there: Makes occasional errors but self-corrects
  • Not yet: Frequently confuses homophones

Lesson 2: Spelling for Accuracy

Duration: 50 minutes

Starter Activity (5 minutes)

Error Hunt

Display a paragraph with 10 spelling errors. Find and correct them.

Main Content (35 minutes)

Teaching Notes:
  • Personal spelling lists: keep a list of words you misspell
  • Strategies: look-cover-write-check, word families, mnemonics
  • Proofreading: read slowly backwards, use spell-check as tool not crutch
Worked Example

Proofreading process: Step 1: Read for meaning. Step 2: Check each word. Step 3: Check homophones. Step 4: Read aloud.

Practice Task

Write a 200-word response, then proofread it using a checklist.

Differentiation

Support:
Provide a proofreading checklist.
Stretch:
Proofread a partner's work.

Plenary (5 minutes)

One Change

Students swap work and each make one spelling correction.

Assessment Criteria

  • Got it: Can proofread effectively
  • Getting there: Identifies some errors but misses others
  • Not yet: Cannot proofread effectively

Homework Suggestions

  • Complete a spelling or grammar worksheet on the topic covered
  • Practise proofreading a paragraph for errors
  • Write a short passage using the skills learned, then self-assess
