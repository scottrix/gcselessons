🔬 Required Practical: Required Practical: Potential Divider

This is a required practical for Eduqas GCSE Electronics. It may be assessed in written examinations.

Apparatus and Materials

  • Breadboard and jumper wires
  • Components per circuit diagram (resistors, transistors, sensors, power supply)
  • Multimeter (voltage, current, resistance ranges)
  • Oscilloscope or data logger (where applicable)
  • Component datasheets

Procedure

  1. Study the schematic and identify all components and connections
  2. Build the circuit on breadboard following the layout diagram
  3. Verify connections with multimeter continuity test before powering
  4. Apply power and measure key voltages/currents at test points
  5. Record results in a structured table with units and uncertainties
  6. Vary input parameters (e.g., sensor conditions, input voltage) and observe outputs
  7. Plot characteristic graphs (e.g., Vout vs Vin, Ic vs Ib)
  8. Compare experimental results with theoretical predictions

Key Measurements and Calculations

  • Measure: voltages at all nodes, currents in all branches
  • Calculate: voltage gain, current gain, power dissipation, efficiency
  • Analyse: linearity, threshold voltages, switching times, frequency response

Safety and Risk Assessment

  • Check component power ratings — do not exceed maximum voltage/current
  • Use current-limiting resistors with LEDs and transistors
  • Discharge capacitors before handling
  • Eye protection when clipping leads or testing high-energy circuits
  • Never work on mains-powered circuits without qualified supervision

Typical Exam Questions

  • Draw the circuit diagram from memory / description
  • Explain the function of each component in the circuit
  • Calculate expected readings for given component values
  • Analyse a results table: identify anomalies, calculate uncertainties
  • Suggest improvements to the experimental method
  • Explain how the circuit would behave if a component failed open/short
