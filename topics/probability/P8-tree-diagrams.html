P8: Tree Diagrams

Foundation Higher All Boards

Construct and interpret probability tree diagrams for independent and dependent events (with and without replacement), calculate probabilities of combined events, and solve multi-stage problems.

Lesson Overview

Estimated Lessons: 3
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, OCR, Eduqas, CCEA

Learning Objectives

  • Construct probability tree diagrams for two-stage experiments
  • Understand that probabilities on branches from a node sum to 1
  • Calculate probabilities of combined events by multiplying along branches
  • Add probabilities of mutually exclusive end-branches for "or" events
  • Distinguish between independent events (with replacement) and dependent events (without replacement)
  • Solve problems involving "at least one" using complements

Prerequisites

  • Probability rules: P(A and B) = P(A)×P(B) for independent; P(A or B) = P(A)+P(B) for mutually exclusive (P4)
  • Fractions, decimals, percentages multiplication and addition
  • Understanding of with/without replacement (P6)
  • Systematic listing for verification (P6)

Materials & Equipment

  • Blank tree diagram templates (2-stage, 3-stage)
  • Coloured counters in bags for physical modelling
  • Mini whiteboards for probability multiplication practice
  • Highlighters for tracing paths on tree diagrams

Lesson 1: Tree Diagrams for Independent Events (With Replacement)

Duration: 50 minutes

Starter Activity (5 minutes)

Multiply Along Branches

Bag: 3 Red, 2 Blue. Draw one, REPLACE, draw again. P(Red) = 3/5. What is P(Red then Red)? Students: (3/5)×(3/5) = 9/25. Introduce tree diagram as a visual for this.

Main Content (35 minutes)

Teaching Notes:
Probability Tree Diagram: A diagram showing all outcomes of a multi-stage experiment with probabilities on branches.
Key Rules:
  • Probabilities on branches from the SAME DOT (node) SUM TO 1
  • Multiply along branches for AND (combined outcomes)
  • Add end-branch probabilities for OR (mutually exclusive outcomes)
  • Sum of ALL end-branch probabilities = 1
Independent Events (With Replacement):
  • Probabilities stay the SAME at each stage
  • Example: Coin flip twice → P(H)=0.5 on both sets of branches
  • Bag with replacement: composition unchanged
Constructing a Tree Diagram:
  1. Identify stages and outcomes at each stage
  2. Draw first set of branches with probabilities
  3. Draw second set of branches from each first outcome
  4. Label end outcomes (e.g. RR, RB, BR, BB)
  5. Calculate end probabilities: multiply along path
  6. Check: all end probabilities sum to 1
Reading Probabilities from Tree:
  • P(RR) = multiply along RR path
  • P(one Red, one Blue) = P(RB) + P(BR) (add end branches)
  • P(at least one Red) = 1 - P(BB) (complement)
Worked Example

A bag contains 4 green and 6 yellow counters. A counter is drawn, its colour noted, and it is REPLACED. A second counter is drawn.
(a) Draw the tree diagram.
(b) Find P(both green).
(c) Find P(one of each colour).
(d) Find P(at least one green).

Answers:
(a) First branches: G (0.4), Y (0.6). Second branches from each: G (0.4), Y (0.6).
(b) P(GG) = 0.4 × 0.4 = 0.16
(c) P(GY) + P(YG) = (0.4×0.6) + (0.6×0.4) = 0.24 + 0.24 = 0.48
(d) 1 - P(YY) = 1 - (0.6×0.6) = 1 - 0.36 = 0.64

Common Misconception: Adding probabilities along branches instead of multiplying. "P(GG) = 0.4 + 0.4 = 0.8" Correction: MULTIPLY along branches for AND. Think: "First G AND second G". Only ADD for mutually exclusive outcomes at the END (e.g. GY OR YG).

Differentiation

Support:
Provide pre-drawn tree structure with blank probabilities. Use fractions with same denominator for easier multiplication. Colour-code: first stage branches one colour, second stage another.
Stretch:
Three-stage tree: "Coin flipped 3 times. Find P(exactly 2 Heads)." Algebraic: "Bag has x red, (10-x) blue. With replacement. P(two red) = 0.36. Find x." (x/10)² = 0.36 → x/10 = 0.6 → x = 6.

Plenary (5 minutes)

Tree Check

Show a tree diagram with one error (probabilities don't sum to 1 at a node, or end probabilities don't sum to 1, or wrong multiplication). Students find and fix the error.

Assessment Criteria

  • Got it: Constructs tree for independent events; multiplies along branches; adds end branches; uses complement for "at least one"
  • Getting there: Constructs tree but makes arithmetic errors; forgets to add for "or" events
  • Not yet: Adds along branches; probabilities don't sum to 1 at nodes; cannot identify end outcomes

Lesson 2: Tree Diagrams for Dependent Events (Without Replacement)

Duration: 50 minutes

Starter Activity (5 minutes)

Changing Probabilities

Bag: 3 Red, 2 Blue. Draw one, NO REPLACEMENT, draw again. If first was Red, what is P(second Red)? (2/4 = 1/2). If first was Blue, what is P(second Red)? (3/4). Probabilities CHANGE based on first outcome.

Main Content (35 minutes)

Teaching Notes:
Dependent Events (Without Replacement):
  • Probabilities on SECOND stage branches DEPEND on first outcome
  • Total number of items DECREASES by 1
  • Number of favourable items may decrease (if that colour was drawn)
  • Always check: probabilities at each node still sum to 1
Key Differences from With Replacement:
  • Denominators change: n, then n-1
  • Numerators change depending on what was drawn first
  • Outcomes are NOT independent: P(2nd Red | 1st Red) ≠ P(2nd Red)
Constructing Without-Replacement Tree:
  1. First stage: original probabilities
  2. For EACH first outcome, calculate new probabilities for second draw
  3. Example: 3R, 2B. First R (3/5). Remaining: 2R, 2B. Second: R (2/4), B (2/4). First B (2/5). Remaining: 3R, 1B. Second: R (3/4), B (1/4).
  4. Multiply along branches as before
Common Problems:
  • P(both same colour) = P(RR) + P(BB)
  • P(different colours) = P(RB) + P(BR)
  • P(at least one Red) = 1 - P(BB)
  • P(second is Red) = P(RR) + P(BR) (Law of Total Probability)
Worked Example

A box contains 5 chocolate and 3 plain biscuits. Two biscuits are taken at random WITHOUT REPLACEMENT.
(a) Complete the tree diagram.
(b) Find P(both chocolate).
(c) Find P(one of each).
(d) Find P(second biscuit is plain).

Answers:
(a) First: C (5/8), P (3/8). From C: C (4/7), P (3/7). From P: C (5/7), P (2/7).
(b) P(CC) = 5/8 × 4/7 = 20/56 = 5/14
(c) P(CP) + P(PC) = (5/8×3/7) + (3/8×5/7) = 15/56 + 15/56 = 30/56 = 15/28
(d) P(second plain) = P(CP) + P(PP) = 15/56 + (3/8×2/7) = 15/56 + 6/56 = 21/56 = 3/8
Note: P(second plain) = P(first plain) = 3/8. Symmetry!

Common Misconception: Using the same probabilities on second branches as first. "First Red 3/5, so second Red also 3/5." Correction: Without replacement CHANGES the bag contents. Always recalculate: new total = old total - 1; new count of that colour = old count - 1 (if that colour was drawn).

Differentiation

Support:
Use physical counters: "Take one out, don't put it back. Now what's in the bag?" Draw the bag contents after each draw. Provide a template: "After Red: ___ Red left, ___ Blue left, Total ___"
Stretch:
Three draws without replacement. "5 Red, 3 Blue. Three drawn. P(all same)?" Algebraic: "n red, m blue. Two drawn without replacement. P(both red) = 1/3. Find relationship between n and m."

Plenary (5 minutes)

With or Without?

Students hold up W (with) or WO (without) cards for scenarios:
1. Lottery numbers drawn → Without
2. Quality control: test bulb, put back, test another → With
3. Draw two cards from deck → Without
4. Spin spinner twice → With
5. Choose two students from class for a trip → Without

Assessment Criteria

  • Got it: Constructs without-replacement trees; recalculates probabilities correctly; solves "at least one" and "second is..." problems
  • Getting there: Sets up first stage correctly but struggles with second stage probabilities; arithmetic errors with fractions
  • Not yet: Uses same probabilities for both stages; doesn't reduce total

Lesson 3: Advanced Tree Diagram Problems

Duration: 50 minutes

Starter Activity (5 minutes)

Reverse Tree

Show a completed tree diagram with end probabilities: 0.2, 0.3, 0.1, 0.4. Ask: "What could the experiment be? What were the first-stage probabilities? Second-stage?"

Main Content (35 minutes)

Teaching Notes:
Three-Stage Trees: Same principles, just more branches. Multiply three probabilities along each path. 2³ = 8 end branches for binary outcomes.
Non-Binary Outcomes: Die (6 branches), Spinner (4 branches). Tree gets wide. Can combine with possibility space for two dice (36 outcomes) but tree for three dice (216 outcomes) is unwieldy — use multiplication directly.
Algebraic Trees: Probabilities expressed in terms of x. Use sum-to-1 at nodes to form equations.
Conditional Probability from Tree (Higher): P(A|B) = P(A and B) / P(B). On tree: P(A and B) = end probability of path with A and B. P(B) = sum of end probabilities where B occurs.
Problem-Solving Strategy:
  1. Draw tree (even roughly)
  2. Fill in known probabilities
  3. Use sum-to-1 to find missing probabilities
  4. Multiply along required paths
  5. Add end probabilities for "or" events
  6. Use complement for "at least one"
  7. Answer the specific question asked
Worked Example

Probability it rains on Monday = 0.3. If it rains Monday, P(rains Tuesday) = 0.6. If not Monday, P(rains Tuesday) = 0.2.
(a) Draw tree diagram.
(b) Find P(rains both days).
(c) Find P(rains exactly one day).
(d) Find P(rains Tuesday).
(e) Given it rained Tuesday, find P(rained Monday). [Higher]

Answers:
(a) Mon: R (0.3), NR (0.7). From R: R (0.6), NR (0.4). From NR: R (0.2), NR (0.8).
(b) P(RR) = 0.3 × 0.6 = 0.18
(c) P(R,NR) + P(NR,R) = (0.3×0.4) + (0.7×0.2) = 0.12 + 0.14 = 0.26
(d) P(R on Tue) = P(RR) + P(NR,R) = 0.18 + 0.14 = 0.32
(e) P(Mon R | Tue R) = P(RR) / P(Tue R) = 0.18 / 0.32 = 9/16 = 0.5625

Common Misconception: For "at least one", adding P(first) + P(second). "P(at least one rain) = 0.3 + 0.32 = 0.62" Correction: This double-counts "both". Correct: P(at least one) = P(R,NR) + P(NR,R) + P(R,R) = 0.26 + 0.18 = 0.44. Or: 1 - P(NR,NR) = 1 - (0.7×0.8) = 1 - 0.56 = 0.44.

Differentiation

Support:
Stick to two-stage trees. Provide a checklist: "Draw → Label → Multiply → Add → Check sum=1". Use decimal probabilities (easier than fractions).
Stretch:
"A game: flip coin. If H, roll die. If T, spin spinner (1-4). Draw tree. P(score > 3)?" Weather forecast problems. "Two bags: Bag A (3R,2B), Bag B (1R,4B). Choose bag at random, then draw counter. P(Red)?" (Law of Total Probability).

Plenary (5 minutes)

Exam Question

Timed past paper question (6 marks) on tree diagrams. Students attempt, then peer-mark using mark scheme.

Assessment Criteria

  • Got it: Solves multi-stage, algebraic, and conditional problems; constructs accurate trees; checks work
  • Getting there: Solves standard two-stage problems; struggles with algebraic or three-stage
  • Not yet: Cannot set up tree for dependent events; major arithmetic errors

Homework Suggestions

  • Tree diagram worksheet: 4 with replacement, 4 without replacement, 2 three-stage, 1 algebraic.
  • Complete 5 past paper questions on tree diagrams.
  • Create a "Tree Diagram Guide" poster showing: rules, with/without replacement examples, "at least one" method, common mistakes.
  • Challenge: "Bag has 10 counters: x red, rest blue. Two drawn without replacement. P(both red) = 2/15. Find x."
