Lesson 2: Core Concepts: set text analysis and exam preparation

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on set text analysis and exam preparation. Check them against the notes below.

Main Content (35 minutes)

Key Fact: Know the WHOLE play, not just the extracts — context matters for every question.
Key Fact: Extract questions: analyse the specific scene AND connect it to the whole play's themes and structure.
Key Fact: Three perspectives: you may be asked from performer, director or designer viewpoint — always answer from the specified perspective.
Key Fact: Structure your answer: point (identify technique/choice) + evidence (specific reference) + explanation (effect on audience) + link (to whole play themes).
Key Fact: Time management: Section A is 45 minutes — plan for 5 minutes, write for 35 minutes, check for 5 minutes.
Drama Exam Tips: For the written exam, use the SEE framework for each point: State your choice (e.g. 'I would position the character DS centre'), Evidence from the text ('because at this moment they are confronting the truth'), Effect on audience ('creating maximum focus and intimacy'), Link to theme ('which reflects the play's central theme of honesty').

Lesson 3: Application: set text analysis and exam preparation

Duration: 50 minutes

Starter Activity (5 minutes)

Quick Recall

Recall the key terms: Drama Exam Tips. Define each in one sentence.

Main Content (35 minutes)

Parent/Teacher Guide: Let your student attempt each question alone first, then compare with the model answer. Award method marks for correct working even if the final answer is wrong.

Q1: How would you approach a written exam question asking you to describe how you would perform an extract from your set text?

Answer: Read the extract carefully; identify the key dramatic moment; choose a perspective (performer/director/designer as asked); make specific staging/performance choices; justify each with reference to the text; link to the play's themes and context.

Q2: Why is it important to understand the whole play, even though the exam only asks about extracts?

Answer: Extracts are shaped by the whole play — character motivations come from earlier scenes, themes run throughout, the extract's significance depends on its place in the overall structure. Without whole-play knowledge, your analysis will be superficial.

Q3: Describe how you would answer a question from a director's perspective about staging a key scene.

Answer: Describe staging choices (stage type, positioning, levels); explain design choices (set, lighting, costume); justify how these communicate the scene's meaning; link to the director's concept and the play's themes; use precise theatrical vocabulary.

Plenary (5 minutes)

Error Review

Review any questions answered incorrectly. Identify whether the error was knowledge, method, or reading the question.

Lesson 4: Exam Practice: set text analysis and exam preparation

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Review what these command words require: state (one point), describe (say what happens), explain (say why), compare (both sides), evaluate (judgement).

Main Content (35 minutes)

Extended Answer

Extended question: Full-Mark Response As a performer, describe how you would use vocal and physical skills to realise a key moment in the given extract. Justify your choices with reference to the whole play. <div class="

A grade 9 response will: identify the key dramatic moment; describe specific vocal choices with justification; describe specific physical choices with justification; explain the intended effect on the audience; link choices to the character's development across the whole play; connect to the play's central themes; use precise theatrical terminology throughout. Mark scheme: The set text exam (Component 1, Section A) tests AO1 (knowledge), AO2 (analysis), and AO3 (performance application). You...

Exam Tips: Read the question TWICE — check which perspective is required | Always refer to SPECIFIC moments in the extract — never write generically | Link extract choices to the WHOLE play — context marks are essential | Use PEEL paragraphs: Point, Evidence, Explanation, Link
Common Errors: Watch Out! Students often make mistakes here. Wrong: For the written exam, you just need to learn the story of the play and describe what happens in the extract. Correct: The written exam tests your ABILITY TO REALISE the text, not just recall the plot. You must make specific performance, design or directorial choices, justify them with textual evidence, and link them to the whole play's themes. Describing what happens scores low marks; explaining how you would bring it to life scores high marks.
