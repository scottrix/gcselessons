Lesson 2: Core Concepts: writing a theatre review

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on writing a theatre review. Check them against the notes below.

Main Content (35 minutes)

Key Fact: Introduction: name the production, company, venue, date and the production's overall intention.
Key Fact: SEE framework: State the technique, Evidence from the production, Effect on the audience — use for every analytical point.
Key Fact: Analysis paragraphs: focus on one aspect per paragraph (e.g. performance, then design, then direction).
Key Fact: Conclusion: evaluate the overall effectiveness — did the production achieve its intention? Sum up your judgement.
Key Fact: Analytical style: precise terminology, specific moments, supported judgements — never vague or subjective language.
Drama Exam Tips: Time management for Section B (live theatre): 5 minutes planning (which moments will you write about?), 30 minutes writing (structured paragraphs using SEE), 5 minutes checking (terminology, evidence, judgements). Plan your key moments BEFORE you start writing to ensure you have enough material.

Q: Describe the structure of a theatre review for the GCSE written exam.

Answer: Introduction (production, company, venue, intention) → Performance analysis paragraph (specific vocal/physical choices) → Design analysis paragraph (specific set/lighting/sound/costume choices) → Direction analysis paragraph (staging/pacing) → Conclusion (overall effectiveness judgement linked to intention).

Lesson 3: Application: writing a theatre review

Duration: 50 minutes

Starter Activity (5 minutes)

Quick Recall

Recall the key terms: Drama Exam Tips. Define each in one sentence.

Main Content (35 minutes)

Parent/Teacher Guide: Let your student attempt each question alone first, then compare with the model answer. Award method marks for correct working even if the final answer is wrong.

Q1: Describe the structure of a theatre review for the GCSE written exam.

Answer: Introduction (production, company, venue, intention) → Performance analysis paragraph (specific vocal/physical choices) → Design analysis paragraph (specific set/lighting/sound/costume choices) → Direction analysis paragraph (staging/pacing) → Conclusion (overall effectiveness judgement linked to intention).

Q2: What is the SEE framework and how does it improve your written analysis?

Answer: SEE: State the technique used, Evidence from the production (specific moment), Effect on the audience. It improves analysis by forcing you to move beyond description ('the lighting was blue') to analysis ('the blue lighting connoted coldness and isolation, making the audience feel the character's loneliness').

Q3: How can you ensure your theatre review is analytical rather than just descriptive?

Answer: Use precise terminology instead of everyday language. Always explain the MEANING and EFFECT of choices, not just what you saw. Make judgements about effectiveness. Support every claim with evidence. Replace 'I liked it' with 'The designer's choice was effective because...'

Lesson 4: Exam Practice: writing a theatre review

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Review what these command words require: state (one point), describe (say what happens), explain (say why), compare (both sides), evaluate (judgement).

Main Content (35 minutes)

Extended Answer

Extended question: Full-Mark Response Write a structured theatre review of a production you have seen, evaluating the effectiveness of the performance and design choices. <div class="

A grade 9 review will: open with factual introduction; use structured paragraphs (performance, design, direction); apply the SEE framework consistently; make clear judgements about effectiveness; support every claim with specific evidence; use precise theatrical terminology; conclude with overall evaluation linked to intention; write in an analytical, not descriptive style. Mark scheme: The live theatre review (Component 1 Section B) assesses AO2 (20%). The question asks you to analyse and evaluate a prod...

Exam Tips: Introduction: name production, company, venue, date — essential facts first | Every paragraph must contain both ANALYSIS and EVALUATION | Use SEE for every point — State, Evidence, Effect | Conclusion: judge overall effectiveness against the production's stated intention
Common Errors: Watch Out! Students often make mistakes here. Wrong: A theatre review should start with your overall opinion and then give reasons why you liked or disliked the show. Correct: A theatre review should start with FACTUAL CONTEXT (production, company, venue, intention) and then provide ANALYSIS and EVALUATION of specific choices. Your opinion only matters when it is supported by evidence and linked to the production's intention. The examiner wants to see analytical skill, not personal preference.
