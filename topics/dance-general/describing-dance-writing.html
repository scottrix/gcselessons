Lesson 2: Core Concepts: describing dance in writing

Duration: 50 minutes

Starter Activity (5 minutes)

Quick recap: write 3 key points from Lesson 1 on describing dance in writing. Check them against the notes below.

Main Content (35 minutes)

Key Fact: Accurate written description requires precise dance terminology, not everyday language
Key Fact: Movement description should cover action, dynamics, space and relationships (A D S R)
Key Fact: Action vocabulary includes actions of the body: turn, jump, travel, gesture, fall, stillness
Key Fact: Dynamics describe how movements are performed: fast, slow, sustained, sudden, heavy, light
Key Fact: Spatial description includes levels, directions, pathways, formations and use of stage space
Key Fact: Relationships describe how dancers interact: unison, canon, contact, complement, contrast

Lesson 4: Exam Practice: describing dance in writing

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Review what these command words require: state (one point), describe (say what happens), explain (say why), compare (both sides), evaluate (judgement).

Main Content (35 minutes)

Exam-Style Question

Attempt a past-paper style question on describing dance in writing from the exam board past paper finder (see Resources), then mark it against the scheme.

Exam Tips: Use A D S R (Action, Dynamics, Space, Relationships) as a checklist for complete descriptions | Always pair a technical term with a specific example from the work you are describing | Write in present tense: 'The dancer extends' not 'The dancer extended' | Replace vague words with precise ones — 'sustained' not 'slow', 'percussive' not 'hard' | Practise writing timed descriptions of short sections to build speed and accuracy
Common Errors: ✗ Writing 'the dance was good' or 'it looked nice'. ✓ Use specific technical language: 'The dancer performed sustained, flowing movements at a low level with smooth transitions between gestures.' ✗ Describing only what the dancers do, not how they do it. ✓ Always include dynamics — the quality of movement is as important as the action itself for a complete description. ✗ Confusing unison and canon. ✓ Unison means same movement at the same time; canon means same movement at different times with a time delay between dancers. ✗ Using past tense when describing dance. ✓ Use present tense for dance description: 'The dancer leaps' not 'The dancer leapt', because the work exists as a living perform
