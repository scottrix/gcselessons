Lesson 2: Core Concepts: professional dance works overview

Duration: 50 minutes

Starter Activity (5 minutes)

Main Content (35 minutes)

Key Fact: AQA 8236 requires students to study specific set professional works for the written exam
Key Fact: The set professional works are 'Within Her Eyes' by James Cousins, 'Artificial Things' by Lucy Bennett and 'Emancipation of Expressionism' by Kenrick H2O Sandy
Key Fact: Each work has a distinct choreographic intention, style and set of features that must be understood in detail
Key Fact: Professional works are assessed in Section C of the written exam, worth 25 marks
Key Fact: You must know the choreographer, company, intention, stimulus, movement content, structure and design elements for each work
Key Fact: James Cousins created 'Within Her Eyes' as a duet exploring love, loss and memory

Lesson 4: Exam Practice: professional dance works overview

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Review what these command words require: state (one point), describe (say what happens), explain (say why), compare (both sides), evaluate (judgement).

Main Content (35 minutes)

Exam-Style Question

Attempt a past-paper style question on professional dance works overview from the exam board past paper finder (see Resources), then mark it against the scheme.

Exam Tips: Learn the basic facts for each work cold: choreographer, company, year, intention, stimulus and structure | In Section C, always name the specific work and choreographer — do not write vaguely about 'the dance' | Prepare detailed notes on movement content, design elements and choreographic features for each work | Practise comparing works — exam questions may ask you to discuss more than one work | Use specific examples from each work rather than general statements — detail scores marks
Common Errors: ✗ You only need to know one professional work for the exam. ✓ AQA requires detailed knowledge of all three set professional works — exam questions may ask about any or all of them. ✗ The choreographer's name is not important for the exam. ✓ Naming the choreographer correctly is essential — it shows precise knowledge and is expected in every professional works answer. ✗ All three works have the same choreographic style. ✓ Each work has a distinct style: 'Within Her Eyes' is contemporary duet, 'Artificial Things' is inclusive contemporary, and 'Emancipation of Expressionism' is hip-hop influenced — they are very different. ✗ Design elements are not needed when writing about professional works.
