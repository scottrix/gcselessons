Lesson 2: Core Concepts: comparing &amp; evaluating dance

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on comparing &amp; evaluating dance. Check them against the notes below.

Main Content (35 minutes)

Key Fact: Comparing requires identifying both similarities and differences — not just one or the other
Key Fact: Use linking words: 'similarly', 'in contrast', 'whereas', 'both', 'however' to show comparison clearly
Key Fact: Always compare the same element — for example, compare use of dynamics in both works
Key Fact: Evaluating means making a judgement about effectiveness, supported by specific evidence
Key Fact: A strong evaluation considers strengths and limitations before reaching a conclusion
Key Fact: When evaluating your own work, be honest and specific about what worked and what could improve

Lesson 4: Exam Practice: comparing &amp; evaluating dance

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Review what these command words require: state (one point), describe (say what happens), explain (say why), compare (both sides), evaluate (judgement).

Main Content (35 minutes)

Exam-Style Question

Attempt a past-paper style question on comparing &amp; evaluating dance from the exam board past paper finder (see Resources), then mark it against the scheme.

Exam Tips: Plan comparison answers in a table before writing — list similarities and differences for each element | Never write about one work then the other separately — interleave your points with linking words | For evaluation, introduce your criteria early so the examiner knows your basis for judgement | Support every comparative point with at least one specific example from each work | In evaluation answers, always finish with a clear, one-sentence judgement that answers the question
Common Errors: ✗ Writing about Work A, then writing about Work B, without linking them. ✓ Interleave your points — compare the same element in both works using linking words like 'whereas' or 'similarly' within the same paragraph. ✗ Only identifying differences when asked to compare. ✓ Compare means identify both similarities and differences. If you only discuss differences, you have not fully answered the question. ✗ Giving an opinion without evidence when evaluating. ✓ Every judgement must be supported by specific evidence from the dance.
