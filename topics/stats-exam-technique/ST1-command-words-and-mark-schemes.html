ST1: Command Words and Mark Schemes

Foundation Higher AQA, Edexcel, CCEA

Interpret 'calculate', 'compare', 'justify', 'evaluate' - what examiners look for, securing method marks.

ST2: Time Management and Strategy →

Lesson Overview

Estimated Lessons: 2-3
Tier: Foundation and Higher
Duration: 50 minutes per lesson
Exam Boards: AQA, Edexcel, CCEA

Learning Objectives

  • Understand the key concepts and terminology for command words and mark schemes
  • Apply command words and mark schemes techniques to solve statistical problems
  • Interpret results in context and communicate findings clearly
  • Identify common misconceptions and avoid typical errors

Prerequisites

  • Basic arithmetic and algebraic manipulation
  • Understanding of data types (discrete, continuous, categorical)
  • Familiarity with statistical notation and terminology

Materials & Equipment

  • Scientific calculator (statistics mode)
  • Graph paper / squared paper
  • Statistical tables (normal, t, chi-squared) or calculator functions
  • Spreadsheet software (Excel, Google Sheets) for demonstrations
  • Real-world datasets for practice (provided in resources)

Lesson 1: Core Concepts

Duration: 50 minutes

Starter Activity (5 minutes)

Quick Recall

Rapid-fire questions on prerequisite knowledge relevant to command words and mark schemes. Use mini-whiteboards for immediate feedback.

Main Content (35 minutes)

Teaching Notes:
Introduce key concepts systematically. Use worked examples with real data. Emphasise: • Definitions and notation
• Step-by-step procedures
• When to use each method
• Interpreting calculator/computer output
Worked Example

Detailed step-by-step solution demonstrating the key technique for command words and mark schemes. Include calculator keystrokes where applicable.

Key formulae for command words and mark schemes — students should memorise or know how to derive.

Common Misconception

A typical student error related to this topic.

Correct understanding with explanation of why the misconception arises.

Differentiation

Support:
Provide structured worksheets with partially completed examples. Use visual aids and concrete examples. Allow calculator use for arithmetic.
Stretch:
Explore extensions: proof of formulae, comparison of methods, application to unfamiliar contexts, derivation of related results.

Plenary (5 minutes)

Exit Question

A single focused question checking the core learning objective. Students write answer on exit slip.

Assessment Criteria

  • Got it: Accurately applies the method, interprets results correctly, communicates clearly.
  • Getting there: Method mostly correct but minor errors in calculation or interpretation.
  • Not yet: Fundamental misunderstanding of the concept. Reteach with alternative approach.

Lesson 2: Application and Practice

Duration: 50 minutes

Starter Activity (5 minutes)

Error Analysis

Present a solution with deliberate errors. Students identify and correct them.

Main Content (35 minutes)

Teaching Notes:
Guided practice → independent practice → exam-style questions.
Focus on: context interpretation, selecting appropriate methods, handling grouped data, technology use.
Contextual Problem

Real-world scenario requiring command words and mark schemes. Students work through: identify variables, choose method, calculate, interpret, conclude.

AO3 Problem Solving

Multi-step question requiring decision-making: which technique to use, handling imperfect data, justifying choices, evaluating limitations.

Differentiation

Support:
Scaffolded version with prompts: "What type of data is this?", "Which measure of spread is appropriate?", "What does the result tell you?"
Stretch:
Open-ended investigation: "Design a study to compare... using command words and mark schemes. Justify your choices."

Plenary (5 minutes)

Summary Triangle

Students write: 3 key points, 2 connections to other topics, 1 question they still have.

Assessment Criteria

  • Got it: Selects and applies correct method independently, interprets in context, evaluates limitations.
  • Getting there: Applies method with guidance, interprets partially.
  • Not yet: Cannot select appropriate method. Reteach decision-making framework.

Homework Suggestions

  • Complete practice questions from textbook/exam papers on command words and mark schemes
  • Find a real dataset (e.g., from ONS, data.gov.uk) and apply the technique
  • Create a one-page revision summary with key formulae, when to use, and a worked example
  • Use spreadsheet to generate data and verify calculations
