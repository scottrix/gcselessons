the solar system overview

FoundationHigherAll Boards

4 detailed 50-minute lessons with teaching scripts, worked examples, parent guides, and assessment criteria.

Lesson Overview

Total Lessons: 4
Tier: Foundation and Higher
Duration: 50 minutes per lesson (200 minutes total)
Exam Boards: AQA, Edexcel, OCR, Eduqas, CCEA

Learning Objectives

  • Explain the key ideas of the solar system overview
  • Apply the solar system overview to exam-style questions
  • Develop independent study skills
  • Build cross-topic connections

Prerequisites

  • Read the revision notes for the solar system overview first (GCSE Revise summary)
  • Key vocab to pre-teach: key terms from the solar system overview
  • Basic skills: reading the summary notes and answering the practice questions there

Materials & Equipment

  • Exercise book, coloured pens
  • Ruler
  • Printed revision notes (link below)
  • Internet for videos (see Resources)

Lesson 1: Introduction: the solar system overview

Duration: 50 minutes

Starter Activity (5 minutes)

Write down everything you already know about the solar system overview. Then check against the key terms: key terms from the solar system overview. Use a mini-whiteboard or paper.

Main Content (35 minutes)

Parent/Teacher Guide:
Before lesson: Read the script below. Pre-teach key vocab: key terms from the solar system overview.
If stuck: Re-read the revision notes (link above), then break the content into smaller steps.
Extension: See the Stretch & Challenge ideas in Lesson 4.
Teaching Script (35 mins):
Mins 0-5 - Hook: "Today: the solar system overview. By the end you will be able to answer exam questions on it unaided. It connects to the rest of Astronomy because the ideas here recur across the spec."
Mins 5-20 - Direct Instruction: Work through the core ideas below one at a time; after each, ask your student to explain it back in their own words.
Mins 20-30 - Guided Practice: Model the worked example together, then let your student attempt the first practice question with guidance.
Mins 30-35 - Independent Practice: 2-3 practice questions from Lesson 3 below, with immediate feedback.

Lesson 2: Core Concepts: the solar system overview

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on the solar system overview. Check them against the notes below.

Main Content (35 minutes)

Key Fact: The Solar System consists of the Sun and everything gravitationally bound to it
Key Fact: Eight planets orbit the Sun: four terrestrial (Mercury, Venus, Earth, Mars) and four gas/ice giants (Jupiter, Saturn, Uranus, Neptune)
Key Fact: Dwarf planets include Pluto, Ceres, Eris, Haumea and Makemake
Key Fact: The asteroid belt lies between Mars and Jupiter
Key Fact: The Kuiper belt extends beyond Neptune; the Oort cloud is a theoretical spherical shell at the Solar System's edge
Key Fact: The Solar System formed about 4.6 billion years ago from a collapsing molecular cloud (solar nebula)

Lesson 4: Exam Practice: the solar system overview

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Review what these command words require: state (one point), describe (say what happens), explain (say why), compare (both sides), evaluate (judgement).

Main Content (35 minutes)

Exam-Style Question

Attempt a past-paper style question on the solar system overview from the exam board past paper finder (see Resources), then mark it against the scheme.

Exam Tips: Remember the order of planets using mnemonics (e.g. My Very Easy Method Just Speeds Up Naming) | Dwarf planets fail the 'clearing orbit' criterion — this is the key distinction | The Oort cloud is theoretical — we infer its existence from long-period comets | Both AQA and Edexcel expect you to know the difference between terrestrial and gas/ice giants
Common Errors: ✗ Pluto is the ninth planet ✓ Pluto was reclassified as a dwarf planet in 2006 by the IAU because it has not cleared its orbit ✗ The asteroid belt is the remains of a destroyed planet ✓ The asteroid belt is material that never accreted into a planet due to Jupiter's gravitational influence ✗ Gas giants and ice giants are the same ✓ Gas giants (Jupiter, Saturn) are mainly H/He; ice giants (Uranus, Neptune) have more water, ammonia and methane ices
Stretch & Challenge (Grade 8-9):

  • Real-world: research one real-world use or example of the solar system overview
  • Critical: "What are the limitations of the models used in the solar system overview?"

Plenary (5 minutes)

Assessment Criteria

  • Not yet: Confused on key concepts - re-run Lesson 2
