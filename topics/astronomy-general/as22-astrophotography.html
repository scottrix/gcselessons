Lesson 2: Core Concepts: astrophotography

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on astrophotography. Check them against the notes below.

Main Content (35 minutes)

Key Fact: Astrophotography records images of celestial objects using cameras attached to telescopes or with standard cameras on tripods
Key Fact: Key camera settings: exposure time, ISO/gain, and aperture (f-number)
Key Fact: Star trails are created by long exposures showing the apparent rotation of the sky around the celestial pole
Key Fact: Image stacking combines multiple short exposures to reduce noise and reveal faint detail
Key Fact: Dark frames (images with the lens cap on) record sensor noise for subtraction; flat frames correct vignetting and dust shadows
Key Fact: Post-processing adjusts levels, contrast and colour balance to bring out detail

Lesson 4: Exam Practice: astrophotography

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Review what these command words require: state (one point), describe (say what happens), explain (say why), compare (both sides), evaluate (judgement).

Main Content (35 minutes)

Exam-Style Question

Attempt a past-paper style question on astrophotography from the exam board past paper finder (see Resources), then mark it against the scheme.

Exam Tips: Stacking improves signal-to-noise ratio — this is a key concept | Dark frames subtract noise; flat frames correct vignetting — know the difference | Both boards cover astrophotography basics in the observational skills section | The 500 rule is useful but not always examined — understand the principle rather than memorising the number
Common Errors: ✗ A single long exposure is always better than multiple short ones ✓ Multiple short exposures stacked together reduce noise and avoid tracking errors; a single long exposure risks trailing and overexposure ✗ Higher ISO always produces better astrophotos ✓ Higher ISO amplifies signal but also noise; there is an optimum ISO for each camera beyond which quality degrades ✗ You need an expensive telescope for astrophotography ✓ Wide-field astrophotography with a camera on a tripod can capture constellations, star trails, meteors and the Milky Way
