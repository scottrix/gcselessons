A3: Algebraic Terminology

Foundation Higher All Boards

Understand and use the concepts and vocabulary of expressions, equations, formulae, identities, inequalities, terms and factors

📋 Key Concepts

Variable: A letter representing an unknown number (e.g., x, y, a)
Coefficient: The number multiplying a variable (e.g., in 5x, 5 is the coefficient)
Constant: A fixed number (e.g., in 3x + 7, 7 is the constant)
Term: A single number, variable, or product of numbers and variables (e.g., 5x, −3, 2a²b)
Expression: Terms combined with + or − (e.g., 3x + 5, 2a − 7b + 4)
Equation: An expression with an equals sign, true for specific values (e.g., 3x + 5 = 14)
Formula: An equation showing a relationship between variables (e.g., A = πr², v = u + at)
Identity: An equation true for ALL values, shown with ≡ (e.g., 2(x + 3) ≡ 2x + 6)
Inequality: Compares expressions using <, >, ≤, ≥ (e.g., 3x + 5 > 14)
Factor: A number or expression that divides exactly into another (e.g., factors of 6x are 1, 2, 3, 6, x, 2x, 3x, 6x)

📝 Expression vs Equation vs Formula vs Identity

TypeSymbolExampleMeaning
ExpressionNo =3x + 7Represents a value
Equation=3x + 7 = 16True for specific x (x = 3)
Formula=A = πr²Rule linking variables
Identity≡2(x + 3) ≡ 2x + 6True for ALL x
Inequality<, >, ≤, ≥3x + 7 > 16Range of values
Key difference: Equations are solved to find specific values. Identities are proven true for all values by simplifying both sides.

📝 Identifying Parts of an Expression

Example 1

For the expression: 4x² − 7x + 3

Identify: terms, coefficients, constant, variable

Solution:

Terms: 4x², −7x, 3

Coefficients: 4 (of x²), −7 (of x)

Constant: 3

Variable: x

Example 2

For: 5ab − 2a + 9

Solution:

Terms: 5ab, −2a, 9

Coefficients: 5 (of ab), −2 (of a)

Constant: 9

Variables: a, b

📝 Factors and Factorising

Factor: A number or expression that divides exactly into another.
Factorising: Writing an expression as a product of its factors.
Example 3

List factors of 12x

Solution: 1, 2, 3, 4, 6, 12, x, 2x, 3x, 4x, 6x, 12x

Example 4

Factorise: 6x + 9

Solution: HCF of 6 and 9 is 3 → 3(2x + 3)

📝 Classifying Algebraic Statements

Example 5

Classify each:

(a) 5x − 2

(b) 5x − 2 = 13

(c) P = 2(l + w)

(d) x² − 4 ≡ (x − 2)(x + 2)

(e) 3x + 5 > 11

Solution:

(a) Expression

(b) Equation

(c) Formula

(d) Identity

(e) Inequality

❓ Practice Questions

Q1: What is the difference between an expression and an equation?

Q2: What is a coefficient?

Q3: Is 2(x + 3) = 2x + 6 an equation or identity?

Q4: In 5x² - 3x + 7, what are the terms?

Q5: What is a variable?

✅ Answers

  1. An expression has no equals sign (e.g., 3x + 5). An equation has an equals sign (e.g., 3x + 5 = 14).
  2. The number in front of a variable. In 7x, the coefficient is 7.
  3. Identity (true for all x), shown with ≡
  4. 5x², -3x, 7
  5. A letter representing an unknown number

🎯 Exam Tips

  • Expression: no equals sign. Equation: has =, solved for specific values
  • Formula: relates variables (area, volume, physics). Identity: ≡, true for all values
  • Coefficient is the number BEFORE the variable (5x, coefficient = 5)
  • Terms are separated by + or − signs
  • Constant term has no variable
  • Factorise by taking out the highest common factor (HCF)

🧠 Problem-Solving Strategies

Problem-Solving

When classifying statements: look for = (equation/formula/identity), ≡ (identity), < > ≤ ≥ (inequality), none (expression). Check if = has variables on both sides and is always true → identity. If it relates physical quantities → formula. If it solves for a variable → equation.
Multi-Step Problem

A rectangle has length (x + 4) and width (x - 2). (a) Write an expression for the area. (b) Write an equation for when the area equals 24. (c) Show that the area can also be written as x² + 2x - 8. Is this an equation or identity?

Solution: (a) Area = (x + 4)(x - 2). (b) (x + 4)(x - 2) = 24. (c) Expand: x² - 2x + 4x - 8 = x² + 2x - 8. This is an identity (≡) — true for all x.

⚠️ Common Errors

Watch Out!

1. Wrong: Calling 3x + 5 = 14 an identity Correct: It's an equation — only true when x = 3

2. Wrong: Saying the coefficient of x in 5 - 3x is 3 Correct: It's -3 (include the sign!)

3. Wrong: Thinking x² and 2x are like terms Correct: They are unlike terms (different powers)

4. Wrong: Calling x + 3 = 7 a formula Correct: It's an equation — a formula relates multiple variables like A = lw

✍️ 6-Mark Exam Question

Extended Answer

6 marks: (a) Explain the difference between an equation and an identity. (b) Show that (x + 3)² ≡ x² + 6x + 9 is an identity. (c) The formula for the area of a trapezium is A = ½(a + b)h. If a = 6, b = 10, h = 4, find A. (d) Is A = ½(a + b)h an equation, formula, or identity?

(a) Equation: true for specific values only. Identity: true for ALL values (shown with ≡).

(b) LHS: (x + 3)(x + 3) = x² + 3x + 3x + 9 = x² + 6x + 9 = RHS. True for all x → identity.

(c) A = ½(6 + 10) × 4 = ½ × 16 × 4 = 32

(d) Formula — it relates variables A, a, b, h for calculating area.

Mark scheme: 2 marks for clear explanation, 2 marks for algebraic expansion proof, 2 marks for correct calculation and classification

📊 AO3: Reason & Interpret

Reasoning and Interpretation

Three students write statements about 2x + 6.

Student A: "2x + 6 = 14 when x = 4" — Equation

Student B: "2x + 6 ≡ 2(x + 3)" — Identity

Student C: "2x + 6 is an expression" — Expression

(a) Are all three students correct? Explain.

(b) Student D says: "2x + 6 = 2(x + 3) is an equation." Is Student D correct? Explain the difference from Student B.

(c) Write an inequality using 2x + 6 that is true when x > 2.

Answers: (a) Yes, all correct. A: 2(4)+6=14 ✓. B: Expand RHS = 2x+6 ≡ LHS ✓. C: No equals sign, so expression ✓. (b) Technically 2x+6=2(x+3) is an equation, but since it's true for all x, it's an identity. The = sign makes it an equation; ≡ emphasises it's an identity. (c) 2x + 6 > 10 (when x > 2, 2x > 4, so 2x+6 > 10).
