A4: Simplifying Expressions

Foundation Higher All Boards

Simplify and manipulate algebraic expressions by collecting like terms, multiplying a single term over a bracket, taking out common factors, expanding products of binomials, factorising quadratic expressions, simplifying expressions involving sums, products and powers, including the laws of indices

📋 Key Concepts

Like Terms: Terms with the same variable(s) and power (e.g., 3x and 5x are like terms; 3x and 3x² are NOT)
Collecting Like Terms: Add/subtract coefficients (e.g., 3x + 5x = 8x)
Index Laws: aᵐ × aⁿ = aᵐ⁺ⁿ, aᵐ ÷ aⁿ = aᵐ⁻ⁿ, (aᵐ)ⁿ = aᵐⁿ, a⁰ = 1, a⁻ⁿ = 1/aⁿ

📝 Collecting Like Terms

Rule: Only add/subtract terms with identical variables and powers. Keep the variable part unchanged.
Example 1

Simplify: 3x + 5x − 2x

Solution: (3 + 5 − 2)x = 6x

Example 2

Simplify: 4a² + 3a − 2a² + 7a − 5

Solution:

a² terms: 4a² − 2a² = 2a²

a terms: 3a + 7a = 10a

Constant: −5

Answer: 2a² + 10a − 5

Example 3

Simplify: 3xy + 2yx − 4xy

Solution: xy and yx are like terms (commutative)

(3 + 2 − 4)xy = xy

📝 Expanding Single Brackets

Rule: Multiply the term outside by EVERY term inside the bracket.
Example 4

Expand: 3(x + 4)

Solution: 3×x + 3×4 = 3x + 12

Example 5

Expand: −2(3x − 5)

Solution: −2×3x − (−2×5) = −6x + 10

Example 6

Expand and simplify: 2(x + 3) + 4(x − 1)

Solution:

2x + 6 + 4x − 4

= 6x + 2

📝 Expanding Double Brackets (FOIL)

FOIL: First, Outer, Inner, Last. Multiply each term in first bracket by each term in second.
Example 7

Expand: (x + 3)(x + 2)

Solution:

First: x × x = x²

Outer: x × 2 = 2x

Inner: 3 × x = 3x

Last: 3 × 2 = 6

x² + 2x + 3x + 6 = x² + 5x + 6

Example 8

Expand: (2x − 3)(x + 4)

Solution:

2x² + 8x − 3x − 12 = 2x² + 5x − 12

Example 9

Expand: (x − 5)²

Solution: (x − 5)(x − 5) = x² − 5x − 5x + 25 = x² − 10x + 25

📝 Index Laws

Multiplication: aᵐ × aⁿ = aᵐ⁺ⁿ (e.g., x³ × x² = x⁵)
Division: aᵐ ÷ aⁿ = aᵐ⁻ⁿ (e.g., x⁵ ÷ x² = x³)
Power of power: (aᵐ)ⁿ = aᵐⁿ (e.g., (x³)² = x⁶)
Zero power: a⁰ = 1 (e.g., 5⁰ = 1)
Negative power: a⁻ⁿ = 1/aⁿ (e.g., x⁻² = 1/x²)
Fractional power: a¹/ⁿ = ⁿ√a (Higher only)
Example 10

Simplify: 5a² × 3a³

Solution: (5 × 3) × a²⁺³ = 15a⁵

Example 11

Simplify: 12x⁵ ÷ 3x²

Solution: (12 ÷ 3) × x⁵⁻² = 4x³

Example 12

Simplify: (2x³)²

Solution: 2² × (x³)² = 4x⁶

Example 13

Simplify: (3a²b)³

Solution: 3³ × (a²)³ × b³ = 27a⁶b³

📝 Algebraic Fractions (Simplifying)

Rule: Factorise numerator and denominator, then cancel common factors.
Example 14

Simplify: 6x² / 9x

Solution: (6/9) × (x²/x) = ⅔ × x = 2x/3

Example 15

Simplify: (x² − 4) / (x + 2)

Solution: Factorise: (x − 2)(x + 2) / (x + 2) = x − 2 (x ≠ −2)

❓ Practice Questions

Q1: Simplify: 3x + 5x - 2x

Q2: Simplify: 2(x + 3) + 4(x - 1)

Q3: Simplify: 5a² × 3a³

Q4: Simplify: 12x⁵ ÷ 3x²

Q5: Simplify: (2x³)²

✅ Answers

  1. 6x
  2. 2x + 6 + 4x - 4 = 6x + 2
  3. 15a⁵
  4. 4x³
  5. 4x⁶

🎯 Exam Tips

  • Only collect like terms (same variable, same power)
  • When expanding brackets, multiply EVERY term inside
  • Watch signs: − × − = +, − × + = −
  • For double brackets, use FOIL or grid method
  • Index laws: add powers when multiplying, subtract when dividing
  • Coefficient also gets powered: (2x)² = 4x², not 2x²
  • Simplify fractions by factorising first, then cancelling

🧠 Problem-Solving Strategies

Problem-Solving

For complex simplification: work step by step. 1) Expand all brackets. 2) Apply index laws to powers. 3) Collect like terms. 4) Simplify fractions last. Check each step by substituting a value (e.g., x = 2) into original and simplified — they should match.
Multi-Step Problem

Simplify: 2x(3x - 4) - (x + 2)²

Solution: Step 1: Expand brackets. 6x² - 8x - (x² + 4x + 4). Step 2: Distribute minus. 6x² - 8x - x² - 4x - 4. Step 3: Collect like terms. 5x² - 12x - 4.

⚠️ Common Errors

Watch Out!

1. Wrong: 3x + 2x = 5x² Correct: 3x + 2x = 5x (powers don't change when adding)

2. Wrong: (x + 3)² = x² + 9 Correct: (x + 3)² = x² + 6x + 9 (middle term!)

3. Wrong: 2(x + 3)² = (2x + 6)² Correct: 2(x + 3)² means 2 × (x+3)². Square first, then multiply by 2.

4. Wrong: (2x³)² = 2x⁶ Correct: (2x³)² = 2² × x⁶ = 4x⁶ (coefficient also squared)

5. Wrong: x²/x = x Correct: x²/x = x¹ = x (but x²/x³ = 1/x)

✍️ 6-Mark Exam Question

Extended Answer

6 marks: (a) Expand and simplify: (2x + 3)(x - 4) - (x - 2)². (b) Factorise fully: 6x² + 15x. (c) Simplify: (4x³y²)² ÷ 2x⁴y.

(a) (2x² - 8x + 3x - 12) - (x² - 4x + 4) = 2x² - 5x - 12 - x² + 4x - 4 = x² - x - 16

(b) 3x(2x + 5)

(c) (16x⁶y⁴) ÷ (2x⁴y) = 8x²y³

Mark scheme: 2 marks for (a) correct expansion and simplification, 2 marks for (b) correct factorisation, 2 marks for (c) correct index law application

📊 AO3: Reason & Interpret

Reasoning and Interpretation

A student simplifies (3x²)² × 2x³ as 6x⁷.

(a) Is this correct? If not, find the correct answer.

(b) Explain the student's error.

(c) For what value of x would the student's answer equal the correct answer?

Answers: (a) Correct: (3x²)² = 9x⁴. 9x⁴ × 2x³ = 18x⁷. (b) Student forgot to square the coefficient 3: (3x²)² = 3²x⁴ = 9x⁴, not 3x⁴. (c) 18x⁷ = 6x⁷ → 18 = 6 (impossible for x ≠ 0). At x = 0, both equal 0.
