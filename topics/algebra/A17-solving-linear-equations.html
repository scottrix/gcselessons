Lesson 2: Core Concepts: solving linear equations

Duration: 50 minutes

Starter Activity (5 minutes)

Review Previous Lesson

Quick recap: write 3 key points from Lesson 1 on solving linear equations. Check them against the notes below.

Main Content (35 minutes)

Linear equation: An equation where the highest power of the variable is 1.
Goal: Find the value of the unknown that makes the equation true. Use inverse operations to isolate the variable.

Practice (10 minutes)

Answer: x = 6

Lesson 4: Exam Practice: solving linear equations

Duration: 50 minutes

Starter Activity (5 minutes)

Command Words

Main Content (35 minutes)

Extended Answer

Extended question: Extended Answer 6 marks: A rectangle has length (2x + 1) cm and width (x + 3) cm. The perimeter equals the area. (a) Write an equation. (b) Solve to find x. (c) Find the dimensions of the rectangle. <div class="

(a) Perimeter = 2(2x + 1 + x + 3) = 2(3x + 4) = 6x + 8. Area = (2x + 1)(x + 3) = 2x² + 7x + 3 Equation: 2x² + 7x + 3 = 6x + 8 → 2x² + x - 5 = 0 (b) Using the quadratic formula: x = -1 ± √(1+40) ⁄ 4 = -1 ± √41 ⁄ 4 . Since x > 0: x = -1 + 6.40 ⁄ 4 ≈ 1.35 (c) Length ≈ 2(1.35) + 1 = 3.70 cm, Width ≈ 1.35 + 3 = 4.35 cm Mark scheme: (a) 2 marks for both expressions and equation. (b) 2 marks. (c) 2 marks for dimensions.

Exam Tips: Do the same to both sides | Collect x terms on one side, numbers on the other | Expand brackets before solving | Multiply by denominator to remove fractions | Always check your answer by substituting back
Common Errors: Watch Out! 1. Wrong: Expanding -2(x + 4) as -2x + 4 Correct: -2(x + 4) = -2x - 8 (multiply BOTH terms by -2) 2. Wrong: Solving x ⁄ 3 + x ⁄ 4 = 7 by adding numerators: 2x ⁄ 7 = 7 Correct: Multiply all terms by 12 (LCM of 3, 4): 4x + 3x = 84 → 7x = 84 → x = 12 3. Wrong: 4x + 3 = 2x + 9 → 4x + 2x = 9 + 3 Correct: 4x - 2x = 9 - 3 (change signs when moving across the equals sign)
AO3 - Reasoning & Interpretation: Reasoning and Interpretation A plumber charges £45 call-out plus £30 per hour. A second plumber charges £20 call-out plus £40 per hour. (a) Write a formula for each plumber's charge C for h hours. (b) For how many hours are both plumbers the same cost? (c) A job takes 3 hours. Which plumber is cheaper and by how much? Answers: (a) Plumber 1: C = 45 + 30h. Plumber 2: C = 20 + 40h. (b) 45 + 30h = 20 + 40h → 25 = 10h → h = 2.5 hours. (c) P1: £135, P2: £140. Plumber 1 is £5 cheaper.
